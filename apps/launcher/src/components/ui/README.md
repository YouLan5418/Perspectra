# shadcn-vue components

Source: https://github.com/unovue/shadcn-vue/tree/dev/apps/v4/registry/new-york-v4/ui (MIT).

Only Button and the Dialog parts used by this launcher are retained.
Local changes: explicit .ts imports, close label in Chinese, default HTML elements for exactOptionalPropertyTypes.
Style customization lives in src/style.css. Reka UI provides focus trapping, Escape, aria descriptions, and modal behavior.
