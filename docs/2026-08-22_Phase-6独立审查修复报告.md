# Harness / Cordis World V0 Phase 6 独立审查修复报告

> 日期：2026-08-22
> 输入：GLM 5.3 Phase 6 审查、冻结实施规格 V0.2、ADR-0040
> 结论：Phase 6 Reference Architecture 修订门槛通过；严格 V0 Release Closure 尚未完成

## 1. 修复思路

本轮按四个根因收口，而不是给单个异常路径增加特判：

1. **恢复只信耐久事实**：已经 COMMIT 的 Round 从 Event/Outbox/Bundle 重建结果，Provider 不参与恢复。
2. **权限必须不可复活**：Lease owner 由进程实例 nonce 决定，外部标签不构成 authority；所有异步窗口贯穿续约和 fencing。
3. **行政与投递必须按 Branch 闭合**：Gate、Inbox proof、Outbox claim/dead-letter 和 archive 补偿都在各自 SQLite CAS/事务边界内完成。
4. **生产入口只有 Application Port**：配置 Application 后不再打开低层 Store/Admin 捷径；CLI/RPC、Cordis event 和耐久输入都经过受约束接口。
