# 阶段报告：悬疑 Demo Phase 2——多轮调查与真相揭露闭环

- 日期：2026-08-23
- 状态：本机门槛完成
- 范围：确定性文本适配、调查 Action、证据链、错误/正确指控、多轮重放

## 已完成

### 输入边界

玩家文本先经过 `DeterministicInvestigationIntentParser`，只生成候选 Action：

```text
玩家文本 → resolved / clarification_required
              ↓ resolved
Round Inbox → Validator → Rulebook v3 → Authority/Event/Outbox
```

支持窄自然语言和显式命令：

| 行为 | 自然语言示例 | 显式命令 |
|---|---|---|
| 说话 | `说 我们开始吧` | `/speak 我们开始吧` |
| 检查 | `检查一下书桌` | `/inspect entity:study-desk` |
| 询问 | `询问鲍勃关于钥匙` | `/ask character:bob entity:study-key` |
| 出示 | `向侦探出示钥匙痕迹` | `/present evidence:key-moved character:detective` |
| 指控 | `指控鲍勃：钥匙痕迹` | `/accuse character:bob evidence:key-moved` |

解析器只看当前角色从耐久 Event 前缀获得的 evidenceId。未发现证据不会出现在 clarification 候选中；即使玩家猜中内部 ID，Rulebook 仍会拒绝未发现或未出示的证据。

### 权威调查规则

Rulebook v3 在不改变 v1/v2 Hash 的前提下新增 `inspect / ask / present_evidence / accuse`。调查状态完全从 Event Log 重建：

- `entity.inspected`：角色发现证据，同时产生 owner-scoped Observation；
- `character.asked`：记录提问对象与主题；
- `evidence.presented`：要求证据已经由行动者发现且目标在场；
- `investigation.accusation-resolved`：记录错误或正确指控；
- `investigation.case-closed`：只有正确指控产生，结案后拒绝再次指控。

Bob 在被问及钥匙时通过正式 Agent Proposal 说谎；侦探在收到证据时通过 Director Proposal 回应。两者仍只提交 Action，不能直接改变案件状态。

## 本地运行

先初始化并执行固定开场：

```powershell
corepack pnpm@11.7.0 demo:mystery D:\path\to\world.sqlite D:\path\to\session.sqlite
```

随后每次用唯一幂等键提交一轮文本；重复同一键会耐久重放：

```powershell
corepack pnpm@11.7.0 demo:mystery:turn D:\path\to\world.sqlite D:\path\to\session.sqlite turn:ask "询问鲍勃关于钥匙"
corepack pnpm@11.7.0 demo:mystery:turn D:\path\to\world.sqlite D:\path\to\session.sqlite turn:inspect "检查一下书桌"
corepack pnpm@11.7.0 demo:mystery:turn D:\path\to\world.sqlite D:\path\to\session.sqlite turn:present "向侦探出示钥匙痕迹"
corepack pnpm@11.7.0 demo:mystery:turn D:\path\to\world.sqlite D:\path\to\session.sqlite turn:accuse "指控鲍勃：钥匙痕迹"
```

输出只包含玩家 Action/Result、公开实体/案件状态和玩家 CharacterView，不包含 Bob/侦探的私有视图。

## Golden Scenario

自动化场景执行七轮：开场、询问 Bob、检查书桌、过早指控（拒绝）、出示证据、错误指控 Alice、正确指控 Bob。最终状态为 `solved`，culpritId 只在正确裁定后公开。重启后用相同幂等键重放最后一轮，Provider 调用为零且 Event Hash 完全相同。
