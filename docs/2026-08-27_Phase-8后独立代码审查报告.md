### 发现问题

**[P2] 投影层未校验 `objective.kind ∈ GOAL_OBJECTIVE_KINDS`**
位置：`packages/store-sqlite/src/cognition-projection.ts:103`（`validateGoal` 仅检查 `objective` 是对象）。
`packages/contracts/src/cognition.ts:40` 已锁定该词表并纳入 vocabulary hash，Genesis 写入路径也有校验（`packages/world-pack/src/schema.ts:536`）；但认知事件直接 `commitRound` 进入日志时（反射路径在 P8.8 之前尚无 validator），`{kind:'whatever'}` 可通过投影校验并进入 bundle/bundleHash。建议补一行 `literal(value.objective.kind, GOAL_OBJECTIVE_KINDS, ...)` 并加负例测试。

**[观察] 非法认知事件可入库形成"毒丸前缀"**
事件 schema 校验发生在重建读取端而非写入闸门：一旦非法事件被提交，该分支此后任意 as-of 的 `rebuildAt/historyAt` 将永久抛错且无法修剪（append-only）。经与 `character-view.ts` 对比，这是仓库既有投影架构的一致选择（世界事实权威 append-only、读侧 fail-closed），不构成对完整性规则的放宽；但鉴于认知事件的词表已在 contracts 冻结，建议后续考虑在 kernel/commitRound 入口增加 schema gate，或把该取舍明确记入文档。

**[观察] 全量重放性能**
每次重建 O(全部事件)，Round 内每个动作各调一次 audience 重建亦同。Phase 8 数据量下无碍；Checkpoint（ continuity-checkpoint/v1）落地时一并评估增量水位。

### 发现问题

**[P3] `direct` scope 的在场旁观者拿不到任何 Observation**
`packages/application/src/scene-decision.ts`（audienceForAction）：`direct` 只产生 `[actor, ...recipients]`，其余在场者既无全文也无 occurrence-only。规范只对 private 明确了旁观者降级规则，`direct` 类动作（如当众向某人递物、对某人做动作）在场旁观者的知情边界 spec 未定。建议要么给 direct 补 occurrence-only 语义，要么在规格/ADR 层显式记录"direct 无旁观观察"，避免实现替规范做沉默决定。

**[P3] occurrence-only 观察包含 `resolution.reason` 原文**
`packages/application/src/round-coordinator.ts`（observation content）：发生级观察附带完整 reason/reason 可能引用行动参数细节，对仅应知道"发生了私语"的旁观者存在过度暴露面。与 v1 全量观察行为一致故非回归，但 v2 引入了内容分级后，reason 是否也应分级值得在同一次改动中决定。

**[观察] `record.id`/`characterId` 仅做非空字符串校验**
`cognition-projection.ts` 的 `text()` 不校验品牌 ID 形状（如 `chr:` 前缀协议串）。品牌强校验在边界层（`brandId`/`assertProtocolString`）完成，与既有投影风格一致；记录在案即可。
