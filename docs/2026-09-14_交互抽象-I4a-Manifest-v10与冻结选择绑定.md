### 1.1 Manifest v10 的形状

v10 = **v9 的全部内容契约 + 冻结世界选择**，只有两处不同：

```
interactionCatalog: InteractionCatalogV3      ← 包锁、定义锁、绑定（含 config）
actionGroupPolicy: { version: 'bounded-action-group/v2' }
```

`InteractionCatalogV3` 已经由 I2-a 的编译器产出，字段恰好是 `InteractionWorldSelection` 除去 `address`（`packages` / `definitions` / `bindings`）。也就是说 v10 的 Manifest **直接携带**了冻结世界所需的选择，运行时不需要再从别处拼。

行动组策略升 v2 的理由只有一个：冻结路径的步骤参数寻址的是 `bindingId` 与定义锁，而不是旧目录条目，形状不同。v1 世界看不到新动作版本，v2 世界也不会静默接受旧版本。

`registries` 沿用 `characterInteractionManifestRegistries()`：v10 的事件与动作词汇和 v9 完全相同（`entity.transferred`、`character.relation-started` / `-ended`、`speak` / `move` / `interact`），变的是**谁拥有语义**，不是词汇。

### 1.2 存储侧不信任自己写过的字节

`runtimeManifestFromStored` 对 v10 调用 `parseStoredInteractionSelection`，逐项重读并重验：

- 包锁、定义引用（正安全整数版本）、定义 Hash、实现 Hash 的结构与唯一性；
- 包 / 定义 / 绑定数量上限（32 / 128 / 4096，与冻结 profile 同量级）；
- 绑定必须指向**本世界已启用**的定义；
- 绑定目标必须是 Manifest 自己声明的实体或角色。

最后一条有一个刻意结果：**`relation` 目标在静态 Manifest 里一律失败关闭**。关系实例是运行期从来源 Action 派生的，静态 Manifest 不可能预先声明它；允许它出现等于让"猜一个关系 ID"有落点。编译器本身也只产出实体/角色绑定，两边一致。

### 1.3 v10 激活失败关闭

`WorldBootstrap` 增加第三个能力开关 `frozenInteractionRuntime`，默认 **false**：

```
Manifest v10 + 无冻结交互运行时 → MANIFEST_RUNTIME_UNAVAILABLE
```

这与规格 §7 的"版本号登记不是声称解析器已支持；未完成闭包不向普通激活入口公开新世界"一致。**登记 v10 不等于 v10 可用**——本轮的 v10 世界能编译、能存储、能被完整重读，但不能激活，因为还不能裁定它的动作。

## 2. 版本守卫的统一

v9 与 v10 在**授权来源**上相同（都需要 Host 证明的 `actionId` 与 `resolutionAuthority`），在**执行路径**上不同。因此把原来散落的 `schemaVersion === 9` 拆成两个谓词：

| 谓词 | 覆盖 | 用途 |
|---|---|---|
| `manifestUsesHostAuthority` | 9、10 | Rulebook 上下文携带 authority/actionId、Authority schemaVersion、玩家预裁定绑定、玩家意图开关 |
| `manifestUsesFrozenInteractions` | 仅 10 | 冻结目录路径、旧 `interact`/`take` 动词拒绝、激活门禁 |

`manifestUsesInteractions`（8、9）与 `manifestUsesCharacterInteractions`（仅 9）**一字未改**，所以旧目录解析、旧 v9 的 move 收尾分支、旧黄金字节全部不受影响。这是本轮"旧路径不动"的实际落点。

## 3. 明确未做的决定

### 3.1 Round Authority 仍是 5，不是规格表里的 6

规格 §7 为新路径分配了 Round Authority schemaVersion 6（"显式角色/定义依据绑定"）。本轮 v10 世界的 Authority 仍写 5。

理由：Authority 6 的**内容**是冻结裁定的角色映射与定义依据 trace，而 trace 只有冻结解析器才产出；本轮没有冻结解析器，写 6 只会得到一个空壳版本号。Authority 6 与 `responsive/v2`、`reaction-evidence/v1` 同属"观察与反应依据"那一批（即 I4-d），一起落地才自洽。当前**没有**任何已激活的 v10 世界，因此不存在需要迁移的旧 v10 存档。

这是一处**有意的、记录在案的偏离**，不是遗漏。

### 3.3 I4 三条验收边界的当前状态

V0.3 §10.1 列出的三条，**本轮一条都还没有成立**：

1. **新路径的 move 经统一生命周期收尾** —— 机制齐全（I3-c 的世界 fold + `contact:end-on-move`），v10 的 move 也已经不再走 Kernel 的 `endCharacterRelations`，但**没有生产调用者**去调 `fold()`，所以"新路径不按接触名分支"目前只到"没有回退路径"，没到"有替代路径"。
2. **fold 只有一个执行位置** —— 目前 `resolve()` 是唯一调用者，应用层尚未接线，所以既没有重复也没有遗漏，属于"还没到会犯错的阶段"。
3. **四入口与恢复门禁** —— 未开始。

## 5. Evidence → Finding → Path

E1：`worldpack/v5` 已能编译出带包锁的 `interaction-catalog/v3`，但 `adaptCompiledWorldPack` 对 v5 直接抛"未接线"。F1：目录编译好了却没有版本可以承载它，"作者可声明"停在编译层。P1：新增 Manifest v10 承载该选择，并把 v5 档的适配接到 v5 编译器上。
E2：规格 §7 要求"未完成闭包不向普通激活入口公开新世界"。F2：若 v10 可激活而不能裁定动作，世界会进入可写但无法解析的状态。P2：`WorldBootstrap` 增加默认关闭的能力开关，v10 激活前置失败关闭（§1.3）。
E3：`schemaVersion === 9` 在应用层出现 9 次，v10 会被逐处漏掉。F3：散落的版本字面量没有单一事实来源。P3：拆成 Host 授权与冻结路径两个谓词，前者覆盖 9/10，后者仅 10（§2）。
E4：Authority 6 的输入只有冻结解析器才产出。F4：先写版本号会得到一个没有内容的槽位，且制造无迁移路径的偏航。P4：本轮维持 5，与观察/反应依据同批落地，并在 §3.1 记录理由。
E5：绑定目标投影若允许 `relation`，静态 Manifest 就能指名一个运行期实例。F5："猜中 ID 不构成权限"会被削弱。P5：存储侧重读对 `relation` 绑定目标失败关闭（§1.2）。
