## 2. I5-a 落地内容

### 2.1 独立包 `examples/world-packs/hand-in-hand/`

一个只为交互路径写的小世界：两个旅人在山脊雨棚躲雨，一把共用的伞、一个保温壶。它有完整的作者文件（world / locations / entities(v2) / characters(v3) / scenes / player-slots / presentation / cognition / memory / assertions），外加 v4 没有的三件：`reaction.json`、`manifestation.json`、`interactions.json`，并把 `worldpack.source.json` 升到 `worldpack-source/v5`。

它的选择覆盖首批五类定义，且**关系解除只写类、不写实例**：

```jsonc
"relationBindings": [{
  "bindingId": "binding:release",
  "relationClass": "base:hold-hand",       // 类：由谁创建的关系
  "definition": { "id": "base:end-contact", "version": 1 },
  "config": {}
}]
```

这是 ADR-0095 的第一个**真实内容**用户——在此之前关系类绑定只在运行时测试里出现过。

### 2.2 用例证明的三件事

1. **作者的包能走到 v10。** `compileWorldPackSource` → `worldpack/v5`；`adaptCompiledWorldPack` → Manifest v10；`WorldApplication.activate` 打开；包自己的选择被冻结并通过激活门禁。
2. **它自己的选择能通关。** 玩家依次：拿起共用的伞 → 递给同行者 → 牵住对方的手 → 走到山脊小路。落库事件里递交落在同行者手上（不是地点），关系恰好一条结束事件、`reason` 为 `participant_moved`——结束来自世界 fold，不是 Kernel。
3. **只改内容就能加交互。** 用例在临时目录里复制同一份包，**只**在实体文件里给保温壶多加两条绑定，重新编译：目录里的绑定集合变了，而它仍然是**同一个 v10 世界**——没有新协议、没有新动作名、没有一行代码。这是规格 §1"只改内容可加物品"在交互路径上的落点。

### 2.3 顺手钉住的一个已知缺口

用例 `cannot yet open a Reaction Cycle on a v10 world, which is a known gap` 显式断言：**响应式的 v10 世界目前打不开反应周期**，抛出 `interaction capability does not match Manifest`。

原因是反应周期的能力声明（`allowedActionTypes`）仍说 v9 的词汇：协调器写 `['speak@1','move@1','take@1']`，而 `store-sqlite` 的判据要求 v10 世界带 `interact@1`。这是 I4-c 记录里列为"未做"的那一项。

之所以把它**钉成一条期望**而不是绕开：绕开就只剩一句"反应入口对 v10 不可用"的口头声明；钉住之后，谁修好它谁必须**有意**改这条期望。包本身的 `reaction.json` 因此是 `disabled`——它不是回避，而是当前 v10 世界能诚实声明的唯一模式。
