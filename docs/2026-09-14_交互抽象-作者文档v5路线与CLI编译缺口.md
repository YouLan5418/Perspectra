## 1. 补的是哪一条

这次升级的目的写在规格 §1：**作者只改内容就能加交互**。到 `07fabdb` 为止，这条链路的每一段都有记录——作者源、编译、激活、模型协议、上限、恢复、部署——但**面向作者的两份文档仍停在 v4 / `--interactions`(v8,v9) / `submit_actions/v5`**，一个字都没提 `worldpack-source/v5`、`interactions.json`、定义锁、两条策略或 `submit_actions/v7`。读文档的人做不到这件事，那这条目的对外就不成立。

## 2. 写文档时翻出的断点：CLI 编不过 v5 包

按文档要给出的第一条命令去核对时，直接红了：

```
$ worldpack compile examples/world-packs/hand-in-hand --out .tmp/…
{"errorCode":"PLUGIN_NOT_REGISTERED","file":"interactions.json","jsonPointer":"/packages",
 "message":"package package:interactions-basic@1 is not installed by the Host"}
```

原因是 `executeWorldPackCli` 的 `validate`/`compile`/`test` 都调用 `compileWorldPackSource(sourceDirectory)`——**不带 Host 的交互包清单**。v5 世界带的是一份**选择**，编译它必须知道 Host 装了什么；测试里一直是显式传进去的，CLI 没有这条路。

修法（保持分层）：

| 位置 | 改动 |
|---|---|
| [world-pack/src/creator-cli.ts](../packages/world-pack/src/creator-cli.ts) | `executeWorldPackCli(args, options)` 新增 `WorldPackCliOptions.interactionPackages`；`validate`/`compile`/`test` 都把它交给编译器 |
| [world-pack/src/tooling.ts](../packages/world-pack/src/tooling.ts) | `WorldPackTestRunner.run(sourceDirectory, interactionPackages)` |
| [world-pack/process/cli-entry.ts](../packages/world-pack/process/cli-entry.ts) | 进程入口带上**默认安装**（`package:interactions-basic@1` 的描述） |

两半各自有用例，且各自单独回退都会变红：库那一半由 `creator-cli.test.ts` 的成对用例钉住；入口那一半由 `tests/process-entry.test.ts` 的**真子进程**用例钉住（起 CLI 编译示例包）。这不是洁癖——第一版只测了库那一半，我把入口的默认安装改成空数组后用例**照样全绿**，等于"作者第一步会断"这件事没人看着。

库保持内容无关：它按交到手上的包编译；**只有进程知道这台 Host 装了什么**。用例成对：带上安装 → `validate`/`test` 通过；不带 → 报 `is not installed by the Host`（这条证明参数是承重的，而不是好看的）。

修完之后文档里的命令逐条真跑过：`validate` → `valid`、`test` → 断言计划、`compile` → `packHash sha256:ae46ed03…`、`inspect`、`activate` → `activated`。

## 4. 文档里明确写下的边界

写文档的价值有一半在于**不把做不到的事说成做得到**，所以三处边界写进了正文而不是脚注：

1. **包拥有、Pack 不能改**：一个定义接受哪些 cue、成功与失败各由谁观察，都是包内受锁策略；作者只能选定义，要改就去改包（Host 侧受信实现）。这是这条路线最容易误解的地方。
2. **网页试玩尚未接上 v7**：真实模型今天用 `tests/experiments/v10-provider-gate.ts` 驱动。
3. **两条适配器前置**：Host 的 `tools` 是契约描述、需渲染成 JSON Schema；上下文里有 `developer` role、需映射。两者都指向 [I5-d 记录](2026-09-14_交互抽象-I5d冻结路径的真实模型门禁.md)。
