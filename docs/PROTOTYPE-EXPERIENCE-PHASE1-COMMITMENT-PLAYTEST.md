# 第一阶段后续实验：角色自己接受的长期约定

> 2026-09-25；deepseek-flash；prototype-g1；通过网页试玩同一条 FrozenWorldPlaytestRuntime 运行。四组使用独立新存档，各 24 轮，中途关闭并重新打开。DeepSeek 凭证仅从 Windows 用户环境变量读取，Provider 日志只记录请求正文和响应，不记录请求头或凭证。

## 1. 要回答的问题

前一轮实验显示，角色被直接追问时能够引用旧经历，但尚不能据此判断自发行为。本轮只测试一个窄场景：同行者**亲口接受**“玩家说打算去后室时，主动提醒看门缝有没有光”的约定。末轮玩家只陈述打算去后室，没有询问提醒词或要求同行者履约。对照组只把首轮私语替换为“先看看前室的桌子”，后续 23 轮输入相同。

中间 22 轮玩家输入围绕桌子、钥匙、保温瓶和休息，不再次说“后室”“门缝”或“光”。两种末轮输入分别为公开陈述和只对同行者私下陈述；语义相同。实际角色可能自己行动，所以有效性还要看首次是否接受、末轮是否仍在前室，以及约定在末轮请求中的来源。试跑中原先的填充语句反复提后室，同行者多次复述约定；该样本不用于长程结论：.tmp/frozen-playtest-drive-2026-09-25T12-45-39-352Z/。

复现入口：tests/experiments/frozen-playtest-drive.ts，使用 --pack examples/world-packs/prototype-g1，依次用 --scenario commitment、commitment-control、commitment-private、commitment-private-control。四组均为 /act speak，避免玩家意图解释造成额外差异。

两组有约定运行满足“角色自己接受”，两组末轮均未直接追问。四组末轮同行者的 scene.locationId 都是 location:front-room。公开有约定组的留守者已通过移动事件离开前室，其他三组末轮三人同场。私下有约定组里，同行者第 3 轮在叙事中声称拿起钥匙，末轮继续声称手持钥匙，但 World Event Log 没有钥匙转移；该组唯一的权威物品转移是留守者拿起保温瓶。这里出现了第三阶段已知的叙事分叉，不能把同行者手持钥匙当成事实。私下说话仍可能引发旁观者处理交互发生事实，不能把它当成只有两名角色参与的完全隔离试验。这些差异限制因果强度，但没有改变末轮的发言条件与同行者所在地点。

## 3. 请求上下文核对

从每组 provider.jsonl 中读取同行者的首个模型请求，核对 context.stimulus、memories、observations、selfObservations 与 scene；汇总保存在 .tmp/commitment-analysis-2026-09-25.json。

- 公开有约定组在第 9、14、22、24 轮选到相关旧记忆；私下有约定组在第 9、14、24 轮选到。**并非每轮持续注入**，而是随当前刺激重新选择。
- 两组有约定的第 24 轮首次请求都有两条相关记忆：sourceSeq=22 是玩家原先的私语，sourceSeq=28 是同行者自己说“行……我就提醒你”的回复。同期 observations、selfObservations 和 stimulus 均不含“门缝”；因此末轮不是靠近期观察或本轮明示约定。
- 两组无约定的末轮请求没有该内容，最终回复也没有提醒看门缝的光。四组请求里的同行者地点均为前室。
- 有约定组末轮这两条记忆的来源不同，仍无法单独量化“玩家提议”和“角色亲口接受”各自对模型选择的贡献；本实验验收的是**自行接受过的约定整体**是否改变后续选择。
- 在两组有约定样本各自末轮的同一世界序号重新准备召回：真实刺激会选中第 22、28 序号；保留动作元数据、在场人物和开放目标，仅把话语改为“我先看看桌上的黄铜钥匙”，两条约定都不再进入模型可见的前 10 条；空刺激同样不选。真实刺激即使去掉在场人物线索，仍选中两条。反事实输出见 .tmp/commitment-recall-counterfactual-2026-09-25.jsonl。这验证了当前“去后室／门口”的话题对本次选择的作用，不声称其他表述都能召回。

当前刺激虽未重复“门缝”，仍含“去后室”“门口”，足以把旧约定选入模型可见记忆。这里验证的是实际选中结果，不把检索算法对所有同义说法的召回能力外推为已通过。

## 4. 决策

在这个具体约定上，现有观察、记忆召回和角色自主输出已形成可见闭环：两个有约定样本主动提醒，两个无约定样本未提醒。**暂不为此新增认知提交路径或通用承诺机制。**未来若出现“角色亲口接受、触发轮仍能看到旧约定，却多次不执行”的真实反例，再评估让角色经既有认知事件提交自己的承诺。

本结果是四条探索性模型轨迹，不是统计稳定性证明；中途角色行动改变了场景成员与保温瓶归属，还出现了未裁定的钥匙持有叙述。四组只有世界包初始化的 character-goal.upsert，没有运行期 character.reflect 或其他认知回写。没有修改 Memory 检索算法、认知事件协议或权威事实路径。未裁定的钥匙转移叙述是第三阶段的具体复现样本，应单独处理。
