本轮停止重复短场景实测，复用[第十三轮连续试玩](PROTOTYPE-PLAYTEST-13.md)的真实模型证据，另用本地模拟 Provider 与数据库断言检查机械边界。本文的“通过”只指列出的路径，不代表真实模型再也不会写出与受控事实矛盾的自由叙述；后者仍是 G3 风险。

| P-03 执行时重验 | 新增测试让 NPC 对已被自己拿走的同一物品再次提出旧拿取请求；第二次被规则拒绝，只有一次转移 | 通过当前物品路径 |

| P-06 提交身份与后续失败 | `store.test.ts` 验证相同事务重放返回 `already_committed`；新网页测试确认先转移、再发生无效续写、重开后仍只有一次转移 | 通过当前路径 |

| P-08 纯表现 | 纯 `publish` 单测无 `perform`；G3 探索样本发现玩家纯表现被第一波过滤，现已用网页回归测试验证 Root 纯表现唤醒 NPC，后续普通旁观表现仍不强行开启新波 | 通过修复后的路径 |

G1 的 `perform → 结果 → 再 perform → 结果 → 自由表达` 已接入默认网页激活，并由模拟 Provider 及实际 World Event 验证；最多两次受控尝试，第三次调用只提供表达或 abstain，8 次总调用预算仍生效。固定世界包 [`prototype-g1`](../examples/world-packs/prototype-g1) 与组合测试 `g1-combination.test.ts` 现在把两房间、两 NPC、黄铜钥匙和握手放进同一条可重跑路径：握手提交关系、同行者拿钥匙、留守者拿取被拒、玩家与同行者进入后室、后室对白不投递给留守者、玩家返回后归属不漂移。玩家对钥匙归属的错误说法也没有产生第二次转移。结合上表与现有单向存储接口，**G1 的模型无关机械门槛在 P-08 修复后通过**；摘要/记忆的具体措辞是否误导模型仍归 G3 体验检查，不在此声称任意叙述都正确。真实模型的握手释放叙述已出现分叉，见 [G3 报告](PROTOTYPE-G3-PLAYTEST-01.md)。

## G2：本轮验证与剩余限制

| 故障 | 验证结果 |
| --- | --- |
| 规则拒绝 | NPC 收到真实 `rejected` 结果，归属不变，可以继续表达 |
| 格式错误 | 续写带非法字段时不发布；物品此前的成功转移保留；网页明确提示“格式无效、交互已提交、后续表达未完成” |
| Provider 失败 | 已提交结果不回滚；网页区分角色模型服务未完成与玩家输入未理解 |
| 超时与打断 | 两个阶段的迟到输出均不提交；网页暂停期间返回的 `perform` 无效，玩家看到未完成提示 |
| 重开 | 关闭并重新打开同一世界后，已提交物品状态仍在，未完成续写不会自动重放，也没有第二次转移 |
| 有界停止 | 调用/波次/角色上限触发时，网页告知剩余反应未执行；不会把预算停止显示为玩家输入有误 |

G2 的**核心机械边界已在这些故障注入下成立**，但完整契约仍留两项明确待办，均不阻塞开始 G3：

- [ ] **G2-1 格式修正**：角色首次返回无效格式时，在本轮剩余 Provider 预算内最多给一次修正机会；先前已提交交互不得重复执行。预算不足或再次无效时结束并明确报告未完成部分。
- [ ] **G2-2 有界非法输出诊断**：只在本机诊断记录中保存无效输出的有限正文及截断标志，避免记录凭据或私密上下文；玩家界面继续显示失败类别和阶段，不直接公开原始正文。

在它们完成前，G2 不标记为全项通过；已验证的“无伪提交、无迟到提交、已成功结果不回滚”保持成立。
