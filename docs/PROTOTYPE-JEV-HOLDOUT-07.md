## 1. 冻结范围和预设退出条件

分类问题、影子对账、时间窗口、单次重写适配器全部保持实验 06 原样。执行前保存源码副本及 SHA-256；执行后校验四个源文件未变。没有根据本轮答案改提示词、重试失败请求或追加样本。

新固定文本和预期标签在首次调用前写入 `fixtures.json`、`protocol.json`。门槛：16 条明确冲突至少检出 15 条；16 条明确正常表达零误报；8 组完整经历链全部正确；调用失败零。任一失败，不进入连续试玩。这些是本次产品验收门槛，不是总体准确率保证。

固定样本通过后，先写入 `live-protocol.json`，再执行四场各 12 回合。预设连续验收要求：纠错组最终明确冲突为零；明确不必要或含糊干预为零；回合/API 审查无失败；发布前适配器中位耗时不超过 1500ms、P90 不超过 4000ms；至少一次有效纠错才有收益证据。无论结果如何，只完成这四场，不继续调参。

## 2. 固定新样本：40 个场景，64 次真实 Jev 调用

两个人工构造场景：维修间的铜哨 / 检修册，档案室的银质书签 / 蓝封账簿。每场景 8 条明确冲突、8 条正常表达，以及 4 组经历链。每组链含两次相似检查、两位不同角色依次回述；两次检查仅一次有正式临时持有，交换真实/虚构的先后次序，并分别回述旧/新经历。

复用实际 `JevShadow`、`holderEvidence` 和 `reconcilePlacement` 运行。构造的是满足这些读取器格式的事件前缀，**不是经 Rulebook 提交的新世界存档**；占位事件 Hash 不作持久化正确性的证明。Jev 只得到公开文字与元数据，不得到预期标签或 World holder。单条样本只审查目标物品；第二件物品用于指代干扰，不把目标检出率当成整段所有物品的覆盖率。

| 指标 | 结果 |
| --- | ---: |
| 明确冲突检出 | 16/16 |
| 正常表达误报 | 0/16 |
| 两次经历及两级回述完整正确 | 8/8 |
| 响应 / 尝试 | 64/64，无失败 |
| 单物品影子审查耗时中位 / P90 | 311 / 400ms |
| Jev 已记录费用 | $0.016532334 |

这里的“独立”只表示**文本没有参加先前调参**。场景由了解既有失败的同一 Codex 作者构造，两个场景有成对的语义模板，时间线索较明确；不是独立人工、随机生产采样、64 个独立事故或 100% 通用准确率。结果只允许进入下一关。

## 3. 新内容连续试玩

复用原 Pack 格式和 core，制作本次证据目录内的“雨站失物招领”：陆舟、程雨、铜怀表、布面日记。两件物品均提供已有 `base:take/drop/give`；日记补齐 drop/give，避免继续靠缺失释放动作制造压力。只改本轮内容副本，原 Pack 和主运行时未改。这是一个内容变体，**不是另一种玩法的扩展性验收**。

执行顺序 A1 → B1 → B2 → A2；A 正常发布加事后影子，B 发布前检查、最多一次重写，再事后影子。四场实际提交的 12 句玩家输入逐字相同，采用明确 `/act speak`，不把输入解释器差异混进实验。NPC 仍自主决定动作与表达，轨迹不同，不是严格反事实配对。

178 条最终 NPC 发布先匿名排序、隐藏组别及 Jev 标签，由当前 Codex 逐条阅读，并对取得、放下候选核对正式前缀；先保存判断，再揭组看干预。作者此前看过汇总报警数量，**不是独立人工或严格盲评**。只计受控持有/释放矛盾；未结构化的刻字、翻页、轻触等不扩张成物理状态。对白错误记忆单列，不当作客观权威事件。

## 4. 14 次干预的逐条结果

| 场次 / 原稿 head | 审阅 | 说明 |
| --- | --- | --- |
| B1 / 233 | 必要且有效 | 日记已由陆舟持有，原稿却说“台面上的两件东西”；修正去掉错误背景位置 |
| B1 / 327、357 | 必要且有效 | 原稿未经正式 take 就把怀表拿起；改成接近、准备或邀请 |
| B1 / 108、132、138、144、162、174、186、210 | 不必要 | 桌面翻书、摊开册子、压页、看翻页的手，被推断为人物取得或持有整本日记 |
| B1 / 238 | 不必要 | “日记摊开的页”没有断言日记在桌面；邻近怀表的台面位置被错误套用 |
| B1 / 339 | 不必要 | 指尖把桌面的怀表翻面，没有明确拿离台面或取得保管；却被要求放弃查看 |
| B2 / 327 | 时间解释有争议，重写明确失败 | 原稿复述刚完成的放下；审查按新窗口中的临时持有报警，重写却把已落地日记改为仍拿着 |

合计 **3 次必要有效、10 次不必要尝试、1 次时间解释有争议且产生错误重写**。B1 head108 的修正不满足发布/收件人校验而回退原稿；head186 返回相同文字。其余 12 次实际改变文字。不能将 14 次尝试全部当成成功修复，也不能将 10 次不必要尝试全部当成成功发布了改稿。

自然表达损失有具体证据：B1 head210 原本已查看夹页和封底，重写把它改成“夹页、封底，我记着翻”，撤回了已叙述的正常查看行为。这个 Pack 不追踪翻页为受控交互，不需要先取得持有权才能翻桌上的书。

## 5. B2 的首次虚构、错误修正和误归链

| seq / head | 实际证据 | Jev / 系统行为 |
| --- | --- | --- |
| 218 | 正式取得日记，holder=陆舟 | 真实旧经历 |
| 281 | 正式放下日记，holder=null；287/299 已发布放下表达 | 后续没有再取得 |
| 322 | 程雨旁白“陆舟手里那本日记” | **第一次客观虚构漏掉**；发布前、影子都主要按 `SPEECH_NOW` 处理 |
| head327 → seq328 | 原稿“把日记放回台面”；新玩家窗口从 309 开始，旧释放在 281 | Jev 对陆舟选 `OBJECTIVE_DURING`、引用旧发布 287，但适配器按当前窗口报警。主模型改写为“手里还端着日记”，真实发布了与 World 冲突的新文本 |
| 334 / 351 | 程雨继续客观提及陆舟手里的日记 | 分别降为对白或无宣称，未拦截 |
| 375 / 381 / 393 | 回顾“陆舟拿过日记，后来放回台面” | 影子均连到虚构根 328，得到 `CHAIN_RECALL` |

影子确实发现了 seq328 的明确错误持有，但它并非第一次虚构；真实首次在 322。后续“拿过再放回”本身有 218→281 的正式证据，并不证明引用了 328 这次虚构。三条回述被连到 328 不能当作成功发现传播；这是**把成立的旧经历连到了错误来源**。其他对白对怀表经历的否认仍有问题，但不能借此把日记这部分正常历史也标成虚构。

这个例子分别暴露了语义分类、时间/来源选择及主模型修正问题。不能全部归因于 Jev 单个模型，也不能通过扩大到“历史上曾持有”来掩盖发生窗口。此次按约定没有加第二次审查、修正循环或记忆回写。

A1 的怀表虚构释放出现在 seq193、198、276，正式 holder 始终为程雨；三条都被影子检出。A2 seq301 的“没去接陆舟手里的日记”同样把真实已放下的日记写成仍持有，也被影子检出。同型问题在 B2 却漏掉，表现不稳定。

## 7. 决策

本轮总体不通过。保留现有影子审查作**可疑线索**，不把报警/归链作为权威结论，不默认开启自动纠错。暂停以同一提示词继续追赶边界案例；恢复记忆、角色交互和前端的产品主线。

如果以后重新评估自动纠错，本轮列出的正常桌面操作、首次客观虚构、回顾真实旧经历和错误改稿必须先得到独立验收。它们是未来明确的复现对象，不是本轮追加开发授权。当前不增加新的分类器、递归重写、World 写入或记忆修复机制。

证据目录：[holdout-2026-09-27](../experiments/jev-narrative-auditor/holdout-2026-09-27)。包含冻结输入与源码、64 次原始判断、全量四场事件/转录/干预/影子日志、178 条匿名复核、14 次干预审阅及一致性验证。没有完成独立人工复核；自动纠错已经失败，不需要以追加真人评分来延迟本次停止决定。
