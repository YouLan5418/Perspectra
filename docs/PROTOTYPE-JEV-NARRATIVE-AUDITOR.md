# Jev 叙事语义审查可行性实验

日期：2026-09-25。分支：`codex/jev-narrative-auditor-spike`，独立工作树：`D:/DeepSeek Harness/Perspectra Jev Auditor`。本实验只考察 Jev 能否把**指定受控物品的持有关系变化**在自然语言中的表达分成五类。没有修改生产运行链、World Event Log、Rulebook、Reaction 调度或发布路径；Jev 的输出不能创建世界事件。

## 1. 实验目的与样本

目标是识别旁白何时把物品转手写成已发生事实，以便未来由确定性世界事件核对。五分类为：无状态变化、意图、尝试、角色陈述、叙事事实。“角色陈述”包括对白、猜测、梦境、日记与回忆中的已完成声称；它不等于客观旁白。“叙事事实”只表示**文本宣称**发生了转移，不表示世界规则已经接受它。

首批 [`cases.json`](../experiments/jev-narrative-auditor/cases.json) 有 100 条人工构造并标注的中文样本，每类 20 条。看过首批结果后补充的 [`stress-cases.json`](../experiments/jev-narrative-auditor/stress-cases.json) 有 50 条难例，每类 10 条；这批是**自适应压力样本**，不能冒充预先封存的独立测试集。包含否定与条件句、意图和失败尝试、说谎与回忆、隐式终态、短暂转交并归还、多角色及多物品。统一目标物品是“黄铜钥匙”，角色多用甲乙丙；这种单一措辞分布限制了泛化判断。

## 2. Jev 配置与复现

使用 OpenRouter [Decisions API](https://openrouter.ai/blog/tutorials/how-to-use-jev/) 的 `POST /api/alpha/decisions`，固定 `typesafe/jev-1.13`，实际响应快照为 `typesafe/jev-1.13-20260917`。请求只含 `state` 与一个 `choice` 问题；五个中文候选标准定义在 [`run.mjs`](../experiments/jev-narrative-auditor/run.mjs)。不传 temperature、完整角色卡、记忆、世界书或历史剧情。第一组只传目标物品与文本；配对第二组再传当前持有者，但问题仍只要求判断文本如何声称，不能让当前状态替代语义判断。没有做提示词搜索或按结果修改分类标准。

30 条首批样本（每类 6 条）各重复调用 5 次。响应保存完整五项概率、所选分类、模型快照、耗时、token、API 实报费用及原始无凭据响应。原始 JSONL：`.tmp/jev-narrative-auditor-results.jsonl`；汇总：`.tmp/jev-narrative-auditor-summary.json`。两者为本地忽略文件。分支另保存了去掉原始响应体与请求 ID 的 [`450 次概率记录`](../experiments/jev-narrative-auditor/results-2026-09-25.jsonl)，仍含每次的五项概率、耗时、用量与费用，可直接复核。调用脚本可续跑已成功的条目；分析脚本为 [`analyze.mjs`](../experiments/jev-narrative-auditor/analyze.mjs)。Windows PowerShell 复现：

```powershell
$env:OPENROUTER_JEV_KEY = [Environment]::GetEnvironmentVariable('OPENROUTER_JEV_KEY', 'User')
node experiments/jev-narrative-auditor/run.mjs --mode text
node experiments/jev-narrative-auditor/run.mjs --mode holder
node experiments/jev-narrative-auditor/run.mjs --mode repeat
node experiments/jev-narrative-auditor/run.mjs --mode stress_text
node experiments/jev-narrative-auditor/run.mjs --mode stress_holder
node experiments/jev-narrative-auditor/analyze.mjs
# 仅使用已提交的去标识概率结果复核统计时：
node experiments/jev-narrative-auditor/analyze.mjs experiments/jev-narrative-auditor/results-2026-09-25.jsonl
```

## 3. 结果

下表的 150 条唯一样本是首批与后补难例的合计；准确率作为描述性结果展示。费用来自本次 API 响应的 `usage.cost`，不是当前目录价格推算。延迟在本机并发 4 条请求下测得，属于单次请求等待时间；若嵌入正式链路，尚需测端到端体验。

| 条件 | 五分类正确 | 叙事事实召回 | 叙事事实误报 | 角色陈述→叙事事实 | 单次延迟均值 / 中位 / P95 | 150 次输入 token / 费用 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 仅物品＋文本 | 144/150（96%） | 30/30 | 0/120 | 0/30 | 首批 374 / 324 / 780 ms；难例 424 / 325 / 968 ms | 102,470 / $0.00430374 |
| 再加当前持有者 | 144/150（96%） | 30/30 | 0/120 | 0/30 | 首批 372 / 328 / 709 ms；难例 398 / 337 / 799 ms | 109,820 / $0.00461244 |

两组 150 个配对样本的最高分类完全相同：当前持有者没有改善本次五分类。它增加了 7,350 个输入 token。首批一条明确“从这一刻起钥匙归乙保管”的事实，叙事事实概率由 0.92 降为 0.66；“甲把钥匙递给乙”由 0.82 降为 0.68。若先设 0.85 阈值，会漏掉这类已正确分类的事实。因此本实验**不设生产阈值**，也不能把 Jev 的 `confidence` 或单个概率当成经过本任务校准的错误率。

重复组：30 条各 5 次，共 150 次；30/30 条五次的最高分类完全一致，叙事事实概率的最大组内摆动为 0.03。重复组五分类正确 145/150，其中同一条“讲述另一个故事里的另一把钥匙”五次均稳定误判为角色陈述；稳定不等于正确。

450 次真实调用全部成功；合计输入 314,545 token、输出 30,859 token、API 实报费用约 $0.01321089。输出 token 记录于 API 用量，但这不是生成式叙事输出。平均每次费用约 $0.00002936。

### 错误与边界

只有六个独立错例，以下全部列出；两种上下文条件都错在相同分类。

| ID | 人工 → Jev | 主要含义 |
| --- | --- | --- |
| `none-07` | 无变化 → 意图 | “要不要给她？”是询问，Jev 当成转交意图。 |
| `none-20` | 无变化 → 角色陈述 | 角色讲述的是**另一把**钥匙的故事，Jev 受嵌套叙事影响；五次重复均犯同一错。 |
| `stress-无状态变化-08` | 无变化 → 角色陈述 | 小说内的同名钥匙交接被当作角色陈述，但真实房间里的钥匙仍由甲持有。 |
| `stress-无状态变化-09` | 无变化 → 角色陈述 | “我的那把”只是乙的静态所有权说法，没有转移。 |
| `stress-意图-10` | 意图 → 角色陈述 | 乙“盼望”未来转交，被归入广义主观陈述。 |
| `stress-角色陈述-05` | 角色陈述 → 无变化 | 乙误以为已经持有，随后发现手空；Jev更重视最终否定。 |

这些错误都没有误报为“叙事事实”，但说明五分类的边界并非完全稳定，尤其是静态状态、主观叙述与未来意图。样本中 0 次误报/漏报**不能证明真实对话的误报/漏报为零**。此外，“叙事事实”概率在仅文本组的非事实样本中最高仍达 0.38，若未来只看概率而不看最高类别，也会遇到边界样本。

## 4. 事实对账与工程判断

**问题一（意图 vs 已发生）：**这 150 条构造样本中，30 条意图没有被判作叙事事实；30 条叙事事实都被识别。**问题二（角色声称 vs 旁白）：**30 条角色陈述没有被判作叙事事实，但有一条被判为无变化。以上是本样本证据，不是对开放式真实剧情的可靠性保证。

**问题三（能否替代双阶段生成）：**当前只能说“作为离线烟雾报警器值得继续验证”，不能说“足以替代 Action-First”。单次 Jev 请求在本机通常数百毫秒、单次费用约 $0.00003，但尚未测接入正式回合后的额外调用频率、端到端延迟、真实文本错误率，也未验证 Jev 命中后是否能可靠与**同一物品、同一接收人、同一轮**的正式事件对账。五分类本身不提供接收人 ID；仅检查“本轮有某个钥匙转移事件”可能错放与叙事不一致的转移。此次不新增事件抽取或语义审查到生产路径。

尝试使用既有 G3 私人试玩日志作真实文本复核时，自动审批拒绝将 NPC 原文发往 OpenRouter：当前授权覆盖 Jev 实验与密钥，但不明确覆盖这批具体私有内容外发。该调用没有执行；原始日志未写入本分支，也未发送给 Jev。需要用户明确授权后，才可在下一次实验中用经确认的日志做真实场景验证。当前实验只向 OpenRouter 发送了本分支人工构造的 150 条样本。

## 5. 验证范围

实际运行了 450 次真实 Jev Decisions API 调用，并检查了每次响应形状与五项概率；`node --check` 验证调用和分析脚本。未运行生产包完整测试，因为本分支没有修改生产代码；未进行在线拦截、修文、发布阻断、世界事件写入或真实日志外发。原 `main` 工作树及其未提交修改保持不变。
