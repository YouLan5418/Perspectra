# 原生记忆检索起步实验：关键词基线与离线语义候选

日期：2026-09-28；Perspectra V1 当前实验工作树。本轮只新增独立实验入口，没有接入正式 Character Turn 或更改生产 Memory。与 Hindsight 影子实验使用同类合成事件，但候选由本项目脚本自行生成和排序；不启动、不调用 Hindsight 服务，也不导入其代码。

## 实验设置

原生基线入口：tests/experiments/native-memory-baseline.ts。它创建新世界、新 memory.sqlite，向 NPC 提供亲见鲍勃取得杯子的观察、随后鲍勃“已经交给玩家”的说法；仅鲍勃能获知暗号“深海灯”；NPC 的私语测试问句不包含暗号本身。鲍勃离场后的放杯事件不向 NPC 投递观察，再插入 18 条雨天对话。入口从现有 CognitiveMemoryService 与该角色 cognitive_memory_v2_sources 读取已授权来源，并保存 source ID、序号、哈希、认识类型和原文。11 个预标注问题覆盖直接问法、同义改写、间接指代、传闻、本人私语、他人私语、未观察的后续事件、承诺是否履行和无关问题。标签表示可用于回答的来源；无答案时“有候选”仅记录噪声，不等同于角色已经作出错误回答。

离线语义入口：tests/experiments/native-semantic-probe.py。它只使用 numpy、tokenizers、onnxruntime，对上述角色来源用本地 intfloat/multilingual-e5-small ONNX 权重编码，做 query/passage 前缀、mask mean pooling、归一化余弦排序。模型文件沿用上一轮实验留下的本地缓存，程序未依赖 Hindsight 实现；Python 和模型都未进入产品运行依赖。原始输出位于 .tmp/native-memory-baseline-20260928-run7/report.json、sources.json、semantic-probe.json。

## 证据 → 发现 → 下一步

| 证据 | 发现 | 下一步 |
| --- | --- | --- |
| 关键词召回 7 个有答案问题命中 5 个；同义“喝水用的器皿”和间接“桌上被拿走的东西”均为空，修门承诺的两种问法都命中。离线语义排序在同 7 题把正确来源全部排第 1。 | 语义候选确实补上该合成场景的两类漏召回；收益来自本地嵌入检索思路，不需要 Hindsight 后端。 | 扩充到不同物品、人物、承诺和真实试玩语料，避免以一个杯子场景选择生产算法。 |
| NPC 的来源集合 21 条、不含鲍勃私语；鲍勃集合 1 条、含私语。语义探针只在各自集合排序，NPC 结果无暗号；原生基线世界 headSeq 保持 36。早期序号查询未返回未来来源。 | 宿主先筛角色可见来源的边界可沿用；这次只证明脚本用该边界，尚未证明生产语义索引的写入与查询隔离。 | 生产切片必须用现有世界地址、角色、as-of 序号和来源身份重新核验候选。 |
| 无答案“鲍勃离场后把杯子放在哪”在关键词基线返回取得与说法两条旧来源；语义首位亲见取得的相似度约 0.905，高于部分有答案题约 0.848–0.864。“门锁现在修好了吗”只存在修门承诺，关键词返回 10 条候选、语义首位仍是承诺（约 0.870）；不在问句提供暗号的 NPC 私语未知题，关键词返回两条杯子旧来源，语义首位仍是无关说法（约 0.887），均未包含暗号。 | 排名和相似度只表达主题接近，不证明来源足以回答问题；通用硬阈值会误收或误杀。 | 将“找候选”和“证据足以回答”分开验收；正式角色请求暂不消费新候选。 |
| 传闻题语义首位是 event:14、修门承诺题首位是 event:16，均标 reported_speech；取得题首位 event:13，标 observed_action。 | 来源类型可原样保留，不必借用 Hindsight 的 world fact 分类。 | 后续组合候选时保留原文、来源 ID/hash 和认识类型；检查角色实际叙事不把说法当成交接。 |

本轮只测来源检索和候选排序，没有让 Gemini 3.7 Flash 或完整 Character Turn 消费新结果，也没有验证长期行为变化。11 题来自单一合成世界，不能据此选相似度阈值、宣称体验改善或启用生产语义索引。下一切片应扩大样本并解决证据充足性，再决定是否引入 TypeScript 端嵌入运行时；不为探针直接把 Python 环境带入应用。
