# 原生角色记忆演进：从 Hindsight 提取机制

日期：2026-09-28。本文是 Perspectra V1 的实施方向，不表示功能已交付。Hindsight 只作为设计参考与受控对照；正式运行时不依赖其 API、PostgreSQL 或代码。实验事实见 PROTOTYPE-HINDSIGHT-SHADOW-2026-09-28.md。

## 1. 问题与现状

真实试玩表明，记忆虽然能写入并进入角色请求，旧私下约定仍不能稳定影响后续主动行为。受控影子实验表明，现有关键词召回漏掉“喝水用的器皿”对杯子的改写，Hindsight 语义检索找到对应亲见来源；但对无答案私语问题，它也返回高分无关内容。这个单一正反例不足以决定算法、阈值或上线。

现有 CognitiveMemoryService 和 LocalMemoryStore 已具备按角色可见视图捕获、世界地址与角色分区、as-of 序号限制、来源引用、亲见与听说区分、关键词索引、自动及主动召回。原生改进应落在这条链路，不重建 Memory Bank。Event Log/Rulebook 仍是权威世界事实唯一来源；检索或归纳不能将对白升格成物品归属、位置等已裁定状态。

## 2. 机制取舍

| 参考机制 | 决定 | 本项目落点 |
| --- | --- | --- |
| 关键词与语义候选互补 | 优先评估 | 只在该角色已捕获的来源中生成候选，沿用现有召回入口与来源对象 |
| 来源引用与证据聚合 | 保留思想 | 派生内容回指该角色可见的原始来源；“某人说过”保持为说法 |
| 相关记忆归纳 | 等行为证据 | 若相关来源已进入请求而行为仍不变，再考虑复用现有主观 claim/goal 投影 |
| 多路排序 | 作为对照方法 | 比较关键词、语义、组合的来源命中与无答案误供给，不照搬图索引或固定分数 |
| 时间与矛盾 | 使用世界 tick 和观察序号 | 区分发生与获知；来源没有发生时间时保持未知，冲突说法并存且带来源 |
| Reflect、world facts、共享 tags | 暂不采用 | Character Turn 自己决定行动；派生事实不替代世界裁定；不共享角色检索空间 |

“复用”指借鉴机制思路，不复制 Hindsight 代码、协议或默认事实分类。其 world memory 不是 Cordis World 的权威 World Event。

## 3. 分阶段实施与验收

### A. 固定只读评估集

从已有合成场景与真实试玩缺口取直接问法、同义改写、间接指代、亲见与传闻冲突、他人私语、完全无答案六类问题。每题标出该角色允许的来源、应优先来源和可答性。记录来源命中、无答案误供给、真实模型回答、成本与延迟；现有召回为基线。只用新实验目录，不触碰 D:/worlds 历史数据。

### B. 经 A 证实收益后，原生实现语义候选

候选索引只包含 CharacterViewBuilder/CognitiveMemoryService 已捕获的来源和其派生表示。按现有 (WorldAddress, CharacterId) 与 asOfWorldSeq 查询；返回前从 LocalMemoryStore 复核来源身份与可见性。与 CJK 关键词结果合并、去重，保留 epistemicKind、原文和来源时间。相似度不能单独证明角色知道，证据不足时允许不提供记忆。先影子比较，再让真实 Character Turn 在受控场景消费。验收改写命中、无答案克制、传闻不升格、私语不泄漏、as-of 限制及世界状态未变。派生索引可重建，新通道可关闭；不迁移原始来源。具体嵌入模型和索引方式由 A 的数据量、精度及延迟决定，不预设新数据库。

### C. 按行为失败类型推进长期认知

如果相关来源未进入请求，继续修召回；如果已经进入而角色仍忘记承诺，才试来源支持的主观认知更新。Episode 可先从现有来源生成可追溯的场景摘要；只有原始条目与上下文预算形成真实负担时才持久化。Relationship、Reflection、记忆图与自动遗忘均等连续试玩证据，不一次建设。

## 4. 不变量与已接受限制

角色只能检索自己的来源，且不能越过世界 as-of 前缀。索引、词典、全局统计或模型调用不能把私语带给其他角色。亲见、别人声称、自己推断必须在返回内容中保持区分。未经裁定的叙事不能改变权威状态；角色是否持续相信虚构叙事仍须真实试玩验证，数据库不变不足以证明体验正确。

当前不做全自动事实抽取、图遍历、跨角色共享知识、现实时间衰减或通用语义裁判。已有 sourceAgeTicks 只证明时间信息到达模型，尚未证明稳定改善行为。

## 2026-09-28 起步证据

已运行原生关键词基线和独立离线语义探针，详见 PROTOTYPE-NATIVE-MEMORY-BASELINE-2026-09-28.md。单一合成世界的 7 个有答案题中，关键词命中 5 个，语义首位命中 7 个；无答案的未观察放杯题语义相似度仍高达约 0.905。阶段 A 已有首组可复现实验，但样本与“证据足以回答”的判定仍不足，阶段 B 未进入正式角色链路。
