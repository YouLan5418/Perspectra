The latest portable build is **0.1.0-test3**, published as a [GitHub pre-release](https://github.com/YouLan5418/Perspectra/releases/tag/v0.1.0-test3). It predates the launcher redesign, model connections and creator page added from 2026-10-15; those can only be tried from source.

`current/` holds current conclusions, `experiments/` holds experimental evidence, and `archive/` keeps historical work. An old document's "completed" only applies to the version it described.

**Language coverage:** the README, product vision, project status and this index are in English. Detailed implementation and creator guides are mainly in Chinese.
