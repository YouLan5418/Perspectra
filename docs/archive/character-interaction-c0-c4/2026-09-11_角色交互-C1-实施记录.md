## 3. 已实现行为

玩家通过显式 `interact` 提交 `core:hold-hand`。Host 根据 PlayerBinding 派生即时裁决上下文；Rulebook 重验角色、目标、位置、active Scene 和关系状态。成功后提交 `character.relation-started`，不附加目标心理、同意或未来行为语义。

参与者可以在后续 Action 或 Reaction Wave 中使用 `core:release-hand`。成功移动会在同一 Resolution 追加 `participant_moved` 结束事件。公开 Observation 包含关系参与者、开始/结束与原因，省略 relationId 和 sourceActionId。可执行的 relationId 仅在参与者的 Affordance 中枚举。

Manifest v9 支持完整可选 Player Input Policy 形状，但当前激活 `player-intent/v1` 会明确失败，等待 C3 耐久解释器。

## 4. 未关闭项

- C0 的真实 Provider 20-call 门禁未运行，不能据工程测试宣称真实模型通过。
