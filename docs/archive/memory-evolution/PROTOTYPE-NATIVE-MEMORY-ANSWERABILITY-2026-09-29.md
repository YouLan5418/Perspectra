# 原生记忆检索：双物品与回答充分性实验

日期：2026-09-29。基线 main 543b680；工作分支 codex/native-memory-evidence。本轮只扩展实验入口与报告，未改正式 Memory 或 Character Turn。

## 问题与方法

上一组单杯实验显示：语义候选能补同义漏召回，也会给无答案问题排出高分相关来源。这轮在新建合成世界加入第二只受控杯子。鲍勃取得白瓷杯，玩家取得银色茶杯；NPC 分别观察到已裁定的取得动作，之后听到玩家声称已把银色茶杯交给鲍勃。鲍勃没有收到这两条观察。17 题分成 10 题有明确来源、6 题缺少可回答证据、1 题指代含糊。题目只询问来源能证明的最初保管，不把“从桌上拿走”或“后来仍持有”当作已知事实。

原生关键词基线由 [native-memory-baseline.ts](../../../tests/experiments/native-memory-baseline.ts) 生成；独立 ONNX 语义候选由 [native-semantic-probe.py](../../../tests/experiments/native-semantic-probe.py) 对各角色已捕获来源排序。完整数据在 .tmp/native-memory-baseline-20260929-run4/。Hindsight 服务与代码未参与本轮。

[native-memory-answerability-probe.ts](../../../tests/experiments/native-memory-answerability-probe.ts) 从同一批来源构造 9 组诊断题、共 18 份关键词/语义静态回答请求。每条候选复核该角色源文本或哈希、世界序号和角色可见性；金标区分 answer、unknown、clarify。模型请求指定 gemini-3.7-flash，本机 8045 网关响应中的 model 字段为 gemini-3.7-flash-tiered。请求与结果不保存密钥。该固定提示只检验给定证据下的回答行为，不是生产提示词方案。

## 证据 → 发现 → 处理

| 证据 | 发现 | 处理 |
| --- | --- | --- |
| 关键词命中 8/10 个明确来源；语义候选 10/10 个目标来源排第 1。白瓷杯的同义改写是关键词漏召回。 | 这组明确指代的合成题支持语义候选补漏；不能推断开放世界总体精度。 | 保留角色内语义候选的原生实现方向，先在真实角色链路做影子验收。 |
| 6 个缺少可回答证据的问题仍得到高分语义候选。例如“鲍勃最后真的收到银色茶杯了吗”首位是玩家的口头说法，约 0.922；“离开后白瓷杯放在哪”首位是此前取得观察，约 0.921。 | 相似度不能证明后续事件发生。亲见与 reported_speech 的差别必须传到回答处。 | 不用通用分数阈值把候选升格为事实。 |
| 18 份真实模型回答中，语义组 9/9 符合这组题的 answer/unknown/clarify 金标；关键词组 7/9。关键词缺少同义来源时回答“无法确认”，缺少双杯候选时也无法指出歧义。 | 检索覆盖影响角色能否回答与澄清；在本次固定提示下，语义组没有把交付说法当成已完成转移，也没有泄漏另一角色的私语。 | 下一步在真实 Character Turn 中观察行为、措辞和成本，不能把静态问答当作连续角色扮演验收。 |
| 含糊题的语义前 5 项同时包含两只杯子的取得观察，模型指出白瓷杯与银色茶杯并请求澄清；关键词没有候选，只能说无法确认。 | “有多个可能对象”与“没有证据”是不同的交互结果。 | 真实试玩验收应包含角色主动澄清，而不只统计来源命中。 |
| NPC 有 23 条可见来源且无鲍勃私语；鲍勃仅有本人私语 1 条且无银色茶杯观察。旧世界序号检查未返回未来来源，世界 headSeq 为 39。 | 本次对各角色的现有视图单独排序，未见跨角色泄漏或权威世界状态变化。 | 原生接线须继续按角色与 as-of 限制候选，并复核来源；实验不证明尚不存在的生产索引已隔离。 |

首轮静态问答曾出现 1 次瞬时 fetch 失败；探针加入重试与按请求哈希续跑后完成全部 18 份。首轮两个问题错误地要求证明“从桌上”或“后来仍持有”，超出了来源；已收紧问法并重跑受影响请求。最终上述判断只依据修正后的 run4。

## 当前结论与边界

阶段 A 的合成证据支持进入**原生角色内语义候选的最小影子实现**，但不足以直接替换正式召回。应沿用现有 CognitiveMemoryService/LocalMemoryStore 的角色来源和可见性边界，先并排记录关键词与语义候选，再在少量真实 Character Turn 中观察是否补上遗忘、是否误信传闻、是否自然澄清含糊对象。暂不增加新的语义裁判、记忆图、数据库或兼容层。

这是同一合成世界上的 17 道检索题和 9 道静态回答题，每种候选只调用一次模型；没有连续试玩、成本/延迟评估或生产运行时验证。模型回应可能受固定提示和网关实际路由影响，9/9 不能解释为可靠率。

验证：17 题基线、离线 ONNX 排序、18 份本机模型回答均完成；TypeScript 类型检查、定向 oxlint 与 Python 语法检查通过。未运行完整测试套件，因为正式运行时代码未改。
