## 2. 中等问题闭合核对

| 项 | 审核结论 |
|---|---|
| M1 PACK_VERSION_DIVERGED 未接线 | ✅ 闭合。`WorldApplication.activate` 写入前经 `assertCompatibleContentPackVersion` 比较已存 `contentPack`（packId/packVersion/packHash），同身份异内容抛 `failWorld({ errorCode:'PACK_VERSION_DIVERGED' })`。因 `failWorld` 抛 `WorldError`，CLI 出口 `worldPackCliErrorEnvelope` 第一分支原样透传 canonical `ErrorEnvelope`，错误码一路保留到 stderr。creator-cli.test.ts 端到端覆盖该场景。 |
| M2 CLI 错误面硬编码 | ✅ 闭合。`worldPackCliErrorEnvelope` 三分支：`WorldError`→原信封、`WorldPackContractError`→经 `worldPackErrorCode` 映射并附 `details.diagnostics`（含 severity/code/file/jsonPointer/message/suggestion）、其余→`INVALID_REQUEST` 且未知错误返回通用 `'worldpack command failed'` 不泄漏本机路径；出口统一 `canonicalizeWorldJson`。creator-cli.test.ts 矩阵覆盖契约/无建议/WorldError/用法/未知异常。 |
| M3 envelope 加字段未升版本 | ✅ 收口。ADR-0063 明确 `worldpack/v1` 必填字段集（含 entities）在 `v0.2.0` Tag 前冻结；Tag 后新增必填字段必须升级格式版本。不承诺兼容审查前生成但从未发布的临时制品。 |
| M4 schemaVersion 作行为开关 | ✅ 闭合。Manifest v3 `contentPack` 新增必填 `runtimeCapabilities.publicSpeechObservationVersion: 1`；`RoundCoordinator` 改读该能力字段，不再读 `schemaVersion`。`contentPackBinding` 对所有 v3 pack 写死该能力，行为与此前等价但已解耦为显式声明，为未来选择留扩展点。ADR-0063 显式 supersede ADR-0062 中"以 schemaVersion 选择公开对白行为"的实现方式。 |
| M5 kernel v3 浅校验 | ✅ 闭合。`runtimeManifestFromStored` 对 contentPack 做元素级深校验：compiler 五字段 exactKeys+textAt+canonicalJsonVersion 精确匹配；pluginLocks 逐项 exactKeys+hashAt+kind 唯一；runtimeCapabilities 值必须===1；presentation schemaVersion/locale/style 精确；initialFacts factId+audience 唯一。world-spec.test.ts 新增 20+ 嵌套畸形矩阵。 |
