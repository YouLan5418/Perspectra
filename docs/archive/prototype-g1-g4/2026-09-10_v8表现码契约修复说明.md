# 2026-09-10 v8 表现码契约修复说明

## 问题与修复

真实试玩发现，模型看到的表现 schema 允许正式校验器拒绝的组合，导致整条提案被拒。修复同时适用于 Manifest v7/v8 对应的 submit_actions/v4/v5，不修改 ADR-0085 的失败语义或历史世界事实。

`packages/contracts/src/action-group.ts` 从 `ACTION_GROUP_CUES` 派生逐动作 JSON Schema。Application 工具契约与网页试玩共用该生成函数：

| 字段 | 约束 |
| --- | --- |
| independent | 仅五个无动作绑定码 |
| speak.onSuccess | 无绑定码及 quiet_voice、trembling_voice |
| move.onSuccess | 无绑定码及 slow_walk |
| take/interact.onSuccess | 仅无绑定码 |
| 两数组合计 | 至少一个码，不能重复；无表现时省略 manifestation |

网页 renderer 升为 `grouped-playtest/v2`。DeepSeek 路径仍通过消息提供 schema，并非供应商强制结构化输出；因此不能承诺模型绝不出错，正式校验器仍为必经边界。

## 失败证据

`*.invalid.json` 新增具体 `validationError`、最多 65,536 个字符的 `rawOutput` 和截断标记。只保存已解析的输出正文，不保存整个供应商对象、请求认证头或思考内容。供应商响应无法解析时 rawOutput 为 null。诊断文本不进入世界事实、Observation 或 Memory。

原试玩记录中的失败次数是历史观测；重放产生的样例只能证明问题可复现，不能当作历史失败原文。旧证据不补造、不回写。

## 验证范围

- 使用 Ajv 与正式 SubmitActionsValidator 比较每个表现码的三种位置（缺省、independent、onSuccess），覆盖两版协议每类动作的全部 3^8 种组合，以及重复、未知码与省略表现。
- 真实 Application 根轮/Reaction 验证共享工具契约；网页运行时通过模拟 DeepSeek 响应验证成功路径、拒绝原文、JSON 错误和截断证据。
- 上述一致性结论限定于表现字段；动作 ID 的跨项唯一性、Reflection 权限以及执行时世界状态规则仍由正式校验与裁定负责，不宣称整个输出 schema 等价于运行时授权。
- 本次没有调用真实付费模型，修复后的实际拒绝率需后续试玩观测。

验证结果：`corepack pnpm@11.7.0 check` 退出码 0；968 个覆盖率测试通过，生产 src 逐文件四项覆盖率均达 100%，P0–P6、3 个性能测试和 39 个硬终止恢复测试通过。Lint 有一条既有测试代码的 optional chaining 警告，不影响门禁通过。

## Evidence → Finding → Path

真实试玩记录及 schema/校验器对照 → 模型 schema 比正式表现契约宽松，旧测试仅覆盖成功输入 → 共享生成函数、穷举一致性测试、失败原文留存，再进行真实试玩复核。
