## 3. 当前玩法与记忆路径

创作者可在包内脚本定义变量、临时活动权限、阶段、轮次与主持人玩法。宿主继续约束模型契约、玩家入口、提案检查与最终执行，提供创作者不能屏蔽的逃生。普通对白不能直接改变追踪中的游戏结果；模型混合提交非法字段时仍整包拒绝。

网页默认使用原生记忆。只有 `--memory-core` 明确启用时，自动和主动召回都经过实验核心：

```text
角色自己的授权 Source 前缀
  → Event Atom → Episode → Observation
  → Retrieval Projection / 多路检索
  → Delivery Projection（最多三项）
  → 真实 Character Turn
```

宿主负责从 CognitiveMemoryService 读取角色已授权来源与时间，Python 不接收世界库路径、完整世界状态、其他角色来源、活动私有状态或包变量。主持人的当轮私有答案仍由宿主直接授权，不因为主持人知道答案就擅自加入长期来源。六字段追溯与“说过不等于做过”的边界保持，新派生记忆不提交为权威世界事实。

“整理长期记忆”是宿主手动维护按钮。它复用已校验的旧 Atom、提炼新增 Source，在完整前缀上重建 Episode、Observation 和索引。首次整理前长期交付为空，近期上下文正常。当前不自动每五回合整理，不暗中在普通发言中启动大批模型调用。取消或失败后已完成的角色缓存保留，其余使用旧缓存；逃生可取消在途整理并恢复输入。

重启从该角色自己的缓存和授权请求记录恢复姓名线索。私有请求、模型返回和召回 trace 存在存档 `memory-core/`，不会通过玩家状态接口公开。

## 4. 独立复现

核心代码在 `experiments/hindsight-core`，活动适配在 `experiments/activity-memory`。Python 依赖固定版本，E5 资产由固定 revision 与六个 SHA256 描述，准备脚本会校验。Python 与权重不进入 Git，新机器仍需安装依赖并下载模型；这不等于已经生成自包含二进制。

具体安装与启动命令见 [活动记忆说明](../../../experiments/activity-memory/README.md)。只支持本机 OpenAI 兼容服务的源码网页 Core 开关，默认 Gemini 3.7 Flash。桌面发布版尚未打包 Core、Python 或 E5 环境；原生网页和桌面路径继续可用。

## 6. 有意识接受的限制

- Core 是可选实验，main 仅接入独立房间修复；本次不推送远端、不发布桌面包。
- 整理耗时和模型成本仍明显，当前手动触发，整次维护最多十分钟。
- 严格 Observation 门槛不变，承诺生命周期、关系摘要与生成认识的结构约束仍待真实试玩证明需要后再做。
- 主持人可能提交非法混合输出，程序会拒绝；不把程序状态安全等同于自由对白语义已完全正确。
- 历史世界和旧试玩目录保持只读；新冒烟使用新的 `.tmp/web-core-integration-20261003-v1`。
