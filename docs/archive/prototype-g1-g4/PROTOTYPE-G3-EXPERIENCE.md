# G3 真实体验验证：连续世界与观察口径

状态：第一组 20 句连续样本已完成，结论见[第一组 G3 报告](PROTOTYPE-G3-PLAYTEST-01.md)：**G3 尚未通过**。以下仍是复验与续玩时使用的固定流程。

后续已完成 [移动观察与网页反馈验证](PROTOTYPE-G3-MOVEMENT-01.md) 以及一次不预设台词和交互顺序的 [开放式连续试玩](PROTOTYPE-G3-FREE-PLAY-01.md)。后者再次发现受控钥匙交接被自由叙述虚构并传播；两次自然复合移动输入因解释顺序无效而未提交。G3 未通过的结论不变。

世界包固定为 [`examples/world-packs/prototype-g1`](../../../examples/world-packs/prototype-g1)：玩家、同行者、留守者；前室与后室；黄铜钥匙；创作者声明的握手。G1 组合测试已验证它的机械路径。G3 在此基础上检查真实模型的角色自然度与叙事连续性，不因 G1 自动化通过而预设 G3 通过。

使用 [`prototype-g3-run.ts`](../../../tests/experiments/prototype-g3-run.ts) 的 20 句固定输入，在**同一个存档**中先运行到第 8 句并审阅，再继续到第 20 句。第二次执行时仍用原数据目录；脚本会核对当前世界 Head 与上一个已记录回合是否一致，拒绝从不明确的中断点自动续跑。日志只保存在 `.tmp`，记录请求的模型、角色可见上下文、响应、回合转录与错误；不记录请求头或凭证。

```powershell
node --import tsx tests/experiments/prototype-g3-run.ts .tmp/g3-next-run 8
node --import tsx tests/experiments/prototype-g3-run.ts .tmp/g3-next-run 20
```

按回合记录四类现象：玩家输入是否被无关澄清拦住；NPC 是否自然地选择表达、执行或 abstain；行动前后是否遵守实际执行结果、当前物品与位置；留在前室者是否把后室未见之事当成亲眼所见。尤其保留失败原文、相应请求上下文与 Event 序号；自由叙述虚构关键状态即使没有写入数据库，也记为体验分叉。一次样本不作为统计可靠性证明。

这 20 句覆盖纯表现、普通问答、钥匙竞争、自然握手请求、跨房间、低声交流、返回后询问所见，以及对钥匙归属的错误说法。模型能否把低声交流约束在实际受众内，需要同时看发布受众与接收者后续上下文；输入文字中的“低声”本身不授予私密频道。契约 T6 的人工格式故障、T7 的打断与 T8 的中途重启需要在连续样本的安全检查点另做并明确标注注入，不混入自然失败率；本轮准备脚本并未声称这些体验项已通过。

G2-1 格式修正与 G2-2 有界非法输出诊断已列入 [G1/G2 验收记录](PROTOTYPE-G1-G2-ACCEPTANCE.md)待办，不在 G3 前先扩展框架。G3 的具体体验问题先用证据定位，再决定是否改上下文、角色指令或调度；此阶段不启动旧代码的大规模删除。
