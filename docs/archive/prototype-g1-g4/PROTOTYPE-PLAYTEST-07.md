# 第七轮：abstain 与非语言表达的语义

日期：2026-09-20。保留第六轮自身历史呈现、人设及最小旁观表现规则，只明确工具描述中的选择语义。默认预算对照后，另做扩大预算实验。结论：系统能够区分 A/B，但本轮真实模型没有选择 A；扩大预算后的自然终止也不是主动 abstain。

## 唯一保留的运行时改动

`packages/provider-chat/src/wire.ts` 的工具描述明确：

- 被唤醒只是处理信息的机会，不是要求表演回应；角色自行决定是否补充或行动。
- A：决定不再补充且不行动，返回 `{"schemaVersion":7,"decision":"abstain","actions":[]}`，不发布表达，也无需用等待或沉默的描写代替。
- B：决定用沉默、注视、微笑等传达回应，返回 act，通过 narration 发布，有权观察者仍可感知。
- 先前表达不会因 abstain 消失；不替模型判断当前是否有值得回应的新内容。

未改输出 Schema、裁定、观察权限、调度资格或人物内容。B 正常发布与“B 必然唤醒每个旁观者”不同；第四轮最小规则仍有效。

默认组 GPT 连续使用无声表现，Claude、DeepSeek 等继续说话，没有空行动。扩大组同样所有角色响应均为 act；GPT 在 Root 加六波共七次调用中持续发布非语言表达。

### 扩大预算究竟如何结束

临时上限：波数 3→6，Reaction 总调用 8→24，每角色 Reaction 调用 2→6，周期截止时间 30→120 秒。每波实际调用数：4、4、3、3、3、1，总计 18，未耗尽 24 次总调用。

- 第一波 GLM 移动至工作区，之后卧室里的交流不会继续向它提供新观察。
- 第四波 DeepSeek 移动至客厅；第五波处理移动前已收到的信息。
- 第五波 Claude 仍发布对白，GPT 继续以手势回应。
- 第六波只有 GPT 被唤醒，响应 Claude 的上一条对白，又发布一段无声表达。
- 最后一段纯表现不产生旁观者新候选，因此 quiescent。代码在无候选时先判断 quiescent/all_abstained，随后才检查波数上限；本次不是 wave_limit，也没有 all_abstained。

最后 GPT 的表达大意仍是“我在这儿，站在你这边，等你决定下一步”。它选择了 B，而不是 A。不能用周期结束证明 abstain 提示已经奏效。

## 扩大预算的失败尝试与恢复

扩大组首次尝试（目录 `abstain-semantics-extended-20260920`）在 Root 提交时被存储校验的 maxWaves≤3 拒绝；第二次（后缀 `-b`）被 SQL CHECK 的同一限制拒绝。两次各产生 5 次模型请求，但未进入 Reaction，不能纳入上表行为对照。保留失败记录。

随后对齐调度常量、存储数值范围及新建库 SQL 的三项上限，使用第三个全新目录完成实验。没有关闭原子事务、信息隔离或其他校验，没有迁移或改写历史数据库。

实验后所有临时上限均恢复；reaction-cycle.ts 与 world-store.ts 无残留 diff，round-coordinator.ts 只保留此前已交付的旁观表现规则。扩大组数据库含超出默认协议范围的实验值，仅用 SQLite 只读查询复核，不作为当前默认运行时可续玩的存档。复现扩大组需按上述条件重新临时设置上限并使用新目录。

## 验证与结论边界

- Wire 与 Frozen runtime 两组共 19 个相关测试通过。
- 新增集成测试：两名角色先发表对白，后续均 abstain，只有两条既有对白，周期 all_abstained，没有下一波调用。原有 B 测试验证纯表现仍发布可见，并可让缺少新候选的周期 quiescent。
- 默认 check 通过：类型、Lint、9 个核心测试；既有 grouped-runtime.test.ts:25 警告保留。
- 未运行旧全量、覆盖率、硬终止或长会话测试。

这次仅能确认：提示明确区分 A/B、系统两条路径工作正常，但两个有效真实模型样本中仍没有主动 abstain。不能进一步断言模型完全不理解：它可能理解选项，却持续认为存在值得表达的内容。当前输入本身也明确请求非语言回应，角色和场景持续提出新话题，仍是内容上的混杂因素。

若继续观察，适合增加明确对话已收束、没有新问题或直接请求的短场景，保持这版指令及默认预算，检查 abstain 是否会出现；不要直接继续堆叠强制沉默规则。本轮没有再修改其他机制。
