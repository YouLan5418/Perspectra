# 第十二轮：通用单角色激活接入

日期：2026-09-23。原型网页试玩默认使用单角色激活：玩家输入先经原有解释与 World Event Log 提交；获得本次刺激的 NPC 依次决定 `perform`、`publish` 或 `abstain`。`perform` 由现有 Rulebook 裁定并提交，同一角色立即收到已提交结果及更新后的授权场景，再选择一次自由表达或不回应。角色、交互定义与移动目的地均来自当前 World Pack 和可尝试选项，没有 GPT 专用分支。

## 改动边界

- `PrototypeCharacterTurn` 仍承担一名 NPC 的提案、裁定、提交与结果续写。每次激活最多一次重要交互，两次模型调用；纯表达或不回应只用一次。
- 原型网页入口新增一个内存中的有界激活循环：最多三波、八次 NPC 模型调用、每名角色最多两次激活；发起激活前预留两次调用，避免已提交的重要动作因全局预算用尽而失去结果续写机会。未完成的调度在中断后可丢弃，已提交事件仍有效。
- 候选只来自本次玩家输入和上一波已提交的角色观察。普通无明确对象的纯非语言表现仍能被观察，但不单独唤醒旁观者。下一波使用实际提交结果，避免把同一波尚未提交的提案当作新事实。
- 移动成功后把来源和目的场景的有权观察者纳入移动观察；续写在新位置生成。带明确交流对象的对白映射为现有 `direct` 发布范围，并拒绝指定当前不可见的对象。没有新增交互框架、数据库状态机或叙事审查器。
- 默认新存档启用这一路径。旧批量路径目前仅由测试及历史对照使用；它未迁移旧存档，也不成为新协议兼容承诺。

## 模型无关验证

网页服务集成测试使用新存档和本地脚本模型：Claude 提出拿取手机，提交后立即收到成功结果，才发布“手机拿到了”；随后 DeepSeek 提出移动，实际到工作区后才发布“我到工作区了”。调用顺序为 Claude 决策 → Claude 续写 → DeepSeek 决策 → DeepSeek 续写。玩家不在工作区时不收到 DeepSeek 的异地续写。测试还检查四名角色分别只发布普通点头时，四次激活后结束，不额外开波次。

单角色集成测试覆盖成功、拒绝、移动后刷新场景、授权观察隔离、取消未提交提案、纯表达及指定可见交流对象。两文件相关测试 29 项通过。`corepack pnpm@11.7.0 check` 的类型检查、Lint 与 35 项核心测试通过；Lint 仍有既有 grouped-runtime optional chaining 警告。本轮没有运行全量覆盖率、旧全量协议测试或硬崩溃测试。

## DeepSeek 四步短场景

新数据目录 `.tmp/generic-activation-20260922/`，驱动 `.tmp/generic-activation.ts`，模型 `deepseek-flash`；通过现有网页 HTTP 提交自然输入。记录含请求、响应、每轮状态和 SQLite，不含凭据。服务已关闭。

1. 玩家请 Claude 拿手机。Claude 真正拿起卧室手机（seq110），同次激活的下一次模型调用看到成功结果并发布回应；第一轮总共七次 NPC 调用，到预算边界结束。
2. 玩家请 DeepSeek 去工作区。DeepSeek 真正移动（seq174），随后的模型调用在工作区上下文里续写；第二轮亦为七次 NPC 调用。
3. 玩家走到工作区（seq207）。第三轮，GLM 自主移动到工作区（seq240）。其后的模型输出同时包含对白与 `addresseeIds: [character:deepseek]`；原型最初按公开对白提交，规则拒绝该表达（seq250），但移动保留。网页准确提示“玩家输入已提交；部分角色处理失败”。
4. 第三轮失败后按驱动的停止条件没有提交第四句。修正寻址映射后，在同一存档对**已提交的那次 GLM 移动**单独重试一次结果续写：模型输出成功提交为 seq256，观察写给工作区的 DeepSeek、GLM 和玩家（seq258–260），没有重复移动。此为针对性续写复测，不能算完整四步连续试玩重新通过。

首次失败记录没有抹掉；两段证据分别保存在 `requests.json` / `responses.json` / `turns.json` 和 `retry-glm-requests.json` / `retry-glm-responses.json`。这次接线缺口已有可见交流对象的回归测试。

## G1 与 G3 状态

通用激活的执行时序、裁定边界和非 GPT 的物品/移动路径已具备原型级证据；`perform` 失败后仍能给同一角色结果的集成测试也已覆盖。契约中的完整 G1 固定小世界与全部 P-01～P-08 尚未逐项验收，不能宣告整个 G1 Gate 通过。

自由叙述仍可能声称没有执行过的物品转移或移动，其他角色仍可能相信这些说法。把它继续列为 G3 连续试玩的体验风险，不把“永远杜绝模型错误宣称”设成 G1 的无限期前置条件。下一步更有价值的是在固定两房间、两角色、关键物品的短场景中做连续验收，重点核对执行结果后的即时表达、旁观者实际观察、位置与归属；根据可复现体验缺陷再决定是否调整。
