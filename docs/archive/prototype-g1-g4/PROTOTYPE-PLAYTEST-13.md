# 第十三轮：两 NPC、同物品与跨房间连续试玩

日期：2026-09-23。本轮只做世界内容的临时实验副本与真实模型试玩，未改生产代码、模型、人设协议或调度预算。目标是核对一段连续过程的执行结果、重新决策与跨场景观察；自由叙述分叉继续作为 G3 体验风险记录。

## 固定情境

从 `examples/world-packs/hand-in-hand` 复制出 `.tmp/g1-two-room-two-npc-pack/`：玩家、同行者、留守者；前室与后室；前室桌上的黄铜钥匙。后室起初是 `created` 场景，首次进入时按已有移动规则激活。该世界包已通过编译。副本仅用于此次试玩；它保留了原包的雨天记忆和部分角色表达材料，故雨天对白不能作为新场景文案质量的验收样本。

驱动 `.tmp/g1-continuous.ts` 使用现有网页 HTTP 提交，`deepseek-flash`，单一新存档 `.tmp/g1-continuous-20260923/`。该目录保留 `requests.json`、`responses.json`、`turns.json` 与 SQLite，不含凭据。共八句玩家输入、31 次 Provider 调用，全部 HTTP 200；八句都提交，无程序错误或玩家澄清。服务已关闭。

| 顺序 | 玩家输入意图 | 已提交事实与模型行为 |

## 验收边界

本样本支持一个连续的 G1 玩法闭环：选择重要交互、提交、同角色立即看到真实结果、他人依据当前可见状态重新决策、移动后按场景隔离观察、返回后继续对话。第三句验证的是留守者**主动不提出**已不可尝试的拿取；没有实际调用 Rulebook 拒绝一次越权拿取，不能把这一路径也写成实测通过。

观察边界只对本次具体世界和事件前缀成立。留守者知道同行者从前室离开，也在玩家返回后知道玩家在场；它没有收到后室 seq162 的对白内容。这区分了对“有人离开”的观察和对“另一个房间内部发生了什么”的观察。

自由叙述仍有一处不自然：玩家 seq167 **返回**前室后，留守者 seq179 却重复“你也要去后室？”。其当前场景已包含回来的玩家，但输入中的移动观察只标记 `move`，没有在该观察里直接说明方向。第八句的后续回答纠正了对观察范围的表述。这是 G3 的上下文/叙事连续性问题；本轮不扩大提示或调度约束，也不把它算成权威位置发生改变。

本轮验证为 World Pack 编译与真实模型连续试玩，并逐项对照模型实际请求、输出、World Event 和观察受众。未修改生产代码，未新增或运行自动化测试、覆盖率或硬终止测试。完整 G1 P-01～P-08 与 G3 自然度仍需各自的验收，不能因这一条短场景成功就宣告全部通过。
