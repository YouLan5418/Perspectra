## 已接通的玩法与边界

- 序章复用 Activity 模拟模型输出，112 条正式表达含 5 条中性玩家问题，经正常提交、观察与记忆流程；末句后交给玩家，未替玩家答应收留。
- 晚餐、私密交流、蛋糕与跨日回访有条件入口；后续决定由真实角色模型完成。使用占位角色与简单背景，没有食物分份、完整物理模拟或正式音效。
- 公开/定向/私密/仅自己表达沿现有权限路径；试玩包提供受众选择、加载状态与 Galgame 式授权历史。程序隔离不等于模型永不虚构。
- 多人处理保持串行、观察驱动与有界反应；每波当前在场候选随机排列，场外候选随后处理。默认 3 波、8 次调用、120 秒期限，可按包配置；没有持续后台自治。
- 模型支持 OpenAI 兼容、Anthropic Messages、Google Gemini 原生协议。实例可选择关闭/低/中/高思考强度，仅影响角色决策与结果续写；部分 Gemini 禁用关闭，网关行为和全部模型档位尚未逐一验收。
- 模型最终上下文合并授权观察与自身表达为 history，移除宿主追踪字段，动态信息放在历史之后。当前位置在 context.locationId；宿主原请求保留完整来源证据。文本共同前缀改善不能直接视为供应商缓存命中率。
- 重要移动、物品转移与机制状态仍经 Action / Rulebook / Event 提交。自由叙事与数据库事实可能出现语义矛盾，需要真实试玩分别检查。

## 记忆与故事线

Core 整理在排队前冻结角色授权 Source，后台运行时允许继续游玩，安装时复核世界版本及前缀。当前实验约 170k 估算上下文触发、整理较老约 120k、保留约 16k 原文重叠；不是供应商精确 tokenizer 或容量承诺。失败/取消保留已安装档案与原文。

完整节点保存世界、会话、变量、身份历史与当时已安装的长期档案；分叉只恢复该节点副本，校验角色、世界、时间和授权来源，不调用模型重建。旧节点缺少长期档案时使用截至节点的授权原文，无法精确恢复未保存的摘要。原线路未来保留，后续整理仍按正常阈值或手动操作触发。

单节点文件分享可导出并导入相同游戏包下的独立实例，排除 Core 档案、请求日志、模型配置与凭证；分享仍包含节点内私密世界历史。一次仅运行一条线路，完整树分享、线路合并和跨包迁移未实现。详见[故事线](storylines.md)。

末端回合重新生成复用相同输入和起点，固定长期档案、隔离执行候选，再整体选择世界与表达结果；下一次输入后关闭上一组切换。它与节点分叉、活动重试分别处理，见[重新生成](tail-round-regeneration.md)。
