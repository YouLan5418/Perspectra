# 当前受控交互

普通日常场景默认尽可能保持角色自由表达。创作者定义小游戏或关键机制时，可以在明确参与范围和生命周期内收紧能力；自由叙事与受控行为按场景共存。

当前活动 policy 可约束玩家及指定参与 NPC 的对白（自由、固定原文选项或关闭）、自由 narration、移动、普通交互白名单和游戏操作。它收窄已有能力或提供已注册包内操作，不能凭工具名获得宿主未安装的执行能力。未参与角色不自动继承限制。

模型契约、页面、提案校验和执行入口使用活动策略。resolve 决定合法状态变化，行动、阶段／换手与授权观察原子提交；正常结束或宿主逃生解除限制。角色可以不执行操作，技术失败不伪装为主动 pass。权威变化由系统提交，不能由自由文本声明。

宿主验证角色、阶段、参数与权限；具体玩法可以选择让主持模型作判断。`ai-girls-hosted-guess` 的主持人可能判断错误，事件如实记录“主持人裁决”，不会暗中把它改成程序核实的数字比较。

当前接受可信本地作者脚本，单活动、同步裁定和有界角色链；没有多活动叠加、恶意脚本沙箱或任意宿主能力扩展。允许自由对白仍不能保证模型不泄露自身秘密或不存在叙事越权。
