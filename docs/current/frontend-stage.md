## 数据契约与权限

最初舞台改造新增的公共字段是可选 `PlayerView.expression`：`speech` 为 `free / none / choices`，`speechChoices` 为允许发言列表，`narration` 为是否允许描写。来源是现有玩家活动视图的 `policy`，仅摘取这三个字段；无活跃限制时默认自由表达。它决定输入控件是否显示，宿主和活动规则仍在提交时验证。SDK 自动合并该字段，宿主补丁列表同步包含它；已有社区页面可忽略这个可选字段。

官方 iframe 发送临时 `frontend-reading` 消息，包含阅读门禁、历史是否打开、呈现模式与已接收历史的序列化内容串。宿主验证窗口、opaque origin、当前默认模板后，用它在未读期间收起活动卡片、不渲染后续操作，打开历史时暂时隐藏活动卡片。宿主通过原 MessagePort 发送仅包含 `activityOpen` 的 `presentation` 通知，协调三个呈现模式；不增加公共 HTTP 字段或能力。该消息不提交世界操作、不给予权限、不持久化；社区模板不受它控制。重新挂载时清除临时状态；中止入口始终可用。

可完全复用：授权场景、已发表转录、表达分段、公开活动状态、可用选项、参与者候选、活动参数校验、进程内请求去重、SSE、末端候选与重新生成，以及原有 iframe / MessagePort / CSP 和授权模式。两个引用默认样式的社区示例补上自己的布局，避免默认舞台样式变化挤压其聊天视图；官方 model-girls 的专用序章前端保留。

## 操作方法

- 点击对话框逐段阅读；空格或 Enter 在非编辑控件上推进。自动阅读按当前段长度等待，打开历史时暂停。
- “跳过”（原“跳到已提交末尾”）仅清空当前阅读队列；不会推进活动、发起模型调用或结束后台处理。
- 阅读时隐藏输入、收缩活动。读完后允许表达时进入回应模式：底部以对白摘要和输入区替换完整对话框，保留受众、外显描写和草稿。点击“回应”可在已读上下文与编辑之间切换。后台忙碌、未读或表达限制仍禁用对应提交。
- “行动”仅列出运行时返回的当前操作，包括活动开始、暂停、恢复和参与者选择。执行仍重新验证选项。
- 玩家主动展开活动卡片后进入活动操作模式：舞台在左、卡片在右，保留简洁对白上下文。收起后只显示名称、状态和回合；轮询、阶段变化与下次操作机会均不会自动打开。展开时依次显示名称和阶段、目标/说明、关键数值、合法操作及表单、当前操作反馈。暂停、恢复、重试角色、重试同一请求与中止逃生保持各自的原操作语义。旧临时布局切换整合为活动卡片展开与收起。
- 阅读游标不写存档。宿主“工具”菜单中的“重新加载界面”定位最后一条发表记录，早期记录留在历史里，不重新执行操作。候选替换从变化前缀之后重新阅读。整个浏览器页面刷新仍沿用原宿主限制：内存令牌丢失，须从 Launcher 重新进入或使用终端原始链接；本轮没有把令牌存到浏览器中。

## 有意识接受的缺口

历史已有授权观察的 `seq`，但公共 SSE 仍是最终视图补丁：没有每条阅读单元的场景成员和活动公开快照，也没有独立可播放的物品事件列表。未读时舞台保留先前展示的场景与活动公开状态，读完或跳过时采用最新授权快照；宿主即使先收到原始最终状态，也不能提前展示新结果。首次加载只能以当前快照为起点。候选替换清除旧候选的场景与活动展示。

这能防止阅读中的突变和后续活动结果抢跑，不能声称 NPC 在每个中途事件的精确阅读位置进出场。实现后者需要最小后端扩展：以玩家已授权的观察序号提供对应场景成员和活动公开状态，复用现有观察投影，不改变世界裁定。本轮未增加该契约；不会推测移动路径或解析自由叙事生成世界状态。

同一批缺口对插件形态表现能力（立绘差分、背景音乐、语音）的影响，以及不改内核时创作者能做到什么，整理在[前端表现插件的能力边界](studies/frontend-plugin-capability-boundary.md)。

左侧物品通知、背包、游戏时间、创作者声明式 UI、背景/立绘资源映射和独立存档菜单尚未接通。活动目标/说明使用既有公开字段；参数选择器识别现有 schema 的 `enum` 或带 `const`/`title` 的 `oneOf`，保留候选原值和类型。没有这些候选时保留合法的数字、文本与布尔表单，不假装世界包已有独立 UI 声明协议。复杂参数继续受原宿主表单支持范围限制，没有新增自动表单框架。恢复条件、存档分叉和 RPG/SLG 实际结算沿用运行时，本轮未做完整跨存档或长期真实模型验收。
