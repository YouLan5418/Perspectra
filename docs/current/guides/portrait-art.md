# 立绘与表情差分出图要求

2026-10-23 按当前源码整理。比如要给 Claude 画一张底图，再画一张 4×4 的表情拼合图，让她说话时能换成笑、害羞或生气：本文列出画布尺寸、对齐和命名要求。`stage.json` 的写法见[自定义前端指南](web-ui.md#官方默认界面布局)，标记取景和脸部框用创作者页面的「立绘标记」。

代码对像素尺寸没有硬性要求，任何尺寸都会按标记缩放。真正的限制只有文件大小：单个文件不超过 64 MiB，整个 `frontend/` 最多 2048 个文件、合计不超过 512 MiB。下文的尺寸是按舞台缩放规则算出的建议值，目的是让画面在常见屏幕上不发糊。

## 通用

- 格式用 PNG 或 WebP，背景透明。
- 图片都放在包的 `frontend/portraits/` 下，可以分子目录。
- 底图用角色 ID 冒号后的部分命名，例如 `character:claude` 的底图是 `portraits/claude.png`。

## 底图

舞台把头顶放在画面约 9% 高处，腰部放在约 78% 高处，腰部以下被对话框挡住或超出画面；手机竖屏分别是 20% 和 74%。所以立绘至少要画到腰部以下，清晰度取决于原图中“头顶到腰部”这一段有多少像素。下表按屏幕的物理像素计算，与系统缩放比例无关：

| 目标屏幕 | 头顶到腰部在屏幕上的像素 | 原图这一段建议 |
| --- | --- | --- |
| 1080p | 约 750 | 800 以上 |
| 1440p / 2K | 约 1000 | 1000 以上 |
| 4K | 约 1500 | 1500 以上 |

- 全身立绘的腰部一般在图片高度的 45%–50%，整张图约为“头顶到腰部”的 2.2 倍高。要兼顾 2K 屏幕，建议 2200–2600 像素高。
- 只画到大腿或膝盖的立绘约 1400–1800 像素高即可。
- 宽度不限。每个人物大约占舞台宽度的 26%（最多 34%），四人同时在场时会互相遮挡一点。头发和衣摆可以伸出去，身体主干最好居中、不要太宽。
- 头顶和腰部的位置用「立绘标记」拖出，不必画在固定位置。

## 三种差分

### 同尺寸图层

- 画布尺寸与底图完全相同。舞台会把它铺满底图，尺寸不同就会变形。
- 只画变化的部分，其余透明，并与底图逐像素对齐。
- 三种格式里这种最不容易出错，代价是每张文件都和底图一样大。

### 局部贴片

- 贴片会被拉伸到脸部框的大小，宽高比必须和框一致。
- 尺寸与底图保持 1:1：`框宽比例 × 底图宽`、`框高比例 × 底图高`。例如底图 1600×3000、框宽高为 0.14 和 0.09，贴片约 224×270。
- 贴片是盖在底图上的，不会擦掉底下原来的脸：要么贴片完全不透明、整块盖住原五官，要么把底图画成无五官的版本。
- 边缘带一点周围的皮肤和头发，过渡更自然。

### 拼合图

- 默认 4 列 × 4 行，也可以写成 1–16 之间的其他行列数。
- 格子必须等大、紧密排列，中间不留缝。图片宽度等于列数乘以格宽，高度等于行数乘以格高，都是整数。
- 编号从左上角的 0 开始逐行往右数：4×4 时第一行是 0–3，第二行是 4–7。
- 每格的尺寸按上面局部贴片的公式算。上例中每格约 224×270，4×4 整张约 896×1080。格子画得更大不会更清晰，只会让文件变大；画得太小，脸会比身体模糊。
- 同一张拼合图里的格子都贴到同一个脸部框里，除非某个表情在 `stage.json` 里另写了 `at`。
- 每格四周建议留 2–3 像素透明边，计入格子尺寸。舞台缩放后可能出现小数像素，不留边容易带进相邻格子的边缘。
- 局部贴片“完全盖住原脸”的要求同样适用。

## 姿势

- 姿势图会整张替换底图，尺寸和脸的位置都要与底图一致，因为表情层和取景标记是共用的。
- 当前限制：姿势可以在 `stage.json` 里声明，但运行时还没有触发方式。模型选不了姿势，舞台也不会切换过去。

## 表情命名

- 只能用小写字母、数字、`-` 和 `_`，以字母或数字开头，最长 40 个字符。
- 模型只看得到表情的名字，看不到图片或说明，所以名字要直白，例如 `smile`、`shy`、`angry`、`sad`、`surprised`；不要用 `face3` 这类编号。意思相近的名字不要放太多，模型容易分不清。
- `defaultExpression` 必须是已声明的表情，角色出场后、模型还没选表情时显示它。
- 包里没给某个角色声明表情时，这个角色的模型上下文里不会出现选表情的选项。

## 推荐流程

1. 出底图，在「立绘标记」里拖好头顶、腰部和脸部框，记下框的四个数。
2. 按框算出格子尺寸并取整，再画拼合图。
3. 在 `stage.json` 里写上 `sheets`、`expressions` 和 `defaultExpression`。
4. 回到「立绘标记」逐个切换表情预览，检查是否对准、有没有漏出底下的原脸。
