# 默认舞台 UI 设计清单（2026-10-22）

玩家打开一个世界包、没有自带前端时看到的就是默认舞台。本文列出它要画的每个界面、每种状态和预留位置，用于 UI 设计和生图。2026-10-23 已按清单补齐设置、保存弹框、物品提示和静态美术接线；插件区域仅留隐藏位置，BGM 和 Live2D 尚未实现；取景、表情差分和按台词换表情已接通 stage.json，创作者页面可拖动标记。实现见[舞台模板](../../packages/frontend/src/default-template.ts)和[舞台样式](../../packages/frontend/src/stage-style.ts)，行为与验证边界见[自定义前端指南](guides/web-ui.md#官方默认界面布局)。源码接通不代表发行包已经包含。

## 1. 基调

- 黑白两色加灰阶，不用彩色。浅色是白底黑字，深色是黑底白字，跟随系统切换，两套都要画。
- 正文（对白、叙述、名牌、地点名）用宋体；按钮、标签和提示用无衬线字体。
- 画面焦点只有一个：对话框。其余元素轻、细，留白多。
- 强调靠反色（黑底白字的块）和粗细，不靠颜色。例如当前说话者的名牌、打开中的抽屉按钮、发送按钮都用反色。
- 作者可以用包里的 `theme.css` 改颜色、字体和圆角，所以设计时最好把颜色、字体、圆角、间距整理成一组变量。

尺寸：桌面 1280×820 和 1920×1080；手机 375×812（竖屏）。手机上抽屉改为从底部弹出。

## 2. 分层

| 层 | 内容 |
| --- | --- |
| 常驻 | 地点、世界名、钉住的 2–4 项状态；立绘；对话框；轮到玩家时的“说点什么… / 静观”一行；右上角的抽屉入口 |
| 一次点击 | 输入框（点那一行或对话框）；人物菜单（点立绘）；受众菜单 |
| 抽屉（右侧，同一时间只开一个；打开时对话区左移让位） | 记录、行动、状态、设置 |
| 宿主外层工具栏（舞台之外，不需要重新设计） | 重新加载、切换官方界面、记忆整理、逃生 |

## 3. 舞台各部分

### 顶栏
- 左：地点名（大）、世界名（小）、钉住的状态（按“你／世界／某人”分组，例如“你 余额 100 · 世界 时间 18:20”）。值过期时标“上次确认”。
- 右：状态指示点和文字，共六种状态：可以回应、正在回复中（带转动的小加载圈，不显示是谁在回复）、阅读中、已暂停、处理未完成、连接断开。然后是抽屉入口：记录、行动（带可用数量徽标）、状态、设置。打开中的入口反色。
- 场景切换时，顶部中间短暂出现“当前情景 · 某地”提示。

### 立绘层
- 1–4 个在场角色并排站，底边对齐。当前说话者完整显示、名牌反色，其他人变淡。
- 没有立绘时显示灰色半身剪影，胸前是名字首字。
- 点立绘（或键盘选中后按 Enter）弹出人物菜单，内容是：对 TA 说、悄悄对 TA 说、对 TA 的行动（如“牵起 TA 的手”）、交给 TA（如“把保温杯交给 TA”）、邀请参加活动。菜单项可能置灰（阅读中、角色回应中）。
- 没有其他人在场时，中央显示“片刻的宁静”。
- 背景：按地点显示整幅背景图；没有图时是纯色。

### 对话框
- 名牌（反色块，压在框的左上边缘）、待读段数（右上角，“待阅读 3 段”或“已读完”）。
- 正文两种文字色：对白，以及叙述／动作（更浅）。
- 底部：提示文字（“点击继续”“轮到你了”“角色还在回应”），按钮“自动”（可切换为选中态）、“跳过”。开启自动阅读时有一条进度细线。
- 末端回合工具：重新生成、候选“‹ 2/3 ›”、生成中的“停止”。

### 轮到玩家的一行
- 位于对话框下方：宽的“说点什么…”输入入口，以及“静观”按钮。

### 输入框（展开态，替换对话框位置）
- 顶部：引用刚才那句话（说话人和摘要），点击回到对话框。
- 正文输入区。活动限制发言时，改为一排台词选项按钮。
- 工具条：
  - 受众按钮（公开／定向／私密／仅自己，四种圆点样式），点开是向上弹的受众菜单，每项带说明；
  - 定向或私密时出现“对 [角色下拉]”；
  - 描写（点开后变成单行输入）；
  - 附带的行动小标签：“连同行动：拿起保温杯 [先说后做 ▾] ×”；
  - 按钮：＋ 行动、静观、发送（反色）。
- 下方的提示条：“正在提交……”、错误信息、“重试同一操作”。

### 活动卡片（活动进行中出现在舞台左侧，可折叠）
- 小标题“当前活动”、活动名、阶段（进行中、调查、序章等）。
- 目标说明；两列状态格子（如“得分 3”“次数 2”）。
- 操作按钮；需要填写的操作带小表单（数字输入、下拉、勾选）。
- 上次结果（“第1次猜了50：偏大”）；管理按钮（暂停、重试角色处理）。
- 手机上卡片在顶部，横向占满。

## 4. 抽屉

每个抽屉都有标题和关闭按钮，内容区可滚动。

- **记录**：对话历史。每条是圆形头像（名字首字）、说话人、正文；玩家自己的头像反色。底部有“回到最新对话 ↓”，没有记录时显示空状态。
- **行动**：按类分组（移动、物品与互动、活动、活动管理）。每项是一行按钮，需要填写的带小表单，开始活动时有参与者选择。没有行动时显示空状态。
- **状态**：按“你／世界／某人”分组，列出全部已知状态（标签和值，过期的标“上次确认”）；然后是“物品”一节，例如“保温杯 在你手里／在这里／在同行者手里”。没有内容时显示空状态。
- **设置**（已接通，见第 5 节）。

## 5. 补齐的界面（2026-10-23 源码已接通）

- **设置抽屉**：
  - 阅读：字号、行距、自动阅读速度、跟随最新；
  - 声音：音量、静音、语音开关；
  - 外观：跟随系统、浅色、深色；
  - 插件分组仅留隐藏位置（见第 7 节），没有插件时不显示。

  只影响本机显示，改动即时生效；保存到启动器的阅读、声音和外观偏好，下次启动沿用。没有语音适配器时语音开关置灰。
- **保存进度**：放在顶栏或设置抽屉里，点击后弹出一个小框，输入节点名（有默认名）。另画保存中、成功、失败三种状态。游戏内不做读档和分支切换，这些留在启动器。
- **物品变化提示**：例如“你拿到了保温杯”“保温杯交给了同行者”，在顶部短暂出现，样式与地点提示同一类。

## 6. 美术资源约定（静态图片已接通）

- 立绘：`frontend/portraits/<角色ID去掉前缀>.png`，例如 `character:companion` 对应 `portraits/companion.png`。透明背景，PNG 或 WebP，高 1600px 以上，人物底边贴图片底边，同一个包里的裁切位置一致（例如都裁到腰部）。
- 背景：`frontend/backgrounds/<地点ID去掉前缀>.jpg`（png、webp 也可），16:9，至少 1920×1080。设计时注意对话框和立绘压在背景上的可读性：可以留一层半透明遮罩，深浅两套各一。
- 缺文件时回退到剪影和纯色背景。
- 取景：只显示腰部以上，按 `frontend/stage.json` 里每张立绘的 `framing: { top, waist }`（头顶和腰部占图片高度的比例）对齐，没写时按全身立绘处理。创作者页面的「立绘标记」可以直接拖动标出取景和脸部框。
- 表情差分写在同一个 `stage.json` 里，支持同尺寸图层、局部贴片加框、拼合图（默认 4×4）三种，姿势整张替换底图；写法见[自定义前端指南](guides/web-ui.md)。声明了表情的角色由模型按段落自选，舞台跟着玩家读到的那一段切换；没有声明的角色不会看到这个选项。Live2D 和例外映射以后再加。

## 7. 预留位置（仅有隐藏容器，尚无插件 UI 接口）

以后会有走 Cordis 的插件、BGM 播放器、Live2D 等，设计时预留：
- 顶栏右侧，抽屉入口左边，留一个插件入口区，放 1–3 个小图标按钮，每个可以打开一个抽屉或小弹层。
- 设置抽屉里，插件各占一个分组。
- BGM：一个小播放条（曲名、播放／暂停、音量），可以放在顶栏或设置抽屉里，可收起。
- Live2D：直接替换立绘层里的某个角色，位置和尺寸与静态立绘相同；说话者高亮规则不变。
- 表情差分：只换立绘图片，不改布局。

## 8. 交付要求

- 每个界面都画浅色、深色两套；桌面和手机各一版。
- 组件的状态都要画到：默认、悬停、按下、置灰、选中（反色）、键盘焦点。
- 至少画这几个关键画面：
  - 阅读中；
  - 轮到玩家；
  - 输入框展开并附带一个行动；
  - 人物菜单；
  - 行动抽屉打开（对话区让位）；
  - 状态抽屉；
  - 活动进行中；
  - 设置抽屉；
  - 保存进度弹框；
  - 只有一个人在场；
  - 4 个人在场；
  - 没有立绘、没有背景（回退样式）。
- 不需要画：启动器、创作者控制台、宿主外层工具栏。
