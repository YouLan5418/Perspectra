# 插件优先运行时：阶段 7 记录

日期：2026-11-04。分支：codex/plugin-first-next-seams。迁移前基线：518f6d6。接续[阶段 6](2026-11-plugin-first-phase-6.md)与[实施方案](../../superpowers/plans/2026-11-04-plugin-first-next-seams.md)。

例如玩家在屋内聊天，同伴可以在别处自己拿起钥匙；进入狼人杀后，只有合法的下一参与者获得活动机会。现在这两类处理和普通反应都经过同一个调度 Provider，插件可以改变机会策略。角色说什么、是否行动仍由角色决定；活动许可、受众、行动裁定和原子提交仍由宿主执行。

## 源码已接通

- `SchedulerRound.phase` 区分场景、自主与活动。场景可携带自主机会，由调度实现决定先后或交错；活动后的单独自主处理也调用同一实例。没有增加新的调度服务。
- [官方入口](../../../packages/official-scheduler/src/index.ts)决定整合或分段，[自主策略](../../../packages/official-scheduler/src/autonomy.ts)与[活动策略](../../../packages/official-scheduler/src/activity.ts)持有循环、停止条件、超时与官方预算。宿主删除旧机会循环和 `#callBudget`。
- [活动桥](../../../desktop/host/activity-round.ts)只提供合法下一参与者、绑定的 turn 和真实结果推进。每次执行前重查参与者，拒绝非法角色及并行活动执行；插件不能伪造 outcome。[自主桥](../../../desktop/host/autonomy-round.ts)只整理本轮声明的机会和执行能力。
- 观察仍以序号引用并检查归属。活动按序号排序取最近 8 条；分段自主保留原授权视图顺序。已有刺激顺序回归曾发现两者不能混用，修正后通过。
- 分段自主的真实发送计数由官方调度传入 `beforeModelCall`，包括格式重试和决策中间件重复发送。`calls` 保留原决策计数口径。第三方不传回调时，宿主不强制执行官方预算。
- 第三方调度返回后，宿主取消并等待它留下的 turn；即使插件自传 signal，也合并宿主取消信号。关闭存储后不能继续调用旧 round。
- 宿主 API 明确升为 `2.0`，官方调度版本为 `2.0.0`。1.x 插件跳过，不加兼容分支。全部仓库示例更新声明，impulsive-scheduler 增加自主和活动处理。

没有新增包、数据库、世界事件或持久化调度队列。角色内部 CharacterTurn 循环仍固定；决策准备、传输适配和默认装配仍属于阶段 8～11。

### 调查过的两项异常

最初狼人杀回放直接复用旧响应中的活动 UUID，导致新世界拒绝行动，并产生额外请求。这是探针没有重绑定临时 ID；修正后 8 次请求、错误修正、结果与转录均一致，未修改生产规则来迎合探针。

一次新实现甜蜜日程运行在序章后没有发出晨间模型请求，探针按零请求判定失败。原始新数据库保留：序章已完成，玩家晨间输入已提交，角色仍 ready；该次探针当时没有保留返回状态，原因未确认。随后真实重跑正常；阶段 6 和新实现各追加 4 次完整序章的受控实验，全部恢复 3 次晨间请求且没有处理错误。它仍是待复现观察，不能写成已解决或完整体验验收通过。探针现会保留失败状态与请求，后续若重现可继续定位。

探针命令为 `node --import tsx tests/experiments/plugin-scheduler-live.ts record|replay|live <chat|staged|integrated|sweet|werewolf> <证据文件>`。record/live 使用新的证据文件；replay 读取旧记录并使用新的数据目录。通过进程环境设置 `PERSPECTRA_MODEL`、`PERSPECTRA_MODEL_ENDPOINT`，可选密钥只放 `PERSPECTRA_MODEL_API_KEY`，不要写入命令或文件。

证据保存在本工作树 `.tmp/plugin-first-next/live/`；失败实例、回放与重复实验结果均不进入 Git。没有保存密钥或请求头。

## 本次接受的限制

第三方是可信代码，可以忽略机会、费用建议和取消；永不返回的插件仍会卡住本轮。官方执行入口保持取消、授权、玩法裁定和原子提交，但不提供沙箱。显式的外部 `requestCharacter` 仍直接请求指定角色，不属于自动调度。

源码、自动回归、响应回放与短程直接试玩均已执行；甜蜜日程单次无请求观察尚未定位。没有完成整局狼人杀、长会话、第三方调度的真实体验、Launcher 人工操作或完整发行包验收。后续阶段也未因此提前实现。
