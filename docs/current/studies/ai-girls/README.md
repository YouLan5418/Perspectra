# AI Girls 当前研究

研究同一 AI 美少女包的真实模型等待、增量显示、Core 召回成本、短期信息保留及长期整理。下面保留五份详细报告的测量条件，不把前序参数当成当前配置。

| 报告 | 发现与地位 |
| --- | --- |
| [performance](performance.md) | 基线耗时拆分，角色模型和整理等待是主要问题；16/8 窗口属于当时配置 |
| [optimization](optimization.md) | 完整 NPC 提交后增量显示、Core 常驻、固定认知无损压缩；热召回 0.033—0.489 秒 |
| [memory-cadence](memory-cadence.md) | 旧窗口第 9 轮遗忘，人工整理恢复；一次阻塞整理约 458 秒，仍有细节未交付 |
| [wide-context](wide-context.md) | 取消条数截断，较宽原始窗口恢复信息；200k/150k 同步整理是前序阶段 |
| [background-compaction](background-compaction.md) | 当前后台整理：170k/120k 软阈值、16k 原始重叠、2×2 有限并行；同批整理 148.063 秒，启动 0.411 秒，前台继续 |

当前采用增量投影、Core 常驻、宽授权窗口和后台整理，仅在显式 Core 实验入口生效的部分不外推到默认原生记忆。现行机制首选[认知与记忆](../../architecture/cognition-memory.md)。

这些是单轨迹或小样本，模型别名不能证明底层身份或容量。后台重放没有真实跨越 170k，也未完成 32k/64k/128k/192k 成组比较；148 秒不能证明 120k 材料一定在期限内完成。

已知问题：普通反应仍出现约 30 秒中断；宽准入的无关认识、关键原因未进 Delivery、人物技术化表达与转义换行仍有记录。后台减少前台阻塞，不证明长期体验或认识更新收益已全面验收。私有 trace 和原始提示留在本机忽略目录，详细报告注明可复核位置。
