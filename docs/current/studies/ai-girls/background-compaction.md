## 2. 小规模实现

### 2.1 冻结与后台执行

`PlaytestMemoryCore`沿现有授权Source快照取得角色、世界地址、`asOfWorldSeq`及完整来源。角色还在等待空闲执行槽时也已经冻结，后续传给Python的JSON不含世界数据库路径、其他角色视图、私有包变量或新经历。别名历史同样只保留冻结前缀。

手动整理立即返回；自动整理在本次NPC反应结束后启动，却不等待构建完成，也不占用前台busy、writer lease或30秒ReactionCycle预算。前台召回继续使用已有常驻Python；后台每个Build使用独立、可取消的Python子进程，避免占住前台召回worker。后台索引仍会初始化自己的Embedding，但本次不是主要耗时，不为此增加worker池。

调度仅在当前`PlaytestMemoryCore`实例中保存未完成工作与2个执行槽。关闭会话立即取消后台工作；没有新增任务数据库、协议、持久恢复、跨进程续跑或通用队列。

### 2.2 横向并行与纵向依赖

不同角色独立构建。一角色内部只并行原有Retain提炼批次，仍按完整Source分批；合并按原批次顺序执行，保留原Source ID和Atom验证规则。整个Source授权在提炼前检查，合并全部Atom后再次验证，之后才进入既有顺序：

```text
有限并行Retain → 完整Atom合并/验证 → Group → Consolidate → 索引
```

一个角色失败保留其旧档案，其他角色可独立安装。冻结失败也会报告为该角色维护失败，不阻止其他角色进入执行槽；前台读取仍严格校验，不用这个处理隐藏损坏档案。

### 2.3 安装与近期尾部

安装前重新读取当前档案前缀。只有本次冻结前缀严格更大才能安装；比较、写临时文件、rename之间没有`await`。较旧或相同前缀迟到时直接丢弃，不回退已安装角色档案。使用现有世界、角色、Source逐条一致性和索引scope检查；没有新增版本、Receipt或分布式锁。

安装后，冻结前缀之后所有授权经历仍以原始工作历史交付。额外保留约16k本地估算Source token的最近原始重叠，手动整理至当前头部也不会清空最近对白；这不是精确的网关token预算。尚未安装的工作不会提前推进边界。安装恰好发生在前台召回等待期间时，已准备好的授权请求仍可继续；阈值观察跳过已经整理的来源。

## 3. HTTP attempt探针

`core_bridge.py`输出 `memory-core/utility-attempts-<pid>.jsonl`，各进程独立写文件，按`atMs`合并获得实际同时运行数量。每次attempt都有开始/结束，携带角色、冻结前缀、Build ID、stage/批次、attempt编号、耗时、120秒超时标记、HTTP状态、异常类型、是否重试及延迟、请求/返回模型、usage、响应头等待和正文读取耗时。探针不记录提示、正文、HTTP认证头或凭证。

已有3次attempt及2/4秒重试等待策略保持不变；没有为并行增加重试。受控回归验证第一次120秒类超时后重试、返回usage及模型别名的记录。

本次16次HTTP attempt均成功，4.077—40.946秒，中位21.478秒；重试0，超时0，实际Utility峰值3，总attempt耗时327.569秒（并发累计，不能当墙钟）。全部返回 `gemini-3.7-flash-tiered`，usage逐次保存。大部分耗时发生在等待响应头，正文读取为毫秒内。

客户端探针可以区分单次慢请求、超时和重试，但非流式HTTP的响应头等待同时包含远端排队、推理/生成和传输；没有网关内部遥测，不能把这些精确拆开。本次没有严重排队或失败的证据，保留2×2参数；一次成功不证明持续高负载下仍如此。旧155秒Group缺少attempt记录，不能用这次结果反推旧调用必然超时过。

## 5. 大工作历史参数

当前`MemoryContextBudget`实验默认：约170k估算上下文软触发，选取最早约120k完整授权工作历史，至少保留最近一组，另保留约16k近期原始重叠。上下文估算含固定材料和Delivery，但120k选择目标只针对短期历史；剩余上下文不保证精确50k。默认参数在宿主选项内可覆盖，没有写入档案协议或永久模型契约。

这更新了前一阶段200k/150k同步实现，取消按8轮定期整理。频率由每角色授权材料体积决定；若固定材料过大或没有足够旧经历可压缩，暂不凭空整理空窗口。达到软阈值后仍允许正常增长，后台失败后保留原始历史，下次模型请求可再次触发。

本次实际Character prompt约15.7k—40.0k；尚未完成32k/64k/128k/192k的成组对照，亦未真实达到170k自动触发。自动接线和目标前缀由回归测试覆盖，供应商大上下文首响、自然度、旧信息利用与超过阈值后的增长空间仍待真实实验。本轮不声称160k以上整理能在600秒内完成，也不建立硬上限后的额外恢复框架。
