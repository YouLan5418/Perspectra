# 自主机会接入动态派发 · 2026-10-11

玩家在前室与同行者交谈，后室角色正在处理自己观察到的玩家离开，保管员独自在工作室拿取钥匙。现在三个候选可以进入同一个有界队列：前台优先，符合空闲槽位及地点限制的自主候选不再等待所有普通反应结束。它仍只依据自己的目标、知识、当前位置和可见物品行动，不会收到玩家的私语。

分支为 `codex/dynamic-scheduling-experiment`。本次替代普通、自主、后续反应三个连续阶段之间的屏障，复用现有调度器、Character Turn 和提交机制；没有增加持久队列、调度协议或后台计时循环。

## 调度与权限

- 派发时最多两个不同地点的角色，场外最多一个，同一角色只保留一次在途激活。普通、自主及后续反应共用这些限制，优先级仍为当前场景、较少连续 stale、较少完成激活，同级随机。地点互斥约束新激活；已经在途的角色提交移动后可能合流，旧视图按 stale 收束，既有行动结果续写仍连续，不保证在途任务始终身处不同地点。
- 到期自主角色以明确机会进入队列，可没有新观察；其普通根回应合并进该机会，不额外普通调用。角色自己的 cognition/goals、授权观察、白名单与最新 Rulebook 裁定继续生效。
- 每个自主机会最多一次受控操作及结果续写，有预算时可 recall。机会完成后才扣一次配置次数；stale 不增加机会次数，但消耗模型调用预算，最多重算一次。
- 普通、自主及自主后续反应各自预留调用预算，未用余量只还给原组。普通与后续反应共用每角色激活上限。已经就绪的普通回应可合并自主观察；旧普通观察消费后只剩自主来源时，下一次调用改用自主后续预算。观察来源和深度只在内存队列中保存，不加入模型刺激。
- 普通和自主期限从共享派发启动时分别计时；自主及其后续共用一个期限。一组截止或单角色模型失败停止对应处理，其他独立处理仍可完成。玩家取消、暂停或关闭会取消全部未提交计算并等待收束。
- 已提交行动与结果续写连续。续写过期时保留 `continuationOf` 和原预算归属，只补写真实结果，不重放操作；提交依旧串行、短租约、原子性，授权投影变化时不提交旧模型输出。
- Activity 入口或仍有活动参与者排程、变量脚本、`publicationAudit`、`--serial-scheduling` 时继续分段处理。内部测量控制 `stagedAutonomy` 仅延后自主启动，普通处理保持动态，不加入 Launcher 参数。

实现：[调度器](../../../packages/application/src/activation-cycle.ts)、[宿主](../../../desktop/host/world-runtime.ts)、[末端候选环境](../../../desktop/host/tail-runtime.ts)。原包声明和启动器设置未变，现有发行包尚未更新。

## 对照方式

[钥匙搬运样例](../../../examples/world-packs/autonomy-scheduling/README.md)和[驱动](../../../tests/experiments/autonomy-scheduling.ts)保持原目标、权限、预算及普通动态入口，区别只在自主是否等待普通处理。每组创建新数据目录；保管员没有外部观察，动作由真实模型选择。8045 / `gemini-3.8-flash`、low thinking，不给真实请求添加延迟。

~~~powershell
node --import tsx tests/experiments/autonomy-scheduling.ts --live --case=mixed-dynamic --staged-autonomy
node --import tsx tests/experiments/autonomy-scheduling.ts --live --case=mixed-dynamic
~~~

省略 `--live` 可运行可控服务。每组 6 次玩家移动；普通 2 层/6 次调用/每角色 1 次激活，自主 1 次机会/3 次调用，后续 1 层/4 次调用，自主期限 120 秒。统计包括末端快照、规则提交、投递与结算；不包含初始编译和两个空闲探测。仅保存调用时序、结构计数、usage、权威动作及公开玩家视图，不保存原始上下文、完整回应、私密推理或凭证。HTTP 200 不代表角色输出格式通过验证。

## 有意识保留的限制

场外最多一个任务，故离场观察者与场外自主角色仍可能互相等待；接入不会让所有后台角色同时运行。多个自主角色不保证都能在预算内轮到。目标完成后没有自动停用机会，`abstain` 仍消耗调用。玩家停止输入后没有常驻自治。

移动冲突、插话与多自主角色预算通过受控回归；真实对照不人为制造这些冲突。短目标和一次对照不能证明长期目标质量、复杂世界公平性、真实冲突额外成本、Core 长聊或 GUI 体验，也不代表发行包已经包含。
