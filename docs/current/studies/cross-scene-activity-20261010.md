# 活动与跨场景通信组合实验

分支 `codex/cross-scene-communication`，2026-10-10。玩家和同行者在前室玩猜数游戏，后室留守者可以发短信或打电话给同行者。同行者自主决定如何回应；通信不会自动猜数、让出游戏回合、暂停活动或移动角色。

## 组合方式与裁定

实验复用已有活动策略的 `interactions` 白名单，没有新增活动通信协议。作者在[样例猜数脚本](../../../examples/world-packs/cross-scene-activity/scripts/activities/guess.js)中列出 `experiment:message` 和电话各操作的定义 ID。游戏内部答案为 73，仅供规则裁定，不向参与角色或远端联系人公开。

组合前，独立通信规则直接裁定自己的绑定，活动 Context 又会过滤交互；如果直接拼接，可能出现模型看不到通信选项但直接提交却绕过活动限制的情况。组合入口将活动规则置于通信规则外层：活动先验证参与者及操作许可，通过后才执行通信。普通活动操作仍由活动脚本裁定。

[PackActivity](../../../tests/experiments/pack-activity.ts)与[PackActivities](../../../tests/experiments/pack-activities.ts)的 rulebooks 允许实验入口传入已有通信 resolver；默认调用不传该参数，沿用原来的基础规则。手动玩家通信与 NPC 行动使用同一组合规则。手动入口补充提交前缀 asOfWorldSeq，供原有活动世界视图检查使用。

| 情况 | 已验证行为 |
| --- | --- |
| 活动允许短信 | 参与者可以发送与回复；游戏 ID、修订号、回合和轮次不因短信改变 |
| 活动允许电话 | 参与者可以自主接听、说话、挂断；通信不代替游戏操作 |
| 活动禁止通信 | 选项不提供；直接提交发送或接听也被拒绝，状态不变 |
| 禁止通信时收到短信／来电 | 授权观察仍可到达；收信不授予回复权限，来电不强制接听 |
| 活动已暂停 | 不再应用进行中的活动限制，可以使用原有通信许可 |
| 电话保持接通时继续游戏 | 正式猜数操作可推进游戏，通话连接仍保持；远端不自动收到活动状态 |

接收通信、接听与游戏操作是不同机制。非参与者不会取得活动 Context、内部答案或结果元数据。电话本端声音仍按本地场景授权投递，普通本地对白不自动传给电话另一端。

## 真实模型复现

使用用户指定的 8046 / `gemini-3.8-flash`，运行[组合脚本](../../../tests/experiments/cross-scene-activity-live.ts)：

```powershell
node --import tsx tests/experiments/cross-scene-activity-live.ts output/experiments/my-activity-sms sms
node --import tsx tests/experiments/cross-scene-activity-live.ts output/experiments/my-activity-phone phone
```

每次使用新目录。脚本给远端角色发起联系的情境意图，活动中的接收者自行选择回应。通信阶段检查活动完整状态不变；之后玩家正式猜 20，再检查 NPC 是否执行正式游戏操作。report.json 记录结果和授权观察；decisions.jsonl 记录有界模型决策，不记录请求信封或凭证。

第一轮 sms 与 phone 的 01 目录均完成通信，但恢复游戏时网关返回字符串 revision `"2"`，规则拒绝，数据没有被强制修正。组合试玩脚本遗漏了普通活动宿主既有的 decideActivityFormat 一次格式修正，已接回同一流程，严格校验原始活动 Schema，不强转模型输出。失败记录保留。

短信最终目录 `output/experiments/activity-sms-gemini38-20261010-02` 为 passed：后室角色发“你好，稍后方便聊聊吗？暗号是纸船。”，活动中同行者短信回复“好的，稍后。”。通信期间活动保持 revision 1、玩家回合不变；玩家随后猜 20，同行者正式猜 60，再本地说“到你了。”。两次正式猜数后 revision 3，游戏回到玩家回合，通信没有造成额外推进。

电话最终目录 `output/experiments/activity-phone-gemini38-20261010-02` 为 passed：后室角色呼叫同行者，同行者自主接听、问“喂，什么事？”，随后回复“在忙，晚点联系。”并主动挂断，再本地对玩家说“挂了，继续吧。”。整个通信阶段活动完整状态不变。之后同行者正式猜 60；首次返回字符串 revision，经原有一次格式修正返回数值 revision，才执行提交；游戏最终 revision 3、两次猜数、玩家回合。

最终检查两个 report.json：远端观察没有活动元数据；电话远端观察没有内部答案；短信暗号“纸船”未出现在玩家观察中。电话真实角色主动结束连接后再继续游戏；保持连接继续提交游戏操作的证据来自自动测试，不能混为同一真实体验结果。

## 接受的限制

这是独立组合运行时，不代表默认网页、Launcher 或发行包已经接通通信。真实试玩只覆盖进行中的猜数活动；禁止通信与暂停后恢复通信由自动测试验证，没有分别进行真实模型试玩。电话保持接通时提交游戏操作有自动验证，真实模型可能自主结束通话后再继续游戏，不能强制保持连接以获得特定结果。

现有活动白名单可以限制发送／接听，但没有免打扰、来电排队、自动超时或活动结束后自动重试未处理消息。活动禁止通信时，响铃可能保留到活动暂停或有权一方结束。尚未验证活动规则动态改变后如何处理现有连接，以及故事节点、分享或默认宿主调度的通信集成。

后续独立[节点实验](cross-scene-nodes-20261010.md)已验证活动与通信的完整回退、单节点分享和原生记忆续玩；默认宿主集成及活动策略动态改变的边界仍未完成。
