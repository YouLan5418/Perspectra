# 跨场景通信实验：电话

分支：`codex/cross-scene-communication`。这是独立源码实验，默认网页、Launcher 和发行包入口尚未安装。

玩家在前室呼叫后室同行者。同行者自主接听、拒接或暂不处理；接听后双方使用通话交互说话。后室留守者只能听见同行者这一端的声音，可以据此作出本地回应；他不会直接听见玩家的声音。同行者向留守者作出的普通表达也不会自动传到电话另一端。

## 已接通的实现

- [电话规则](../../../tests/experiments/cross-scene-phone.ts)沿用现有 `interact`、Rulebook 与观察投递，提供 call、accept、decline、say、hangup。联系人许可用于发起呼叫；接听授权当前连接内双方说话，不扩大物理可达范围。
- 唯一新增的权威事实是 `communication.call-updated`，记录呼叫双方与 ringing、connected、ended 状态。[独立实验运行时](../../../tests/experiments/cross-scene-runtime.ts)在激活前把该事件加入本实验 Manifest，按既有算法重新计算事件注册表、Manifest 和 Genesis 的哈希；默认编译器的事件集合没有改变。状态从已提交事件重建，没有第二份通话数据库或后台任务。
- 未接听不能传话；只有被叫方可以接听或拒接；双方均可挂断；挂断后声音不再投递。每名角色同时仅有一通未结束电话，忙线拒绝新的呼叫。
- 控制操作只给通话双方投递观察。通话正文给对端投递，同时给说话者当前场景内的授权观察者投递本端声音。旁观者的观察不含远端正文、callId 或 peerId。当前沿用场景观察者作为可听受众，没有单独建立距离、音量或耳语模型。
- 普通 publish 继续按原本场景传播。电话不会传输整个场景上下文、姿态或本地对白。正文仍是说话者陈述，不证明移动、物品转移等事实。
- 接收观察复用原生记忆和 Prototype 激活；没有电话专用调度器。接听后的执行续写允许角色自主说话或挂断。每次玩家命令受 3 波、12 次模型调用、每角色 2 次激活、120 秒预算限制，跨场景不增加预算。

相较[短信实验](cross-scene-communication-20261010.md)，电话增加了接听与持续连接事实，并区分本端可听声音。没有把短信重命名成电话，也没有为后续托梦等玩法先建立通用媒介框架。

## 复现

在仓库根目录运行，并指定新数据目录：

```powershell
node --import tsx tests/experiments/cross-scene-phone-entry.ts output/experiments/my-phone-trial --scenario
```

去掉 `--scenario` 可交互输入 `call`、`say 正文`、`hangup`，以 `/quit` 退出。固定场景在接通后发送秘密暗号、询问意愿、挂断，再尝试一次已结束的传话；模型可以拒接，脚本不会强制接通。

默认模型为用户指定的 8046 / `gemini-3.8-flash`。环境变量 HCW_LOCAL_ENDPOINT、HCW_LOCAL_MODEL 可以覆盖，凭证只从 HCW_LOCAL_API_KEY 读取。输出目录包含有界模型决策 decisions.jsonl 与观察、位置和操作结果 evidence.json，不保存请求信封或凭证。样例或来源格式改变后使用新目录。

## 验证与体验

[五项电话回归](../../../tests/prototype/cross-scene-phone.test.ts)覆盖未接听、忙线、接听与拒接权限、双向通话、本地连锁与隔离、挂断后禁止投递、第三方无通话权限、SQLite 提交中断的原子回滚，以及重开已提交连接而不自动重放反应。电话、短信、场景判断、激活调节、官方玩法与执行结果共 6 文件 41 项通过；类型检查和 Lint 通过。没有重新运行全仓默认 check，上一轮短信实验的全仓门禁状态见其报告。

随后按用户要求进行了[原功能回归检查](cross-scene-regression-20261010.md)，包括完整默认 check、失败项环境重跑和原有活动真实模型试玩；以上 41 项是电话实现时的验证记录，最新范围以回归报告为准。

真实模型数据：`output/experiments/phone-gemini38-20261010-01`，8046 / `gemini-3.8-flash`，共 9 次模型调用。

1. 同行者自主接听并通过电话说“喂。什么事？”，留守者没有回应，周期 quiescent。
2. 玩家通过电话告知秘密暗号并询问稍后过来的意愿；同行者通过电话回答“可以。稍后过去。”。留守者只听见本端回答，问“怎么了，有事要过去吗？”，同行者本地回答“嗯，前室有点事。”。玩家转录没有这段后室对白。此轮因 wave_limit 停止，不能视为所有连锁自然收束。
3. 玩家挂断，同行者本地表现为“收起手机。”；再尝试通过已结束电话说话，被拒绝，没有接收者激活。

最终 evidence.json 中留守者观察不含“蓝色纸鹤”或 peerId，包含本端回答。玩家仍在前室，两名 NPC 仍在后室。这是一个短场景的实际结果，不是任意自然语言绝不泄密的证明；角色若自主向旁人复述收到的内容，仍属于角色行为。

## 影响与接受的限制

本次电话修改集中在独立实验入口、规则、样例与测试，复用短信已增加的媒介来源呈现和动态参数 Schema。默认宿主没有安装电话规则，默认 Manifest 事件表未扩大。现有场景受众、移动和物品权限保持原路径；相关测试通过，不能替代所有默认玩法验收。

尚未实现免提、铃声对旁观者的刺激、振动／静音、无人接听超时、离线来电、自动结束已离线角色的连接、活动期间通信策略、默认前端、故事节点及分享集成。无人处理的呼叫保持 ringing，直到一方结束；连接可以跨实验入口重开保留，未提交后续反应不保证恢复。真实 Core 模型整理、长期多轮通话和发行包体验尚未验证。
