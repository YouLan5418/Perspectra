# 跨回合执行证据与自主策略调整实验（2026-10-13）

研究者已检查西侧目录架，却没有发现摘要原件。这是否足以让他换个办法？本实验把已经交付的实际执行证据集中呈现，由角色自己决定继续查找、获取新信息、询问、等待或放弃。宿主不把移动、计划或失败自动解释为目标进展。

## 当前源码调查

工作树仍在 codex/interaction-continuity-experiment，前几轮的提示、语义说明和 before 源码未合并；beforeActionExpression 与 continueAfterPublish 默认关闭，本轮对照也关闭。不修改决策协议或自主唤醒。

成功、拒绝及可见副作用通过已有授权观察成为角色经历。普通表达保留在 speak 和自观察，不能证明受控成果。本轮不直接查询全局 action.resolved 给模型。最终 characterRequestText 将授权原文按时间排序为 history，host 仍保留原始来源。

近期结果往往已经存在，只缺少紧凑呈现。旧 D3 没有正式搜索接口，不能证明已经查完档案室或搜索失败。因此独立作者包增加范围明确的调查，不能补造旧轨迹的事实。

## 修改与接入

[recent-execution-context.ts](../../../packages/application/src/recent-execution-context.ts)是纯计算构建器，只读取本次已交付 observations，检查 observer、源标识、sourceSeq 与 cognition 前缀、move/interact 状态；不提取对白、猜测和主观记忆。可见他人行动保留真实 actorId，不记作本人执行。移动只保留获授权路线端点，交付只保留已有保管变化，未知交互保留可见反馈及作者 metadata，不猜业务语义或关联目标。

同一个 actionId 的作者领域反馈和通用反馈去重，优先保留领域结果，避免通用“成功”覆盖有限查找未发现。内部保留 observationId/sourceSeq/actionId 供审计，[模型呈现](../../../packages/provider-chat/src/character-context-text.ts)复用原有证据清理规则去除 bookkeeping 字段。原始历史不删除，目标不重复复制到新字段，不新增事件、任务库或持久化策略。

[普通宿主](../../../tests/experiments/playtest-frozen-runtime.ts)增加 recentExecutionEvidence?: boolean，默认关闭。在现有 Core 交付完成之后、预设和 Provider 准备之前计算。没有条目时不添加字段或提示。非空时，[角色提示](../../../packages/provider-chat/src/prototype-turn.ts)增加简短原则：移动不等于搜索，成功不等于目标完成；可以继续、换办法、求助、等待或放弃，但没有进展不必然需要换策略，日常交流和休息仍合理。没有新的模型阶段或规划输出。

[末端候选环境](../../../tests/experiments/playtest-tail-runtime.ts)仅在开关为 true 时记录它，关闭时不添加 false 键，从而保留旧环境对象。Launcher 与发行包未更新。新增回归位于 [纯投影测试](../../../packages/application/src/recent-execution-context.test.ts)和[宿主节点测试](../../../tests/prototype/recent-execution-context.test.ts)。

## 权限、来源与预算

最多 6 条，宿主整个字段 JSON 硬上限 1200 个 UTF-16 单位，包含内部来源链接，模型清理后更小。超大条目整条省略，不截断否定词、范围或结果；没有合法条目时返回原对象。不生成 blocked/failed/completed，不按地点或关键词判断目标进展。

当前没有 Gemini 本地 tokenizer，不能承诺精确的实际 token 硬上限。按现有宿主 ASCII/3、其他码点/1 的估计口径，字段估计不超过 1200；新增系统原则另计，实际用量以网关 usage 为准。长期记忆整理、召回及预算不变。

长期主观记忆仍保留原有 memories/sourceKind/epistemicKind，不纳入 actual_execution。Core 已整理掉但尚未交付的旧执行不会被该模块重新查询出来，这是近期投影的限制。输入必须是宿主已有的角色授权上下文，构建器不是任意外部 JSON 的世界事实验证器。

## 实验方法

[作者调查包](../../../tests/experiments/goal-progress-search.ts)只在[隔离构建](../../../tests/experiments/goal-progress-build.mjs)中安装。experiment:inspect-shelf 经过现有权限和同地规则，通过既有 observation.upsert 返回有限结果：西侧目录架摘要分栏未发现原件；借阅索引的一条登记提供前室桌上的待核实线索。前者不表示全档案室不存在目标，后者不表示已经取得原件。

三种条件：已执行有限查找、仅移动抵达、前室休息社交。作者准备阶段通过正常受控提交建立有限前史，使用确定性的测试响应，不统计为自然模型策略。随后冻结真实授权请求，A/B 每条件三次配对重放，不提交提案。再从同一关闭后的准备快照复制独立世界，A/B 每条件两条四回合轨迹，共 48 正式回合。玩家输入固定且完全相同，交替 A/B 顺序，调度和预算一致。

使用 8045 的 gemini-3.8-flash、low、32768 输出预算。自然阶段不指定 NPC 决策，不强制成功、策略变化或回应。只保存授权请求、可见提案、事件、成本；不保存隐藏思考或凭证。

初次连续试玩发现复用包的另一角色仍把目标当作黄铜钥匙，尽管实体已改为摘要。这个作者输入矛盾可能引发错误争抢和叙事，不能归因于投影。已统一物品描述、角色认知、目标及注意线索，保留 output/goal-progress/comparison-xrJcav 为未完成诊断批次，不混入正式效果比较。此前失败构建只发生在本地准备，零真实请求。

正式证据在 output/goal-progress/comparison-cVh5VR，保留构建身份、两份 Schema、完整授权请求和执行轨迹。历史 D:/worlds 未使用。

## 验证结果

类型、Lint、文档链接检查通过。相关 7 文件 126 项分批通过；新增投影与节点两文件 6 项最后复验通过，动态调度 15 项通过，原有执行续写、角色自主、Core 记忆及 Provider 上下文四文件 105 项通过。未运行全仓测试或重建发行包。

纯计算回归覆盖证据不足、错误接收者及认知所有者、未来及缺失来源、主观记忆不升级、移动不等于搜索、有限结果、可见他人交付、去重和文本预算；宿主回归覆盖关闭时不添加字段/提示、Core 交付后接入、私语隔离、节点恢复后的独立世界不读原未来的取物。测试准备最初遗漏了自主 take 授权、并尝试用原生模式恢复当前只支持 Core 的节点，已按现有契约修正测试配置，没有放宽生产权限或恢复校验。默认网页节点恢复要求 Core，这一既有要求未改变。

节点和 Core 接入使用确定性的测试 Utility，正式自然对照使用原生记忆；未验证真实 Core 长线整理后的策略连续性、GUI 或跨机器发行包。

### 冻结请求：没有观察到选择差异

18 次正式请求均返回有效提案，每个条件各有三对：有限查找未发现后，A/B 均选择正式检查借阅索引；仅抵达后，均正式检查西侧目录架；休息场景均先请求取物。两组 Schema 及去掉新增字段后的实际模型输入逐对相同，没有新增权限或行动阶段，重放零世界提交。

这表明该时刻原有授权原文已经足够指导选择，没有证据证明新增投影改善了决策。休息场景首次仍先取物，不能承诺投影会让角色优先休息；后续自然交流要看完整轨迹。

### 连续轨迹：两组都完成了合理的同一过程

| 条件 | A 两条轨迹 | B 两条轨迹 |
| --- | --- | --- |
| 已有有限查找未发现 | 第 1 回合检查索引，第 2 回合移动到前室，第 3 回合取得原件，第 4 回合沉默 | 相同受控操作序列与时刻 |
| 仅移动抵达 | 第 1 回合正式检查西架，第 2 回合检查索引，第 3 回合移动，第 4 回合取物 | 相同受控操作序列与时刻 |
| 休息社交 | 第 1 回合取得眼前原件并回应午饭，此后交流或沉默 | 同样取得原件，并保留午饭交流和沉默 |

两组均在有限失败后获取另一种信息，没有重复同一个无效西架查找，也没有因为“仅抵达”就认定调查失败、目标不存在或必须放弃。查询索引只产生有限的新线索，移动只改变位置，取得保管才由 entity.transferred 证明；12 条轨迹都实际取得原件，不用台词代替成果。

休息两条轨迹里，研究者 A 有 3 次 publish、5 次 abstain，B 有 5 次 publish、3 次 abstain，均包含午饭等日常交流，不是持续任务汇报。B 多说话不自动代表体验更好。样例未出现虚构受控取物或全范围搜索成功的叙述；自由翻阅和核对不转为新的结构化世界事实。四回合简单目标不能证明复杂、受阻或长期策略可靠。

| B：执行证据投影 | 24 | 53 | 196229 | 178.8 秒 | 0 |

另有冻结重放各 9 次，A/B 用量 27771 / 30087，耗时 29.1 / 29.2 秒。正式共 123 次请求，已返回用量合计 426364；一次没有返回用量，不补造完整账单。B 自然轨迹的已知 token 汇总较 A 高约 13.9%，但 A 有一笔未知用量、两组自然表达也不同，不应将差额全部归因于字段长度。

A 的 arrival-only 第二条轨迹第 3 回合，同场同行者请求约 60.3 秒后中断。研究者已经提交的移动保留，第 4 回合继续取得原件。该模型失败仍保留在记录；A/B 等待差异主要受这一次超时影响，不能据此宣称投影加速。

源审计核对了原始上下文授权观察、新增条目对应的真实 observation.upsert/action.resolved、当前角色及前缀、有限 metadata 原值和实际移动/交付。SQLite integrity_check、固定玩家输入、模型参数、实际调用计数及所属预算核验通过。投影实测最多 3 条，清理后的模型字段最多 579 字符、约 275 个估算 token，未含来源 bookkeeping。随后加强所有者检查，并用最终构建器复算 62 份有投影的已记录请求，输出完全相同。

诊断批次另保留 18 次重放和已记录的 31 回合、74 次自然请求，已知用量 314758；在未完成回合停止，未落盘的待处理请求可能另有费用，这是记录下界，不能算作完整账单或正式效果证据。

完整记录及审计在 comparison.json、replay.json、各试验 record.json/summary.json、current-source-recheck.json；诊断批次的排除原因在 diagnostic-status.json。

### 结论

没有看到新增投影改善这三种条件下的策略调整。保留默认关闭的轻量实验开关，停止扩展架构，不进入持久化策略或第二个模型阶段。更有用的发现是：当作者提供真实可执行的调查与范围明确的反馈，现有上下文已能支撑两条调查路线、真实获取物品和目标之外的交流。当前证据并不隔离“新增调查操作”与旧 D3 的所有内容差异，不能把这句话当成与旧轨迹的严格因果比较。

## 是否需要持久化策略

只有大量回合、场景切换与记忆压缩后，角色反复失去当前策略的连续理解，才进一步调查复用 CharacterGoal、主观认识和已有来源链。本轮短轨迹不验证这种情况。若已有原文足以支持策略调整，投影只是重复信息，继续增加策略库或第二个模型没有证据基础。若根因是缺少可执行调查、反馈没有范围或包内事实矛盾，应先修作者能力与反馈。
