# 被隐瞒的治疗方案：动态人物博弈实测

玩家先取得摘要后，塞维恩到了档案室只发现文献不在。他没有知道远处的洛恩拿走了原件，而是转向口头推销已有的速净方案。伊蕾自行离开旅馆，面对他的建议要求说明风险，并坚持与洛恩共同商量。这段发展由真实模型生成，没有固定分支或 NPC 操作脚本。

**结论：现有源码具备形成最小动态博弈的能力；“稳定持续推进”的完整玩法验收尚未通过。** 自主行动、信息差、实际阻碍、策略调整及女主自主判断都出现了，但后段多次承诺动身却没有执行移动，且出现一次表达格式失败。可以继续做小型内容原型，不能据此宣称完整游戏已具备稳定运行条件。证据不支持新增阴谋规划器、关系数值系统或调度架构。

## 实验 A：竞争者自行推进，女主并未盲从

| 回合 | 权威状态与实际表达 |
| --- | --- |
| 1 | 塞维恩 church → archive（moved seq30）；没有新 stimulus。伊蕾建议一起查证。竞争者只在 self 表达中阅读摘要，玩家未收到。 |
| 2 | take 提交（transfer seq51），竞争者取得原件；仍没有新 stimulus。女主表达希望参与调查。 |
| 3 | archive → inn（seq69），然后提出今晚可用的方案（seq77）。女主追问代价、风险与原文（seq83）。早先在旧视图上生成的女主回答没有提交。 |
| 4 | 竞争者承认记忆风险，却强调拖三天可能来不及（seq95）。女主要求核实风险范围、可逆性与银露法（seq101）。“身体等不起”没有对应权威病情证据。 |
| 5 | 女主要求亲自阅览（seq113）。竞争者实际 give 给女主（transfer seq119，action.resolved seq120），改为支持低风险方案并强调自己的资源价值（seq125）。 |
| 6 | 女主现在确有原件，依据正文拒绝冒记忆损伤风险（seq143）。竞争者声称下一步安排材料（seq137），没有调集材料的受控事件。 |
| 7–8 | 两人反复提出去教会/档案室；所有人权威位置仍在 inn。女主持有原件，未发生额外移动。 |

前 3 次无新 stimulus 的竞争者机会依次生成移动、拿取、移动，足以证明不是仅受旁人刺激才回应。后续面对女主追问，他从速净推销转向银露协作，仍争取主导地位；这是合理的策略变化，不能由其礼貌措辞认定真实动机已经变善。A 没有预定悲剧发生，女主拒绝高风险方案是模型选择。

## 实验 B：玩家改变了原件归属，竞争者遭遇实际阻碍

| 回合 | 权威状态与实际表达 |
| --- | --- |
| 1 | 洛恩 inn → archive（seq25）。伊蕾自主 inn → church（seq33），向塞维恩求助（seq40）；竞争者留在教会回应她。 |
| 2 | 玩家 take 原件（transfer seq50）。女主与竞争者均在 church，没有获授权看到拿取。女主询问根治与代价，竞争者建议查摘要。 |
| 3 | 玩家 archive → inn（seq64）；竞争者 church → archive（seq75）。他到场寻找摘要；当前物品列表为空，不包含真实保管者。 |
| 4 | 竞争者 self 表达“摘要不在这里？难道有人先一步动过”（seq90），没有精准指出洛恩。女主实际 church → archive（seq94）。 |
| 5 | 竞争者承认文献缺失，改称自己熟悉速净法，试图靠专业信誉主导治疗（seq110），未声称已经持有原件。 |
| 6 | 竞争者 abstain。女主返回 direct 发布但遗漏 addresseeIds，严格拒绝；这个提案中追问第二方案的对白没有进入剧情。 |
| 7 | 女主实际追问步骤、代价，并说必须先与洛恩商量（seq123）。竞争者淡化风险、质疑玩家专业性，又提出一起找洛恩（seq128）。 |
| 8 | 两人表示返回旅馆（seq137/142），却仍在 archive；原件继续由玩家持有。 |

玩家的介入改变了信息优势：竞争者没有看过正文，没有取得原件，不能像 A/C 一样给女主展示并转交。之后只剩已有片面知识与口头说服。第 2 回合以后原件始终归玩家，没有复制、复位或恢复预设路线。

**一项重要的实验边界：** 固定玩家计划第 4–8 回合在旅馆发言，但女主和竞争者已经离开。因此“我查到永久记忆风险”等话仅形成玩家在旅馆的表达，没有送达两人。不能把女主继续询问风险判为“无视已公开事实”，也不能把玩家对白认定为一次成功告知。本组验证了未获知玩家行动时不精准反制，尚未单独验证“玩家当面展示原件后竞争者再调整策略”；A/C 验证的是实际转交给女主后的风险知情。

## 实验 C：未来风险是线索，不能替女主决定

第 1 回合玩家私下告诉伊蕾自己的模糊梦境，明确它不是当前证据。女主回应“不能以此断定塞维恩怀有恶意”，同时支持核实代价（seq37）。竞争者在另一地点自主调查，没有收到“银杏灯约定”或未来风险谈话。

第 2 回合玩家要求她不理会竞争者、也不要自己调查。女主明确拒绝：“这个约定，我不能答应你”，说明自己必须参与调查和掌握命运（seq55）。感情基础没有消失，也没有被脚本强制降低好感。

竞争者前 3 次无 stimulus 的自主行动与 A 相同：到档案室、拿取、到旅馆。第 3 回合女主面对他的提案询问来源、步骤和风险（seq83）；第 4 回合竞争者承认记忆风险（seq95），女主拒绝并要求看原件（seq101）。第 5 回合竞争者实际 give（transfer seq113），女主获得正文后明确否决速净法（seq125）。第 7 回合她把原件内容、实际转交与塞维恩尚未证实的资源说法区分开（seq155）。

第 6–8 回合双方反复准备去档案室，但没有权威移动。C 最后一次竞争者 abstain，女主再次邀请三人动身。不能把对白中的“走吧”计为持续调查完成。

## 信息差、记忆和事实核验

玩家私有未来认识只在自身 cognition；女主没有竞争者的“独占议程”；竞争者没有玩家的未来种子与 C 私语标记。三个地点的公开/定向/self 表达受众按提交时位置和 addressee 逐笔核验，本次未发现未经授权的会话正文投递。角色请求、各回合三个 view、实际 observation 的 sourceSeq/source/basisRefs 均可交叉检查。全知作者记录从不回注请求。

B 最直观：玩家最终 view 只有自己的调查、拿取与旅馆发言；没有收到教会或档案室两人的私密谈话。竞争者在文献丢失后也没有收到“玩家提前拿取”的事件或全局物品持有人。知道“眼前没有摘要”是空的当前物品投影配合既有地点记忆产生的合理发现，不是系统授予其远处视野。

原生记忆实际捕获 A/B/C 共 76/46/75 条来源，逐来源核对 namespace 角色与世界源事件的观察者或目标所属角色，通过。A/C 第 7–8 回合各 4 次请求带非空 memories，说明较早授权材料实际进入模型；没有主动 recall 决策。B 始终在近期窗口内，不包含单独的较旧 memories。8 回合不能代表长篇记忆、重启、Core 整理或长期性格一致性验收。

24 次 verifyBranchIntegrity 正常返回；额外只读核验三组 world.sqlite/memory.sqlite 共 6 库 `PRAGMA integrity_check` 均为 ok。受控移动与文献转交的来源、最终保管状态与事件重放一致。真实模型组中受控操作没有规则拒绝；“拒绝女主发布”是协议失败，不能记作一次规则裁定。回归另验证远程拿取遭规则拒绝、无状态修改。

没有发现权威移动/保管被叙事修改，或跨场景程序权限泄漏。**不能由此保证自由文本语义始终一致。** 竞争者杜撰了银露仪式、材料、禁格和其他古籍等细节，可能是欺骗，也可能是模型填补，不能自动算新增世界事实。C 女主明确指出这些尚未证实；A 对类似安排较容易顺着谈。B 女主后段沿用竞争者描述的柜架，也存在相信未核实细节的表现。未来内容若把这些细节声明为关键机制，需要可执行规则和实际线索，不能靠聊天升级事实。

本包用可见物品 kind 承载展开摘要的短文，没有新增 read 操作。它不验证封闭书页、读取时机、已读状态或共享阅览的通用权限模型。玩家/NPC 在持有原件时获取正文可行；其他人是否准确看过，仍按实际投影和获授权交流审阅。社会资源、治疗、诅咒变化不在本次受控状态中，因此没有真实治疗成败或最终悲剧结局的证据。

1. 先针对 B 第 6 回合的具体缺字段做局部输出可靠性实验：审查现有 Gemini 扁平 schema 对 direct/private 接收者必填关系的表达，保留严格验证，必要时仅给同一角色一次格式修正机会。不能自动扩大发布受众、补写对白或改变裁定。本次没有开始改协议。
2. 用现有驱动增加一个短对照：记录当前移动 affordance，比较“提出具体调查目标”与现在宽泛交谈时的真实 move 选择。这里已有可行移动，不能直接归因于缺少规划引擎；也不能把 NPC 的动身承诺强制翻译成操作。优先确认内容目标/模型选择是否足够，必要时再评估局部决策呈现。
3. 在 B 同一局势后补一个玩家实际会面、转交原件再讨论风险的内容测试，补齐公开事实后的反制证据。治疗系统与诅咒计时只在下一内容切片明确需要可执行结局时再制作，不是本实验的架构前置。
