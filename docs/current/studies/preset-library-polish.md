## 接受的限制

没有酒馆文件直接兼容、historyDepth 或条件脚本。本轮使用浏览器及原生桥替身验证界面，真实 Node LauncherCore 验证存储与文件写入；未重新构建或实测 Tauri 原生窗口与操作系统对话框。剪贴板若被运行环境拒绝，界面会提示手动选文复制。

JSON 交换最多 100 万字符，整库超过上限需分开导出；库本身没有自动关联更新机制。库操作立即保存，配置草稿需保存全部配置；关闭编辑器放弃草稿不会撤销已完成的库操作。Inspector 搜索只过滤当前调用展示，不搜索存档或已丢弃请求；保留上限仍为 4 次。一轮真实模型验证只覆盖功能链路，不代表长期角色自然度或记忆质量验收。


## 后续更新：交换格式 v1
