# 官方序章性能优化 · 2026-10-10

玩家每次点击“继续”只发表一条固定表达，但 test3 后端在序章后半段仍需约 1.5 秒。固定台词脚本实际执行约 0.5 毫秒；等待主要来自宿主重复读取历史、构建视图及操作前的末端重生成快照。

## 本轮修改

- 活动状态按当前提交序号复用，并只读取 `activity.updated`。每次查询仍核对世界头，返回独立副本；新提交使旧前缀失效。不同运行实例与候选世界不共享状态。
- 没有长期档案时，身份快照只恢复／复制已经获得的授权别名，并校验角色、世界和事件前缀，避免为所有角色重建完整记忆源。已有长期档案仍执行完整来源校验。
- 保留每回合数据库备份、权威事务、发表与观察分发、模型输出和 Rulebook 校验。未增加数据库或持久化协议。

实现：[活动读取](../../../tests/experiments/pack-activity.ts)、[身份快照](../../../tests/experiments/playtest-memory-core.ts)。这是源码实现，尚未重新构建便携发行包；test3 文件未修改。

## 性能复测

使用 Node 24.14.1，和 test3 内置的官方游戏目录、相同 local/openai 配置及默认 Core 记忆预算。旧版本使用发行 bundle；新版本使用按相同 Node/esbuild 设置构建的诊断后端。全程新建临时目录，不读写历史试玩数据。计时包括末端回合外层的操作前快照与前后收尾，不包括启动或 WebView 绘制。

| 序章表达 | test3 原耗时 | 优化后 |
| --- | ---: | ---: |
| 第 1 句 | 523 ms | 443 ms |
| 第 50 句 | 949 ms | 619 ms |
| 第 100 句 | 1417 ms | 768 ms |
| 第 110 句 | 1506 ms | 791 ms |
| 第 112 句 | 1506 ms | 804 ms |

从同一份实验末端回合前快照分别恢复到新目录后，优化前两次不含 CPU 采样的操作为 1567／1495 ms，优化后三次为 763／766／774 ms，约减少一半。身份快照从约 527 ms 降到约 13 ms。普通角色视图与当前角色记忆投影仍有随历史增长的成本，本轮没有实现全局视图缓存或调整连接生命周期。

完整序章验证 112 条正式角色／玩家表达，其中 5 条玩家表达；最后进入 free 阶段、台词正确、error 为 false、真实角色 provider 调用为零。性能测量通过了实际末端回合外层，没有绕过备份或提交。

原始数据在工作区 `output/diagnostics/prologue-performance-test3-tail.json`、`prologue-performance-test3-repeat.json` 和 `prologue-performance-optimized.json`。这些是本机诊断输出，不包含凭证；本报告保留可用于代码评审的测量摘要。

## 验证与限制

类型检查、Lint、文档本地链接检查通过。四个相关测试文件共 90 项通过，包含状态副本与新提交刷新、别名权限与独立副本、已安装档案跨角色拒绝、失败提交、私密观察、候选切换和强制终止后的恢复。首次并行运行两个普通用例失败，单独重跑相关用例及串行完整运行通过；并行失败原因未单独确证。首次沙箱运行无法 taskkill 测试子进程，放开执行权限后五个强制终止恢复用例通过。

本机 8046 模型接口在本轮不可用，未完成新的真实模型试玩。没有测量 WebView 绘制、不同机器／磁盘、自定义预设文本规则或已有长期归档下的性能；已安装档案仍接受原有来源校验开销。自动回归和脚本序章不替代角色自然度与长期召回体验验收。
