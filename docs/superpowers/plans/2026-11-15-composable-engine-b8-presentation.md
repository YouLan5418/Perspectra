## 实施边界

- 接通已授权 GameplayPlayerView，校验并隔离展示故障；属性表、条目列表只显示当前玩家已知数据。
- 共同操作保留作者标签、分组和开放展示分类；物理目标类型仍按核心身份推导。参数允许提供固定部分，其余由表单填写，执行时校验完整参数和当前候选。
- pluginControls 统一布尔和有限选项；玩法控件绑定本模块已注册且当前可用的操作，仍走正式裁定。pacing 作为已有运行偏好适配，保留下一轮生效及原保存范围；端侧音量等保持端侧设置。
- 默认表单首批支持字符串、数值、布尔、枚举及授权角色选择。复杂结构提供明确 JSON 输入／校验说明，不发明动态组件或事件总线。
- Launcher 在已有包设置入口读取已允许插件的 configSchema，提供常用字段和复杂配置 JSON 编辑。保存前完整纯校验，拒绝越界路径及运行中修改；内容变更沿用已有包摘要／新实例约束。
- 同步完整视图、增量清除、客户端、授权路由和错误反馈。搜证示例补面板／控件，用真实 Host 和默认舞台验证。

## 接通结果

- 共同操作的固定参数与开放输入分离，参数 Schema 公开到默认表单；执行复核完整值、当前目标、固定字段与 restrictions。开放展示分类不再决定物理 targetRef.kind。
- GameplayRuntime 从当前玩家授权模块状态生成只读展示，校验并复制有限 JSON。单模块展示故障经过净化提示，不泄漏内部栈，不影响其他模块和已提交事实。
- 玩家请求使用 setPluginControl；模块控件绑定自己的公开操作，当前唯一候选和参数通过后仍走核心 Handler。bool／select 支持值校验、不可用状态和明确反馈。pacing 以现有运行偏好适配，端侧设置范围保持独立。
- 默认舞台增加授权属性表和线索列表，使用纯文本；参数支持常用标量、枚举、角色选择与复杂 JSON。角色候选变化时保留合法草稿和行动表单焦点／选区。
- Host 外壳与 SDK 完整／增量传输共用字段清单，移除字段用 null 清除；查询结果正确更新 SDK 缓存。按钮行动被拒时显示业务原因，不显示内部操作 JSON。
- Launcher 读取已启用且允许的配置 Schema，常用字段／完整 JSON 双模式；复用 B7 整包纯校验、当前摘要检查和真实路径约束。同源包排他文件锁覆盖重新读取到原子替换，避免多个 Launcher 相互覆盖。只改源包，旧实例包摘要及存档保留。
- 搜证示例加入两种面板和通过正式操作控制的搜查开关，增加持久状态后 dataVersion 提升至 2。

实现仍沿用现有 packages 和 v5 包目录。没有引入新 UI 框架、事件总线、时间模型或恢复协议。

## 有意识保留的限制

- 默认表单是有限 Schema 控件，复杂字段用 JSON；不实现任意递归 Schema UI 或作者组件系统。
- 单控件绑定一个唯一的当前操作候选；多候选／需要多个开放必填参数的操作通过普通行动表单完成。
- 配置保存锁不自动恢复。中断残锁明确提示确认原进程退出后人工清理，外部编辑器不参与锁。
- 改源包后使用新实例；不自动升级旧存档，也不增加兼容承诺。
- 性能不承诺几十毫秒；无头推演、更多玩法体验和发行验收分别留后续批次。
