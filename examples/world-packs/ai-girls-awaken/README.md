# 历史素材：一觉醒来，我的大模型们都变成了美少女（v4）

同名世界的可运行版本见 [ai-girls-awaken-v10](../ai-girls-awaken-v10)。上一级目录中的 `ai-girls-awaken.worldpack.json`（`worldpack/v4` 编译产物）、`ai-girls-awaken.interactions.json` 与 `ai-girls-awaken.character-interactions.json` 属于同一批历史素材。
