# 纸灯牌桌

原创占位卡牌样板，不需要 RPG 插件、美术或模型密钥。包含四色接龙、灯塔守望身份战和三席密封竞价，共用 `official-cards` 引擎。

在仓库根目录运行：

```sh
node --import tsx tests/experiments/cards-preview.ts
```

打开打印的本机地址，在行动菜单选择活动，读完开场后点击牌桌选择。可在宿主保存、暂停/继续和中止。临时世界退出即删除；正式开档请用正常世界包入口加载此目录。

实现、配置、隐私包络、第四规则扩展和本版不支持末端重新生成的范围见[卡牌指南](../../../docs/current/guides/cards.md)。本包明确配置：玩家赢得竞价且报价至少6时，随终局获得3点「纸灯积分」。删除 cards.json 的 reward 可关闭；其他包默认不发奖。终局与积分同事务，强退、败局及门槛不足不发。
