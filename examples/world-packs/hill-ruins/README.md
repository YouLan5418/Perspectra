# 山脚遗迹：官方 RPG 机制的验收包

你和少女法师澄住在山脚小屋，屋后山坡上有一座遗迹。邻家姑娘阿茹不爱冒险，留在家里等你们。

例如：你在客厅对澄说“陪我去遗迹看看吧”，澄自己选择“加入队伍”。你走进遗迹一层，澄跟着来；旁白说石廊潮湿阴冷，守卫喊“擅入者，止步”，作者写好的澄说一句“小心，它的护甲很硬！”并放出火球，守卫生命 50 → 36，然后轮到你。守卫倒下后铁钥匙落在地上，拿起它才能打开通往二层的铁门，二层的木箱里有一瓶药水。回家睡一觉，生命回满。留在客厅的阿茹只看见你们出门；你回家开口讲，她才知道遗迹里发生了什么。若全队倒下，醒来时大家回到客厅，生命只剩 1。

## 这个包验证什么

- `rpg.json` 的全部字段（属性、角色、技能、装备、消耗品、休息、敌人、掉落、宝箱、锁门、写死的演出、战败、队伍）；字段说明见[创作者：RPG 玩法](../../../docs/current/guides/rpg.md)。
- 属性只在遗迹里显示，在家时状态栏没有生命和魔力，但在家睡觉仍能回血。
- 阿茹留在家里，不知道战斗细节（认知隔离）。
- `scripts/status.js` 是物品规则模板的拿起、放下、交给；钥匙、宝箱药水都靠它拿起。

## 结构

| 内容 | 位置 |
| --- | --- |
| 地点：客厅、卧室、遗迹一层、遗迹二层、宝库（没有路可到，只放掉落物） | `locations.json` |
| 角色：玩家、澄（同伴）、阿茹（留在家里） | `characters.json`、`cognition.json` |
| 物品：铁剑、两瓶药水（客厅一瓶，遗迹二层木箱一瓶）、铁钥匙（在宝库里，守卫倒下后落到一层地面） | `entities.json` |
| RPG 配置 | `rpg.json`（已在 `assetFiles` 登记） |
| 物品规则 | `scripts/status.js` |
| 推演脚本 | `.perspectra-lens/scenarios/` 下三份 |

阿茹没有写进 `rpg.json` 的 `characters`：那里除玩家以外的角色都是“同行 NPC”，必须全部在场，地图内容才会开始。

澄的演出有三处：遗迹二层的进入台词，遗迹一层开战时的话和火球，以及第 1 轮她自己的回合再放一次火球。没有写死的回合由她自己（模型）决定。

在当前源码 Launcher 中导入本目录并新建游戏实例。也可以从仓库根目录运行（需要可用的模型连接，使用新的数据目录）：

```powershell
corepack pnpm@11.7.0 experience:web --memory-none --pack examples/world-packs/hill-ruins --data-dir .tmp/hill-ruins-manual-20261108
```

## 验证状态（2026-11-08）

- `corepack pnpm@11.7.0 worldpack validate examples/world-packs/hill-ruins`：通过。
- 三份推演（`node --import tsx desktop/lens/cli.ts simulate examples/world-packs/hill-ruins <名字>.json`）都是 `passed: true`，退出码 0：
  - `clear-and-rest`：澄入队，到遗迹一层开战，打赢，铁钥匙落地，拿钥匙，铁门放行，二层拿药水，回家睡觉，生命回满。
  - `defeat-back-home`：带着重伤战败，传送回客厅，生命为 1，阿茹不知道战斗。
  - `aru-knows-nothing`：阿茹只知道他们离开，不知道遗迹和战斗。
- 另用包透视的状态栏核对过：在客厅时没有生命和魔力，进入遗迹后出现。这一项没有写进推演脚本。
- **没有用真实模型试玩过。** 澄是否愿意入队、写死的台词读起来是否自然、没写死的回合她怎么打、战斗节奏是否合适，都是未验证。推演只证明规则、触发和信息差，不证明体验。

## 已知限制

- 一个宝箱只装一件物品；没有等级与经验、商店、格子地图。
- 写死的演出（澄的台词和火球）可能和她当时知道的事矛盾，需要试玩检查。
- 全部限制见[创作者：RPG 玩法](../../../docs/current/guides/rpg.md#6-已知限制)。
