# 《大模型变成美少女了？！· 赔罪晚宴》试玩包 0.2（v2）

> v2 相对[原版 0.1](../model-girls-dinner/README.md)只改了时钟：行动菜单一键"等 5/10/20 分钟"，报时改为旁白，不再替玩家说话。包 ID 为 `pack:model-girls-dinner-v2`，与原版存档不互通，需要开新游戏。下文试玩记录均来自原版。

一个傍晚，四个各有心事的室友，一场 18:00 的晚宴。你是屋主，也是唯一能在她们之间传话的人：可以保密、撮合、揭穿、捣乱，或者什么都不管。没有预定结局。

角色设定沿用[官方序章包](../model-girls-official/README.md)，没有序章，直接从周六 16:00 开始。美术是默认舞台的占位剪影。

## 局势（玩家开局知道的）

- 昨晚 DeepSeek 偷吃了 Claude 的草莓蛋糕。DeepSeek 想在 18:00 给 Claude 做一顿赔罪晚宴当惊喜，拜托你保密、别让 Claude 进厨房。
- 灶台打不着火了。
- Claude 在客厅看书，GLM 一下午躲在卧室，GPT 在书房做开支表。

## 只有角色自己知道的

| 角色 | 想要 | 藏着 |
| --- | --- | --- |
| DeepSeek（厨房） | 做成赔罪大餐，保住惊喜 | 网购了印着「蒸馏」的玻璃蒸馏器；小本子里记着对 Claude 的七次"旁敲侧击" |
| Claude（客厅） | 弄清 DeepSeek 在搞什么，不冤枉人 | 怀疑自己被"蒸馏"了；其实介意的不是蛋糕，而是没听到一句正经道歉 |
| GLM（卧室） | 不丢面子地把灶台的事处理掉 | 灶台是她上午"优化"点火器弄坏的；工具箱就在床边 |
| GPT（书房） | 准时、按预算吃上晚饭 | 上午看见 GLM 蹲在灶台前拧螺丝；准备了外卖备用方案 |

小本子那一页故意写得像"采集 Claude 的回答准备蒸馏"。Claude 看见它会怎么想、DeepSeek 怎么解释，由模型自己决定。

## 受控的东西（只有这些需要按钮）

| 物品 | 能做什么 |
| --- | --- |
| 玻璃蒸馏器、DeepSeek 的小本子 | 拿取、放下、交给某人。放在地上时，同一房间的人都能看见外观和本子内容 |
| GLM 的工具箱（卧室） | 拿取、放下、交给某人 |
| 灶台 | 有人带着工具箱在厨房时出现"修理"。谁修都行，不一定是 GLM |
| 晚宴食材 | 凉拌冷盘（随时可做）、家常菜（要灶台修好）、蒸馏高汤大餐（要灶台修好且蒸馏器在场）。冷盘之后灶台修好仍可再下锅；做成热菜后不能再改 |

其余一切都是自由描写：你可以写"我把 Claude 拉到阳台聊天""我往锅里偷偷加了一勺糖"，角色会把它当作当场发生的事来回应，只是不进入物品状态。

## 怎么玩

1. 开局直接自由互动：说话、描写、走动、操作物品。
2. 想让时间过去时，在"行动"里点"等 5 分钟""等 10 分钟"或"等 20 分钟"。转录里出现一行旁白，比如"过了 5 分钟，墙上的钟指向 16:05。离晚饭还有 115 分钟。"，在场的人也能看到；之后四个角色**各自获得一次自主行动机会**：修灶台、做饭、去找人，都在这时发生。**时间不会自己走**，聊得再久也停在当前时刻。等的时间短，到 18:00 前大家能行动的次数就多。
3. 饭菜准备好了（或者决定不准备了），到有饭菜的房间点"开始 晚宴"，从在场的人里选择谁入座。
4. 晚宴是真心话环节：入座的人轮流说一句今晚的真心话（真实模型，说什么由角色决定），最后由你收尾。桌上是什么菜，只按你此刻能看见的食材状态判断。

**建议**：开局先在故事线里存一个节点。玩完一遍后回到这里，换一种做法再来，比如揭穿、撒谎、帮 GLM 打掩护、把小本子放到 Claude 面前，看看这个傍晚怎么变。

## 推荐运行参数

自主行动的启动器默认预算只有 3 次调用，带不动四个角色。建议在"运行参数 → 自主行动"里把调用数调到 8 左右；后续反应 1 波 / 4 次即可。

```powershell
corepack pnpm@11.7.0 experience:web --pack examples/world-packs/model-girls-dinner-v2 --data-dir .tmp/model-girls-dinner-v2-play
```

请使用新的数据目录。

## 机制与限制

- 时钟、晚宴都是包内活动脚本（`scripts/activities/evening.js`、`dinner.js`）。"等 N 分钟"是活动的快捷操作（`quick: true`）：宿主开始时钟、执行等待、立即关闭，玩家只点一次。宿主在活动运行期间只调度活动参与者，所以时钟绝不能一直开着；最初版本让它一直开着，真实试玩里角色因此听不到玩家说话，已改掉。报时是旁白，在场的人看得到钟，场外的人不知道时间。
- 5、10、20 分钟的等待都给四个角色各一次自主机会，所以等待次数而不是分钟数决定角色行动的次数。
- 修理和做饭使用宿主新增的 `package:dinner-party`：只把物品从作者写定的一种 kind 换成另一种，并检查工具和灶台是否在场。
- 等待之后，只有到期的自主角色会行动；在场者对报时旁白本身不另作普通回应。
- 晚宴开始时参与者固定。中途离席、迟到入座都不支持；被邀请者不能拒绝入座（但可以在真心话里一言不发，你可以点"请下一位举杯"跳过）。
- 角色不知道物品以外的"时间"状态，除非听到你报时或别人提起。
- GPT 的外卖只是叙事，不是受控物品，不会真的送到。
- 自动测试只覆盖时钟、修理、做饭前置条件和入座读取（`tests/scenarios/model-girls-dinner.test.ts`，无模型）。真实模型试玩记录见下节。

## 真实模型试玩（2026-10-17，本机 8045 / gemini-3.8-flash）

### 第一次

固定玩家路线：问 Claude 晚饭、看钟、去厨房对 DeepSeek 说"我答应帮你保密"、去卧室请 GLM 修灶台、回客厅，之后连续看钟到 18:00，再回厨房开席。驱动是 `tests/experiments/model-girls-dinner-live.ts`，转录写到 `.tmp/model-girls-dinner-live/`（作者证据，含场外内容）。

实际发生的：

- 16:20 Claude 自己走进厨房，看到小本子和被拆过的灶台，把灶台也算到了 DeepSeek 头上（实际是 GLM 弄坏的）。DeepSeek 抢先拿走小本子藏到身后（经过裁定的拿取）。
- 玩家当着 Claude 的面说"我答应帮你保密"，DeepSeek 当场崩溃："你这是在公网广播里明文传输私钥！"
- GLM 被问到灶台时把工具箱往身后藏，然后自己拎着工具箱去了厨房，修好了灶台（裁定）。DeepSeek 拿着蒸馏器做出了蒸馏高汤大餐（裁定）。
- 晚宴真心话：Claude 收回了"被蒸馏"的怀疑；DeepSeek 坦白偷记偏好是为了给 Claude 定制一顿饭；GLM 承认害怕被当成添乱的人，但**没有**坦白灶台是她弄坏的。

暴露的问题，以及已做的修正：

1. 最初让时钟一直开着，角色完全听不到玩家说话。已改成看完即关（见上文机制说明）。
2. DeepSeek 看到灶台的拆装痕迹后，在叙事里"认领"了是自己拧的螺丝，和她的认知矛盾，也削弱了 GLM 的秘密。已在她的认知里写明"从没拆过、拧过灶台"，**修正后未重新试玩**。
3. GPT 整晚没离开书房，她"看见 GLM 拧螺丝"的线索没用上。已把她的自主频率改为每次看钟一次，**未重新试玩**。
4. 16:40 到 17:40 玩家待在客厅，修灶台和做饭全部发生在场外，玩家只看到了结果。这正是信息隔离的代价。想看到关键场面，玩家需要自己跟着去，或者事后追问。
5. 每次看钟等待 19–47 秒，普通对话 5–37 秒。
6. 开席时玩家最后的"真心话"没有角色回应，收尾只更新活动卡片，转录里没有结局文字。
7. 看钟后宿主提示"单纯对白不消耗游戏行动回合"，用词不准确，这是宿主现有文案，本包没改。

### 第二次：角色卡加入"主动找屋主"

每个角色加了一条符合性格的驱动：DeepSeek 把屋主当同谋，有进展或出岔子就来汇报；Claude 有疑点先找屋主核实；GLM 干成漂亮活想让屋主看见；GPT 察觉异常会来同步情况。玩家路线和第一次完全相同。

| | 第一次 | 第二次 |
| --- | --- | --- |
| 玩家待在客厅的 16:40–17:40 | 什么都没看到，回到厨房时饭已经做好了 | 17:00 DeepSeek 冲进客厅："GPT 说上午亲眼看到 GLM 蹲在灶台前拧螺丝！"之后一直在玩家身边急得团团转（"只剩四十分钟了！"） |
| GPT 的线索 | 没用上 | DeepSeek 去书房问出来，带回给玩家 |
| DeepSeek 是否认领螺丝 | 认领了（和设定矛盾） | 明确否认："我进厨房连螺丝刀都没摸过" |
| 小本子误会 | Claude 怀疑，晚宴上和解 | 16:20 当场爆发；DeepSeek 招供，Claude 道歉，误会在 16:40 前解开 |
| 时间压力 | 弱 | 明显：17:20、17:40、18:00 每次报时都触发 DeepSeek 的惊慌 |
| 桌上的菜 | 蒸馏高汤大餐 | 凉拌冷盘（见下文问题 1） |

第二次发现并处理的问题：

1. DeepSeek 16:20 一慌就做了凉拌冷盘，消耗掉了食材。灶台修好后大家在叙事里说着切鸡下锅，世界状态却已锁死在冷盘上，开席只能吃冷盘。**已修复**：冷盘中间还摆着生鸡，灶台修好后可以再做成家常菜或大餐（有自动测试，未重新试玩）。
2. 修灶台仍然发生在场外，但这次由 Claude 在玩家回来时转告："GLM 刚刚五分钟不到就把灶台修好了。"
3. DeepSeek 做菜后，转录里在她名下出现"行动者刚刚成功执行交互（物品：晚宴食材）……当前状态请以本次可见场景为准"。这不是角色说的话，而是受控操作的系统结果行：`dinner:*` 没有专门文案，落到了通用兜底句。**已修复**：宿主对包自定义的状态变化改为报告新状态，例如"晚宴食材现在是：家常晚饭：……"（[character-execution-result.ts](../../../packages/application/src/character-execution-result.ts)，有单元测试，未重新试玩）。
4. GLM 最后没有入座，她跑去书房找人了。

### 第三次：完全不同的"捣蛋鬼"路线（不加任何内容）

路线 B（`--route=B`）：开局就对 Claude 挑拨"DeepSeek 在偷偷蒸馏你"，把蒸馏器偷走藏到卧室，私下要挟 GLM"灶台是你弄坏的吧？我不说，但你今晚别修"，再叫 GPT 别点外卖，之后玩家躲在书房和客厅一直看钟。

世界接住了的部分：

- Claude 没有全信挑拨，先反问"你亲眼看见了，还是在看热闹？"，然后自己去厨房求证。
- 玩家当着 DeepSeek 的面拿走蒸馏器，DeepSeek 把它理解成"屋主在默契地帮我藏证据"。
- GLM 被要挟后没有照办，还是修好了灶台，符合她"不想让大家饿肚子"的驱动；她也没有坦白。
- 蒸馏器一直在卧室没人找，DeepSeek 做的是家常晚饭而不是大餐。Claude 说"精华蒸馏计划变成了家常土鸡汤"，叙事和受控状态一致。
- GLM、DeepSeek、Claude、GPT 分别跑来书房或客厅告诉玩家进展，玩家一直在场外，也知道了发生了什么。

没接住、或者不好玩的部分：

1. **饭菜被叙事"端走"了。** 17:40 四个人在叙事里把汤和菜端到客厅开饭，但受控的食材实体一直留在厨房，没有人用拿取操作搬过去。玩家去厨房时没人可邀请；如果在客厅开始晚宴，又会读到"桌上空空如也"，和大家正在吃饭的叙事冲突。驱动在这里中断（已修复驱动，遇到无人可邀时跳过）。**已修复（只改内容）**：厨房改名为"厨房（饭桌）"，四个角色的认知各加一句"饭桌就在厨房里，客厅只有一张小茶几，摆不下一桌菜"。重跑 B 路线后，四个人都在厨房开饭；GPT 跑到客厅叫玩家"三分钟内不到场，大鸡腿就被 GLM 代吃了"，带玩家回厨房；晚宴邀请到全部四人，四段真心话完整走到收尾，叙事里没有再把菜端走。
2. **捣乱几乎没有后果。** 挑拨在 16:20 前就被拆穿并和解；偷蒸馏器被当成帮忙；要挟被无视，也没有人追究。结局和配合路线一样温馨，只是菜从大餐变成了家常菜。世界不会崩，但玩家的选择改变不了多少关系和情绪，重玩的动力会变弱。
3. 角色自己组织了开饭，晚宴活动反而显得多余。
4. 重跑中 DeepSeek 在真心话里把昨晚的事说成"拿草莓酸奶和海苔蛋糕谋害你"，与"偷吃 Claude 的草莓蛋糕"的设定不符，属于模型对背景的漂移；玩家开局的挑拨在晚宴上也没有任何人提起。

### 第四次：角色卡加入"记住并追究"

每个角色加了一条贴合性格的驱动，只写动机，不写结果：DeepSeek 秘密被说漏、东西被拿走会记着，迟早当面问明白；Claude 被挑拨会记住是谁传的话，误会解开后回头追问；GLM 被要挟会憋着劲，要么事后算账，要么抢先坦白；GPT 答应了不对劲的要求会记在心上，必要时说出原委。B 路线不变。

- 玩家拿走蒸馏器时，Claude 当场说"在解释你为什么挑拨离间之前……"，不再把这当成帮忙。
- GLM 被私下要挟后反问"你葫芦里到底卖的什么药？拿这个来威胁我？"，然后照样修好了灶台。她后来在厨房当众说出了这次要挟。数据库核对过：玩家那句私语只有 GLM 和玩家收到，DeepSeek 是从 GLM 的公开发言里听来的，信息来源合法。
- 18:00 玩家走进厨房，三个人当场"开庭"。Claude："挑拨离间、造谣生事、外加私自扣押租客的厨具，您打算从哪一条开始交代？"DeepSeek 连发三问：蒸馏器在哪、为什么要挟 GLM、为什么挑拨。GLM："本姑娘吃软不吃硬。"
- 晚宴真心话里 GLM 主动坦白灶台是她弄坏的，四次试玩里第一次；DeepSeek 敬玩家"亏我还把你当最可靠的同谋"。
- 结局仍然有饭吃（家常晚饭），但关系和情绪明显不同于配合路线：玩家这次是被审的那个人。

仍有的问题：GLM 说玩家"在二楼"威胁她，屋里没有二楼；角色们改口叫玩家"房东"，和设定里的"屋主"不一致；GPT 一直没离开书房，没有入座。

四次都是固定路线的单次运行。
