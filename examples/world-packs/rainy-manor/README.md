# 雨夜古宅：官方跑团活动的验收包

雨下个不停的周末，你和合租的阿茹、澄、梅窝在老公寓的客厅里。柜子里有一盒骰子和阿茹从旧书店淘来的剧本《雨夜古宅》。

例如：你打开“跑团”，勾选阿茹和澄，邀请阿茹主持《雨夜古宅》。阿茹自己决定接不接；接下后，你和澄都读到开场：“雨夜，你们开车穿过山路，车在一座古宅门口熄了火……”。你说“我想用撬棍撬开书房的门”，阿茹判断要做敏捷检定、难度 12，程序掷出 d20。这组点数只有你和阿茹看得到，澄只知道“玩家进行了一次敏捷检定”。阿茹宣布“门锁卡住了，撬棍发出一声刺耳的响动”，这句澄也能看到，她可以自己决定接一句“你小声点！”。阿茹还可以掷只有她自己知道的暗骰。没参加这一局的梅坐在旁边，看不到点数、面板和剧本的秘密，也听不到你在局内说的话；但阿茹和澄在局内说出口的话，她听得见。

## 这个包验证什么

- `trpg.json` 的全部字段：角色卡模板（两项数值、四项技能、d20）、每名 AI 角色的卡面差异、主持人候选（阿茹、梅）、一个剧本、两个预设题目。字段说明见 `packages/official-trpg/src/config.ts`。
- 剧本的真相、结局和标为 `public: false` 的内容（阁楼、阁楼里的老妇人、账本、画像背面的刻字）只有主持人知道。
- 检定点数只给被检定的人和主持人；暗骰只给主持人；没参加的角色什么都看不到。
- 一局结束后，参与者对这一局的记忆带着活动标识（见 `tests/host/trpg-memory.test.ts`）。

## 结构

| 内容 | 位置 |
| --- | --- |
| 地点：客厅 | `locations.json` |
| 角色：玩家；阿茹（爱讲故事，适合主持）；澄（好奇、冲在前面）；梅（冷静、爱挑细节） | `characters.json`、`cognition.json` |
| 物品：茶杯、骰子盒（只是摆设，跑团里的事不碰主世界物品） | `entities.json` |
| 跑团配置 | `trpg.json`（已在 `assetFiles` 登记） |
| 推演脚本 | `.perspectra-lens/scenarios/` 下三份 |

## 验证状态（2026-11-09）

- `corepack pnpm@11.7.0 worldpack validate examples/world-packs/rainy-manor`：通过。
- 三份推演（`node --import tsx desktop/lens/cli.ts simulate examples/world-packs/rainy-manor <名字>.json`）都是 `passed: true`，退出码 0：
  - `scenario-game`：阿茹主持《雨夜古宅》，玩家撬门，点数只有玩家和阿茹知道，澄只知道有过检定并自己接了一句话；剧本的秘密谁也没看到；没参加的梅看不到点数、宣布和剧本（她仍听得见 AI 参与者在局内说的话）。
  - `theme-game`：梅用题目“一场没人记得的生日会”即兴主持，把真相写进私密笔记；阿茹拿到聚光灯后自己提出行动。
  - `hidden-rolls`：对澄的检定点数只有澄和阿茹知道；阿茹的暗骰只有她自己知道。
- 推演只证明规则和信息差，不证明体验。
- 2026-11-09 用 GLM-5.3-Flash 跑了两局脚本化试玩（玩家一方是脚本），见[试玩记录](../../../docs/current/studies/2026-11-09-rainy-manor-playtest.md)：阿茹和梅都接下了主持，7 次检定的讲述和点数一致，回到客厅后大家都把它当成一局游戏；但主持人几乎只用说话讲结果，待处理行动堆积，澄和阿茹很少拿到行动机会；局外的梅听见了阿茹讲出来的线索。没有真人试玩。

## 已知限制

- 题目开局时没有作者写的真相，主持人要自己把真相写进私密笔记。
- 一局里的角色卡、笔记和局内内容在结束后不保留，下一局重新开始。
