# 活动经历结束证据与交付完整度实验

日期：2026-10-02。产物：`.tmp/hosted-memory-20261002-closure-v1`。原始轨迹：`hosted-memory-20261002-v1`，只读。

## 1. 实际解决的问题

第一轮结束 Source 已保存，却被相似度门槛挡住。只交付开场和前几轮时，Claude 角色曾补出“注意力转移，所以搁置”的无依据原因。本轮补齐活动关联和交付结束证据，不继续调编码器或门槛。

玩家与 NPC 结果现在统一通过 `resultMetadata.activity` 提供 id/revision/phase/round/active/lifecycle。复用 PrototypeCharacterTurn 的 executionResult 回调附带宿主观察元数据，只有完整结果的授权接收者获得它；occurrence_only 不带详细元数据。生命周期由已提交结果的 active 状态确定，作者自定义 phase 不充当通用结束枚举。全部观察仍与行动结果同事务提交，没有新数据库表或正式 Memory schema。

Python 实验适配仅接收单个角色的授权档案，按白名单保留元数据。Atom 增加活动关联；Episode 关联该活动的开场和结束 Atom，而不强制一局只形成一个 Episode。不同 Episode 的同一活动可以共享其授权结束锚点，派生关联不改下层 Source 或聚合原有证据引用。

## 2. 交付行为与边界

命中相关 Atom／Episode 后，按已知活动 ID 补入结束和开场原文，不要求结束再通过独立相似度门槛。已有检索排序不变；明确的活动 ID 走授权档案内的精确关联，不增加 RRF 投票。没有 ID 的“那局”仍需先检索命中，不按最近一局猜测。

结束优先、开场其次、原有命中证据随后；仍最多三项、4500 JSON 字符，完整度标注也计入预算。同证据去重；当前上下文已有结尾时不重复交付。trace 区分检索证据与 same activity ending/opening evidence，保留六字段来源、关联依据和完整度状态的来源映射。

材料完整度只说明实际提供的内容。角色授权档案没有结尾时标未知，不把缺失等同“正在进行”。结束证据虽然存在、但本次没提供时，标“已结束，未包含结束记录”；不推断动机，不替角色宣布遗忘。权限和 asOfWorldSeq 前缀校验保留。

旧冻结来源没有 active 字段，本轮导入只识别既有宿主逃生的完整固定结果描述与 host-aborted 元数据；没有宽泛关键词判断或作者阶段名推断。新来源使用结构化生命周期。此识别留在实验适配，不是正式存档兼容机制。

## 3. 固定候选重放

三角色 Source 内容／哈希完全不变。确定性重建行动投影，保留原 Atom ID、原 Episode 分组和原 Observation 文本，不重新调用 retain／group／consolidate 模型。复用原始泛问的召回候选与分数，排除门槛变化；主动 recall 仍在同一授权前缀内使用原索引和既有检索规则。

## 4. 真实 Character Turn

Gemini 3.7 Flash，11 个独立世界分支、19 次实际调用，全部合法 publish。相同问题、人物设定和冷上下文；清空近期观察，没有活动临时状态或私有答案。不人为增加 tick，不反馈新回答到原档案。

| 条件 | Turn 数 | 本次可见结果 |
| --- | ---: | --- |
| 不补结尾、不标注 | 4 | 3 次表示缺少后续；Claude 1 次再次补出注意力转移 |
| 只标注材料完整度 | 2 | 两位均表示已结束但没有结束细节，未补出结束原因 |
| 补结尾并标注 | 4 | 两位各两次均回答玩家使用逃生按钮中止；未出现注意力转移的说法 |
| 未参与的 DeepSeek | 1 | 两次调用交付均空，表示没有这局记录 |

控制条件使用相同的重建行动投影，但不加结尾锚点或完整度标注；不是逐字复刻第一轮旧请求。主动 recall 的查询由角色自由选择，各次可能不同。这里是固定来源的少量案例验证，不能给出普遍正确率或消除采样噪声的因果结论。

## 5. 接受的限制

三项预算中开场和结束占了两个位置。扩展条件仍有回答只提玩家猜数，遗漏 GPT 也曾猜过；本轮证明结尾能够被交付和使用，不证明整个过程或参与者完整复述。没有增加全局参与者摘要、额外重排序或关系认识生成。

Episode 分组仍由模型完成；没有活动 ID、且经历关联有歧义时不强行补结尾。标注不能保证模型绝不新增因果。Observation 生成与严格交付规则未放宽；本轮不是 Observation 行为收益验证。

正式网页仍使用原 CognitiveMemoryService，实验 Hindsight Core 尚未接入网页。新活动观察元数据已在运行时代码补齐，已有存档不改写；本轮未重启或修改玩家正在玩的页面。
