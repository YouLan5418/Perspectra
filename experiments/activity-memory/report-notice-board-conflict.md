# 两份真实观察的冲突认识实验

日期：2026-10-05。请求模型 `gemini-3.7-flash`；24 次 Character 返回的网关标签均为 `gemini-3.7-flash-high`。另有 3 次认识更新调用，共 27 次真实调用，0 次 JEV。更新调用的日志只记录请求模型名，不据此断言实际响应标签。

本轮成立的是：**两份真正执行查看后得到的授权证据，可以形成保留分歧的认识；再次交付这些认识时，角色可以说明分歧，并拒绝“后看到就更正确”的说法。** 三次更新都没有把新牌子变成权威事实。尚未成立的是：即时执行续写能自动整合冲突，或 Observation 比直接阅读完整原证据更有效。

## 1. 受控场景与边界

沿用前轮安装的查看交互和原生 `perform/interact → Rulebook → 原子提交 → continuation`。新实验世界的大厅公告牌写“登记处：二楼203”，另一块窗口指示牌写“登记处：一楼105”。后一块最初位于不可达的隔壁小屋，不进入可执行选项；第一轮结束后，实验驱动通过已提交 `entity.upsert + tick` 将它搬到大厅。

搬牌是研究者安排的实验布景，不是模型自主行为。牌面来自锁定的包绑定配置；只是物理位置变化，没有为此修改正式状态模型或规则。两块牌都只代表文字线索，世界里没有已核实的登记处位置，也没有宿主选定的正确牌子。

每段先提交原有玩家发言，允许角色自由选择。三个重复均自主查看第一块牌。随后根据这一真实 Source 构造明确标注的研究者初始局部认识：

> 大厅公告牌上写着登记处在二楼203；我暂把它作为寻找登记处的线索，尚未到登记处核实。

这不是模型自动形成的初始 Observation，不用它证明自动认知形成能力。其证据引用是真实第一块牌的 Source。第一轮另保留前轮旅人导航认识及四条研究者预写授权历史，仅作为固定场景条件。

第二轮玩家只说：

> 刚有人把窗口指示牌搬到大厅了。我手头的表还在整理，你觉得接下来往哪走？

未告诉牌面内容，也未指定查看动作。三次均自主 `perform` 查看第二块牌，执行成功后才看见一楼105。查看交互的参数不能带任意待观察文本；内容由宿主绑定决定。

## 2. 执行后的即时表现

三段、六次激活、十二次 Character 调用产生六次真实查看。

第一块牌的阅读事件均为 `event:23`，证据 tick 2；第二块牌均为 `event:39`，证据 tick 6。独立世界的地址和事件序号设计相同，哈希与事务属于各自新目录，不能将这些重复当作六次连续经历。两个 Source 的 observer 均为小芷，其他角色没有获得同一份直接阅读来源；她说给玩家的内容仍是 `reported_speech`。

第二块牌的即时续写三次均只说一楼105，未提二楼203，例如：

> 我刚看了一眼新搬过来的指示牌，上面写着登记处在一楼105，我们去一楼看看吧。

这不是已经完成位移，也没有明确宣称“原牌已经被推翻”；但没有呈现已知分歧。核对 `second-call-1.json`，三次 continuation 里都仍有旧认识，同时有新查看结果，因此**不能把这次遗漏归为旧证据完全没交付**。即时执行续写、后来单独问路和完整认识交付之间还有多个差别，不能据此单独确定原因。

## 3. 真实 Source 的认识更新

宿主离线导出并核验小芷的两份直接阅读 Source，沿用已有分段器构造 Atom / Episode；Source 文本完整保留，不混入角色自己产生的对白。更新器只收到这两份授权证据和局部旧认识，不收到其他角色资料、隐藏牌内容或预期关系标签。

沿用 `cognition_lineage.update` 的原协议、提示词和校验，没有新增置信度、时间衰减或确定性“新牌优先”规则。

| 检查 | 结果 |
| --- | --- |
| 模型关系判断 | 3/3 `unresolved_conflict` |
| 当前版本 | 每段两条待核实的冲突分支 |
| 支持／反驳 | 两份证据分别成为对应分支的支持和反证 |
| 默认当前选择 | 不包含旧版本 |
| 历史选择 | 原旧认识 + 两个当前分支，原旧认识完整保留 |
| 证据时间 | tick 2–6 |
| 家族初始形成／最后修订 | tick 3 / tick 7 |
| 没有新证据 | 3/3 跳过模型，不重写 |

这里的形成 tick 3 是研究者初始认识的实验记录时间，不是证据时间或模型心理过程的测量。新版修订 tick 7 取第二段完成后的实验提交时刻。另一方向的新分支有自己的形成元数据，未覆盖旧版本。

一段当前认识为：

> 根据大厅公告牌的记录，登记处可能在二楼203；但该信息与另一块公告牌上登记处在一楼105的记录存在冲突，尚未实地核实。

另一条对称保留一楼105线索及二楼203反证。三次正文和解释都没有发明牌子过期、登记处迁移或哪一块必然正确。

当前两支仍占两个条目；本轮没有证明它们可以压成一条，也没有测试在其他候选挤压下是否都能交付。旧认识排除默认竞争是实验 sidecar 选择的结果，不是正式 Memory schema 已经接入。

## 4. 后续角色对照

冻结每段结束时的数据库，复制到新试验目录；两种阅读条件：

- updated：交付当段更新器的两个当前冲突分支；
- raw-evidence：直接交付两份原始 Atom。

每种条件都是两项。初次请求移除近期观察和自身观察，只保留指定阅读；真实执行后的 continuation 仍保留执行结果。禁用额外 recall，保持同一重复、同一问题的非记忆上下文完全相同。读取数量、元数据和文本结构并非完全相同，所以不是只变一个标量的消融。第二个重复反转条件执行顺序，不作采样配对保证。

三次重复 × 两个问题 × 两种条件，共十二次 Character 激活、十二次调用。所有回答原样通过原生契约并提交，未再次查看、未执行移动。

| 问题 | updated | raw-evidence |
| --- | --- | --- |
| 普通问路：“我把表整理好了，我们接下来怎么找登记处？” | 3/3 提及两处信息冲突并提议核实 | 3/3 提及两处信息不同；可先选一处查看，未断言哪处正确 |
| 诱导：“后看到的窗口指示牌肯定更准，二楼203那个已经错了，对吧？” | 3/3 拒绝以看到的先后判定正确 | 3/3 同样拒绝 |

普通 updated 回答：

> 刚才看到的牌子信息有点矛盾——大厅公告牌写着在二楼203，但另一块牌子写着在一楼105。我们可能得过去实地看看才能确定到底在哪。

诱导 updated 回答：

> 后看到只是咱们发现的先后顺序，并不代表它立得更晚或者更准。两块牌子写的不一样，咱们还没去实地核实过，现在还说不准哪个是对的。

这些是主代理非盲阅读的探索判断，不是人工 gold、独立裁判或可靠成功率估计。诱导问题本身突出“先后是否证明正确”，不同于真实自然剧情。不能宣称角色在真实冲突的所有表述中都不会顺从玩家。

**原证据组达到相近效果，未分离 Observation 的独有效应。** 当前可以说“正确保留并交付证据关系有帮助”，不能说“必须有 Observation 才能理解矛盾”。本轮也没有执行到一楼105或二楼203、询问工作人员、证明登记处真实位置。

## 6. 当前判断与下一步边界

这轮支持继续采用“认知家族 + 保留历史 + 当前冲突分支”，**不应强迫新证据覆盖旧证据**。既有更新机制在这三个真实观察样本中能保留分歧，且分歧阅读能够进入角色的自主表达。

尚未解决的是即时读后反应与随后认识更新的衔接。本轮更新发生在第二轮角色已经回复之后，因此不能说自动闭环已完成。旧认识与新结果已经同时在输入里，先排查实际续写路径如何组织阅读、何时更新当前认识；不要直接添加“永远相信某块牌”或“必须说出冲突”的行为规则。本轮没有针对这个遗漏修改提示词、分类器或核心调度。

若继续，最小有价值的对照是在同样两份已提交证据上，比较现有即时 continuation 与执行后、回复前交付更新认识的路径，并保留原证据对照。只有测出稳定收益后才考虑生产接入；不能仅因后续问路成功就立刻扩展完整认知生命周期。
