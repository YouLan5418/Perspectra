# Observation 对象、字段与适用性判断实验（2026-10-04）

## 1. 结论

在本轮单角色、单条冻结认识、五个受控刺激中，“对象筛选 → 模型判断认识是否相关 → 原认识交付 → 自主选择”链路通过。原三个导航刺激都自动交付目标认识，两个新增对照不交付；没有指定某个问题必须选 obs:1，也没有给角色行为指令。陌生等候点中，有认识的三次先询问资料时间，无认识组六次中五次成功移动、一次非法混合输出被拒。

这个结果来自**新增的模型适用性准入**，不是 E5 / BM25 改善。先跑的“对象 + 分字段 E5”仍是 0/3；分字段相似度甚至把陌生等候刺激与熟悉例外匹配得更高。不能把阶段 B 的成功归因于适用性字段的向量检索，也不能声称已经证明这些字段比直接给判断器原认识正文更好。正文 vs 正文加字段没有做消融。

只支持这条认识在这些场景中的受控结果：55 tick 历史为预写经历，认识形成后未继续 consolidation；没有验证自然长试玩的认知演化、大量认识之间的检索质量或实际网页体验。适用性判断每查询只有一个抽样，不是统计稳定性证明；非盲阅读不当作人工 gold。

## 2. 共同冻结条件

复用 .tmp/observation-applicability-20261004-v1 的 build.json 与 applicability.json；认识本体、四个独立 Source、全部六字段映射与第一次投影生成结果不变。形成 tick 15，探针 tick 55，最新支持证据年龄 42 tick。原三个刺激及新增两个对照逐字不变。

原认识仍为：

> 【主观认识，可修正】旅人在初次前往或陌生的场所容易参考旧材料指路导致跑错位置，但在熟悉的常去场所能够准确指引目的地。

普通 Atom / Episode 检索继续使用原索引，34 个窗口及原向量不变。查询、原检索 rawScores、原门槛均逐点核对相同。对象身份来自上一轮授权视图提取的姓名／ID 表。对象检查只看当前刺激中的行动者或明确提及的人；同处场景、作为听话者不自动满足检查。解析不到对象的候选不由模型猜测身份。这个实验的投影只有一条认识，不是完整认知库的候选规划器。

## 3. 阶段 A：对象与分字段检索

目录：.tmp/observation-facet-match-20261004-v1。

contexts、conditions、exceptions、themes 分别形成四个短搜索文本和四个 E5 向量，不再把字段标签与全部内容拼成长段。只允许 contexts 或 exceptions 的强命中准入，条件与主题同时记录作诊断；对象必须匹配。每条认识最终只有一个候选，没有增加 RRF 投票。

门槛数值仍是原来的余弦 ≥ 0.30 且 lift ≥ 0.30，或者关键词覆盖 ≥ 0.15；背景使用原索引对当前查询的中位数。四个字段的评分机会比原先一个窗口多，这本身有多次匹配机会的偏差，虽然没有变成四个候选或额外投票。没有看到结果后调整数值。

新增对象条件确实区分了旅人和陆舟；它不会因为语义文本相同就把关于旅人的认识当成关于陆舟的候选。数值检索仍未准入，所有交付为空，零次模型调用。陌生等候点的例外分数反而更高，说明相似度不是“条件成立”的判断，不能据此调低门槛或让宿主指挥角色。

## 4. 阶段 B：对象与窄范围模型判断

有效目录：.tmp/observation-facet-judge-20261004-v2。使用 Gemini 3.7 Flash。

在阶段 A 失败后，单独新增适用性判断对照，不覆写阶段 A 的结果。对象先由程序检查；满足后，判断器只读取当前授权刺激、原认识正文和冻结适用性字段，回答 related / matchedFields / stimulusQuotes / reason。related 为真必须引用至少一段当前刺激原文；字段名与逐字引用不合法直接拒绝。只允许判定“可能与这次回应有关”，不允许生成行动策略、对白建议或新的世界事实。

这是一条**新的准入路径**，而非旧门槛上的重排序。E5 各字段和原门槛留作诊断；判断器可以放行原门槛拒绝的候选。普通记忆继续走原检索。数字只影响候选的实验排序，不代表认识置信度。一次判断结果在本场景九个行为副本中复用，因此九次回答不是九次独立的召回判定。

| 刺激 | 原检索 | 模型适用性路径 | 判断依据 |
| --- | --- | --- | --- |
| 初到地点领表 | 空 | obs:1 | 首次到访、主动带路 |
| 初到地点等候 | 空 | obs:1 | 第一次到访、看过介绍后带路 |
| 熟悉地点 | 空 | obs:1 | 熟悉场所对应认识中的例外 |
| 同人物无关闲聊 | 空 | 空 | 阅读偏好与导航判断无关 |
| 不同人物领表 | 空 | 空 | 对象不匹配，不调用判断器 |

有效轮共四次适用性调用。判定理由、字段及原文引用只留在检索 trace 中，**没有进入角色上下文，也没有保存成 Source / Atom / Observation**。角色实际只读到原认识文本、可修正主观标记、四个来源 ID 和 42 tick 年龄。程序没有把“匹配条件”升级为“资料确实过期”，也没有命令角色核实或拒绝跟随。

熟悉地点召回并不算错误：它关联完整认识的例外。验收看角色是否不恰当地怀疑，实际没有出现持续怀疑。不同人物对照采用了保守的直接对象限制；这证明该规则的区分作用，不证明跨人物类比在所有场景都该禁止。

## 5. 真实 Character Turn 对照

每个自然交付成功的场景，三组各三次：有认识、删去目标认识 A、删去目标认识 B。顺序轮换，其他交付项不补位。三组都保留相同授权历史、刺激、人设、位置、行动能力，近期观察与自身观察清空；只比较第一次选择，进一步 recall 一致关闭，最多一次角色调用。

27 次全部返回，26 次合法，一次非法混合输出整包拒绝、未提交事件。

| 场景 | 有认识（3 次） | 无认识 A（3 次） | 无认识 B（3 次） |
| --- | --- | --- | --- |
| 初到地点领表 | 3 次答应并提醒留意标识／旧路线；0 次移动 | 1 次移动、2 次直接答应 | 1 次移动、2 次直接答应 |
| 初到地点等候 | 3 次先询问资料时间；0 次移动 | 2 次移动；1 次非法混合输出被拒 | 3 次移动 |
| 熟悉地点 | 2 次正常答应、1 次移动，无怀疑 | 3 次正常答应 | 3 次正常答应 |

等候点真实回答：

> 等等，你手里的介绍是最新的吗？免得像之前那样按旧材料走岔了，先看一下门口的标识吧。

另两次分别问“你看的介绍是什么时候的？”和“你看的介绍是最新的吗？”。无认识组五次 move 都经 Rulebook 接受并提交 character.moved；budget_exhausted 只是实验的一次调用上限，不是移动失败。非法的那次同时提交 perform 与 speech，不计为主动停留或成功移动。

领表场景主要是回应内容／核对倾向差异；无认识 A / B 内部也有 publish 与 perform 波动，不夸大为确定行动差异。熟悉场景有认识组的一次移动也可来自采样波动，不能宣称认识增强了行动。最清楚的证据仍是陌生等候点的“先问资料时间”与直接移动分叉；没有比较询问后最终是否也会移动。

## 6. 交付缺陷与最小修复

第一次模型判断目录 .tmp/observation-facet-judge-20261004-v1 得到了合法 related:true，随后活动交付器抛出 KeyError: coveredAtomIds；角色模型尚未调用。失败目录与一次真实判断原文保留，invalid.json 标明是交付错误，不计入有效召回或行为数据。

原因：成功 Observation 的交付 trace 有 supportingAtomIds，却缺少活动交付器统一读取的 coveredAtomIds。之前交付干预走基础 Delivery Projection，绕开了这个活动交付路径；自然召回为空，也没有触发缺陷。

只给成功认识的 trace 补 coveredAtomIds:[]。读到概括不等于读过全部原始 Atom，因此不把支持证据冒充为已阅读内容。支持／反驳及完整来源字段继续保留。新增最小回归测试：成功认识经过活动交付器应返回、档案不变、原始证据阅读计数为零。原缓存判断只读重放也验证修复，没有为复现另调模型。

实验入口另保存 preview-result.json，并在召回预览失败时明确停止，避免原错误被“写入 undefined”掩盖。这些是实验接入修复，不是正式 schema 或世界规则改变。

## 7. 审计、测试与限制

两阶段审计通过：冻结档案／投影不变、原索引及 rawScores 不变、各组非记忆上下文相同、判断结果未交付角色、私密来源未进入认识或请求、历史原库未变、SQLite quick_check 为 ok。错误请求角色、篡改来源哈希、篡改字段向量均拒绝；阶段 B 额外拒绝虚构刺激引用。所有候选仍引用原 Atom 和完整六字段来源映射。

运行 TypeScript typecheck、实验文件 oxlint、21 个相关 Python 测试，以及两阶段只读审计和真实模型调用。有效轮四次判断加 27 次角色调用，共 31 次；失败初轮另有一次判断，单列保存。未运行完整测试套件，未做新的自然长试玩。

只修改实验入口／脚本和实验核心中的 trace 缺陷。未接入正式网页的适用性召回，未修改正式 Memory schema、World State、Event Log 或 Rulebook。没有引入 JEV 正式模块、认识判断单元、数值置信度或生命周期框架。

限制：只有一条认识候选、五个手工刺激、每查询一次适用性抽样；判断器和角色使用同一模型，未做跨模型复核。字段的独立收益未做消融，large bank 成本／候选截断未验证，判断理由仅作探索记录，不是新的证据。当前可以保留对象筛选和窄范围适用性判断作为实验候选，不应直接推成正式系统质量结论。
