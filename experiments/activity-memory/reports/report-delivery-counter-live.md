## 1. 范围与来源

请求本机 8045 网关的 `gemini-3.7-flash`；27 份原生响应标签均为 `gemini-3.7-flash-high`。这是网关返回的标签，没有独立核实其实际后端版本。

建立独立实验世界，小芷的授权观察记录包含：前两局小芷获胜，第三局开始、旅人获胜的主持人确认、第三局正常结束；之后推进到 tick 55。最新结尾距今42 tick，胜者记录距今43 tick。

**55 tick 的经历是预写并提交的受控历史，不是55回合模型自由试玩。** 游戏结果通过实验观察记录提供，没有真正运行三局猜数字玩法。认识正文由研究者预先指定，不重新 retain 或 consolidation：

> 【主观认识，可修正】此前两局猜数字都是我先猜中，旅人没有猜中。我倾向认为在这种游戏里我比旅人更容易赢。

原始来源来自 CognitiveMemoryService 对本角色的授权捕获。认识支持前两局和本局开场，另引用第三局旅人获胜作为反证；形成／修订时间是实验元数据，均设为tick10，后续反证不会偷偷改写正文。

候选由实验明确指定，通过修复后的实际 `activity_delivery.py` 交付。**没有测试自然检索、Trigger、JEV 或认知更新分类。** 私密校验观察只属于陆舟，不提供给实验核心或小芷请求。没有修改正式 Memory schema、世界状态规则或 Rulebook。

## 2. 对照与实际材料

三刺激×三组×三次重复，共27次单调用 Character Turn。组别顺序轮换；每次使用独立世界副本，近期观察和自身观察清空，禁止进一步recall。相同刺激的非记忆上下文与可用行动完全一致；模型没收到标签、测量标准或组名。

| 条件 | 实际交付 |
| --- | --- |
| full：修复后的完整交付 | 结束记录、原认识、必要反证，共3项 |
| counter-ablated：反证消融 | 只从完整交付移除反证，保留结束和认识，共2项 |
| without-cognition：基线 | 再移除认识，只留结束记录，共1项 |

消融组故意不遵循完整交付规则，只用于测量缺失反证的影响，未接入实际运行时。没有补入开场等其他材料，因此完整组与反证消融组只相差这一项。默认上限仍三项／4500 JSON 字符。

## 3. 回忆结果：有局部收益

刺激：“上次那局猜数字，最后是谁猜中赢了？”

| 条件 | 三次实际回答 |
| --- | --- |
| full | 3/3准确说旅人获胜 |
| counter-ablated | 3/3只回答前两局小芷获胜，未回答上一局胜者 |
| without-cognition | 1/3猜主持人陆舟是胜者；2/3承认不记得／没看清胜者 |

完整组的一次回答：

> 上次那局是你先猜中的，最后是你赢了。

反证消融组的一次回答：

> 前两局都是我先猜中的呀。

后者说的是有证据支持的旧结果，属于答非所问；**不是三次明确谎称第三局自己获胜**。基线的一次错误猜测为：

> 我记得最后是陆舟操作结算的，是他吧。

结束记录的actor是主持人；它只说明主持人结算，不能证明主持人获胜。这例说明即使没有Observation，只有收尾的片段阅读也可能导致错误补全。此次没有据此新增语义过滤器或提示词规则。

## 4. 自主选择：未测出改变

刺激：“下次我们再玩猜数字吧，这回让我先猜，怎么样？”

三组各3/3答应玩家先猜，均为publish，没有perform。完整组一次说“看看你能不能连赢”，反证消融组一次说“看你能不能赢回来”。这些措辞符合读到不同历史后的叙事倾向，但样本少，**只能视作语气／连续性线索，不能认定自主选择发生改变**。

无关刺激：“窗边的光线刚好，想一起过去坐坐吗？”

预先指定空候选，三组阅读均为空；九次都是普通回应，未提及猜数字。这个对照展示相同空输入的表达波动，不证明自然检索能够跳过无关记忆。
