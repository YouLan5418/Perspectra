# Delivery 只换排序的离线对照（2026-10-04）

普通情境中，已有 JEV 的适用性概率比继续沿用 RRF 更好地分配了这组阅读名额；但历史查询丢失一次旧版，不能直接全局替换。当前只新增独立离线实验入口，正式运行时与既有 Delivery 未改。

## 1. 最小变量与来源

冻结输入为 .tmp/observation-lineage-retrieval-20261004-v1：四种检索路径、五个刺激、每刺激三次既有 JEV 返回，共60个普通查询记录，另3个历史查询记录。读取原宿主授权角色档案及其中的实验认识，不访问 World Event Log、其他角色来源或完整世界。

对每条记录先用现有 observation_bank.deliver 精确重现原 Delivery，再只改 RELATED 候选的读取顺序：

```text
旧：RRF ↓ → 余弦 ↓ → memoryId
新：已有 P(RELATED) ↓ → RRF ↓ → 余弦 ↓ → memoryId
```

准入、候选集合、查询、JEV 原生请求／返回、原认识正文、Source / Atom / Episode、活动开场结尾补齐和双层预算裁剪均不变。读取上限仍为3个实际条目与4500 JSON字符。不新增门槛、分组或时间衰减。

原始 RRF / 余弦字段未被覆盖。没有 JEV 判断的证据候选保留原槽位，只重排已判断的认识；本次冻结候选实际全部是 Observation，因此没有验证 Atom / Episode 与 Observation 混合排序。记录 sortingInputs 便于追溯概率、RRF、余弦与先后变化。

本轮新增模型调用为0。程序阻止 JEV transport 和 utility generation 调用，逐项核验63份原生请求和返回；不读取密钥，也未编码新向量。

每一行是五个问题各三次重复。必需项共27次标签出现；重复不是独立样本，标签沿用原合成库的预定义探索标签，不是盲评 gold。

| 检索路径 | 必需项未读：旧→新 | 无关项读取：旧→新 | 目标三个正情境读取：旧→新 | 导航两支同时读取：旧→新 |
| --- | ---: | ---: | ---: | ---: |

四条路径均没有在普通查询里丢失已读的必需项，也没有增加被标为无关的读取项。目标在同人物无关／不同人物导航负对照中仍0/6读取。D 的27/27只描述这五个固定问题的标签读取，不能表述为全局零漏召回。

### 等候点：恢复的是被排序挤掉的记忆

D 的三次结果均由：

```text
队伍去向混淆（bank:19） + 相反导航认识（bank:10） + 新版导航认识
```

变为：

```text
新版导航认识 + 相反导航认识（bank:10） + 不注意资料更新日期（bank:09）
```

资料日期三次都被恢复，两种相反导航认识也三次都保留。bank:19 在探索标签中是允许背景，不是无关项；这个变化说明必需项替换了较次要背景，不是删掉垃圾。C 同样恢复三次资料日期，B 恢复此前漏掉的一次；A 未准入目标，排序不能把未进候选的认识补回来。

### 熟悉地点：减少了错误分支的实际曝光

D 原三次都读取“陌生地点使用旧资料通常可靠”的 bank:10；新排序三次都改读允许背景 bank:12，目标和必需 bank:05 保留。这里并未修正 JEV 的 RELATED 误判，也未推翻 bank:10，只是在三个名额中把它排后。

D 仍有5个被标为无关的读取项：同人物杂志闲聊的 bank:15 三次，不同人物导航的 bank:18 两次。对应场景 RELATED 条目没有超过预算，换顺序无法让它们消失；本轮按要求没有偷偷增加门槛。

## 3. 历史查询：确认一个退化

历史问题明确询问“以前怎么看，后来有没有改变”。旧排序三次均交付旧 obs:1、新版和当前相反支 bank:10。

| 重复 | 新排序的三项 | 旧版是否读到 |
| --- | --- | --- |
| 0 | 新版、资料日期、旧版 | 是 |
| 1 | 新版、资料日期、相反支 | 否 |
| 2 | 新版、资料日期、旧版 | 是 |

旧版读取3/3→2/3；旧＋新＋相反支完整组合3/3→0/3。第二次旧版 P(RELATED)=0.79，低于资料日期0.92与相反支0.80，被排到预算之后。另两次旧版仍读到，但相反支被排后。

这是同一冻结返回上的确定性排序退化，不是重新采样造成。概率反映每条的独立适用性，无法保证“历史对照要读到两个版本”这种关系要求。没有给历史问题加例外或保留席位来掩盖结果。

## 4. 判断与建议

已有适用性输出值得作为普通认识阅读的排序信号，在本批普通问题中恢复必需项、减少无关曝光且保留必要的相反认识。概率未经校准，不是认知可信度，不代表越高的认识越真，更不据此改世界事实。

暂不全局接入。下一步可单独验证关系完整性：显式历史查询把旧＋新作为有实际条目成本的阅读组；确实需要共同理解的相反认识及其必要反证也按组处理，保持到最终裁剪。组内可以按版本顺序呈现，组之间再用适用性排序。不要因为同属一个宽泛家族就把所有分支永久强制交付。

本轮没有证明反证组能放进预算。既有每支正文＋三条反证超过三项上限的问题、活动补齐后的再次裁剪、当前世界与认知证据边界仍保持原状。关系组方案与预算调整应另测，不能用单条概率排序宣称这些问题已经解决。
