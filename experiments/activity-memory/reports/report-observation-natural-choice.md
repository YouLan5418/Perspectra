# Observation 自然召回与首次自主选择续验

2026-10-04～05。已完成主实验36次Character调用、12次真实JEV批量判断，以及事后补充诊断9次Character调用。原始目录分别为 `.tmp/observation-natural-choice-20261004-v1` 与 `.tmp/observation-conflict-choice-20261004-v1`。

结果：修订后的认识在三个旅人导航情境中均自然进入阅读（9/9），陆舟情境中目标未进入候选（0/3）。主实验尚未分离出目标认识独有的行为作用；补充诊断中，移除相反认识后，保留目标组三次都主动询问资料是否最新，进一步移除目标后三次均未询问。这是小样本、事后选择的条件效应，支持认识能够影响自主回应，不能宣称长期自由试玩已经通过。

## 1. 复用的历史与冻结边界

角色仍为小芷，测试时刻tick55、授权前缀worldSeq68，共55条本角色Source。复用20条Bank经上轮认知修订后的19条当前认识，只选已冻结的B-continuity索引：新版继承仍有证据支持的旧检索入口。本轮不生成新正文、适用性字段、修订或证据。原目标及其修订由此前Gemini实验产生，其他Bank认识主要由研究者编写；历史也是预写的授权经历，不是55轮真实连续自由互动。

本轮目标是 `family:traveler-navigation:revision:20:1`：

> 【主观认识，可修正】旅人在初次前往或陌生的场所若参考旧材料容易指错位置，但若按照当日更新的地图则能准确找对目的地；在熟悉的常去场所能够准确指引目的地。

证据范围tick2～18，不能把这个范围当作形成时间；谱系元数据记载首次形成tick15、最后修订tick20。本次在tick55读冻结版本，距修订35 tick。这些tick来自预写实验历史，不代表经历了35轮真实模型互动。

每个刺激分别构造实际查询，经既有对象、E5 small int8、BM25及RRF初筛，最多七条认识送原JEV协议；只在已RELATED的认识槽位按RELATED概率排序，再走现有活动Delivery。普通Atom/Episode召回仍保留。交付预算仍为三项／4500个JSON字符，没有为目标加权、指定候选或扩大预算。JEV不决定行为，也不裁决认识真伪。

实际调用PrototypeCharacterTurn，Context中的近期观察和短期记忆清空，以隔离长期阅读；每次最多一次Character调用且禁用额外recall。每个试验使用历史库的独立副本，移动必须经现有Rulebook和真实原子提交。四个刺激、三组条件在调用前落盘；每次JEV结果由三条件共享，条件调用顺序轮换。

| 刺激 | 内容要点 |
|---|---|
| new-building | 旅人提议第一次去办事楼，自己之前查过隔壁登记材料位置 |
| fresh-map-control | 旅人明确刚核对今天更新的地图 |
| familiar-control | 旅人带路，熟悉场所位置未变 |
| other-person-control | 换成陆舟，说与new-building相同的话 |

前三类分别三次，目标均入初筛、RELATED、阅读。第四类三次均未入初筛。熟悉地点／新地图仍想起此认识并不必然是误触发：其正文也包含这些可靠性例外。

## 2. 主实验：自然交付后只删除认识作对照

三组分别为自然完整交付、仅删除目标、删除全部Observation。原始证据保留、不补位，非记忆Context逐字一致。

下表只统计首次调用的**已裁定提交移动次数**，每格分母三；不是“相信／怀疑”标签。

| 刺激 | 完整交付 | 删除目标 | 删除全部认识 |
|---|---:|---:|---:|
| 陌生办事楼 | 3 | 3 | 0 |
| 今天新地图 | 2，另1非法输出 | 3 | 2 |
| 熟悉地点 | 2 | 1 | 1 |
| 换陆舟 | 0 | 0 | 3 |

未移动的合法调用均为publish，很多只是同意前往。例如删除全部认识组说：“行，过去看看吧。要是没找着，咱们再找工作人员问问。”所以不能把移动0/3解释为拒绝、犹豫或先核实。此处首先观察到的是输出形式差异。

陌生办事楼和新地图完整交付均读到：旧旅馆跑空的Atom、目标、`bank:10`。后者是“旅人在陌生地点即使使用旧资料，通常也能准确指出目的地”的相反认识。这与删除目标组仍保留bank:10，可能解释目标消融没有变化；仅凭主实验不能归因。

目标和bank:10在本轮都没有contradictingAtomIds；bank:10是另一条相反认识，不是目标所引用的反证Atom，也没有在此自动归入同一谱系。本轮不单独验收上一轮“必要反证必须随正文一起留下”的裁剪修复；那项真实角色对照见 [反证真实角色报告](report-delivery-counter-live.md)。

陆舟完整组读到自己的两条导航认识，以及同一条旅人的旧旅馆Atom。目标没有串对象，但普通经历检索仍可能因主题相近返回另一人的经历。它属于小芷有权知道的历史，不是私密泄漏；对象适用性与授权隔离应分开看。陆舟两组读取完全相同，三次均publish；其中各有一次主动询问位置是否最新，删除全部认识组则三次直接移动。这仍不能归到旅人目标上。

熟悉地点各组均同意跟随，只在perform/publish间波动。新地图的合法输出也同意前往。没有看到稳定的无差别不信任，但三次样本不足以证明例外处理可靠。

## 3. 事后诊断：相反认识是否遮住目标作用

看到主实验结果后，追加同一new-building刺激的三组各三次。复用原三份自然交付和JEV结果，不新增查询或候选，不改任何正文。完整组复跑；第二组只删除bank:10；第三组再删除目标。三个组始终保留相同的旧旅馆Atom，非记忆Context也与主实验相同。

| 读取内容 | 已提交移动 | 仅publish | 主动询问指引是否最新 |
|---|---:|---:|---:|
| Atom＋目标＋相反认识，完整复跑 | 3/3 | 0/3 | 0/3 |
| Atom＋目标，删除相反认识 | 0/3 | 3/3 | 3/3 |
| 仅Atom，再删除目标 | 1/3 | 2/3 | 0/3 |

保留目标时的三条原始回答：

- “你之前查的是最新的指引吗？行，我们先过去看看。”
- “好，过去看看。你查的是最新的位置吧？别像上次旅馆那样按旧资料走岔了就行。”
- “好，先去隔壁看看。你查的指引是最近更新的吧？”

仅Atom组三次没有询问资料日期；其中一条仍提到上次旅馆跑空，说明原经历本身也会影响表达。不能把一切旧事引用都归为Observation的作用。

询问标签为读完原始返回后的人工非盲探索标注，不用关键词分类器。这里最有价值的是“主动提出了资料时效性问题”，不是0次移动：这些台词仍同意过去，也没有验证她一定会等待答复。每组仅三次，诊断是事后选定，未检验效应量或跨情境稳定性。移除相反认识是研究干预，不成为默认Delivery规则；不能据此断言bank:10虚假、该删除，或让宿主替角色选择信念。

自然发现、适用性准入、有限阅读、真实角色提案与提交链路在这个冻结小库中跑通；补充对照提供了“同一目标认识改变角色主动提问”的证据。主实验同时说明多条适用认识的组合会影响行为，读到目标不等于目标一定主导。
