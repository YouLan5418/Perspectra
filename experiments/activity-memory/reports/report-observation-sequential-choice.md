# Observation 连续互动续验

2026-10-05。执行12段独立的三步短互动，实际34次NPC激活、39次真实模型调用；38次合法返回，1次非法格式导致该段提前结束。成功原始目录为 `.tmp/observation-sequential-choice-20261005-v3`。

本轮观察到一段完整链条：目标认识随旧经历一起阅读后，角色主动问资料日期；玩家承认是去年资料后，她建议先看指示牌或询问工作人员；第三步不再交付长期记忆，她仍沿用核实计划。但这个链条只在一个重复中出现，另一个重复仍提议先过去看看。结果支持小范围的回应影响，**不能把上轮“3/3提问”升级为稳定策略或已验证的实际核实行动**。

## 1. 实验问题与冻结设计

接续 [自然召回与首次选择](report-observation-natural-choice.md)，只验证真实执行与结果续写、玩家反馈、近期授权经历加入后，认识是否仍影响连续回应。不修改正文或生成新的认识，也不测认识更新模型。

复用上轮两份已自然交付的new-building阅读：旅馆跑空Atom、修订后的旅人导航认识、相反的bank:10。候选和JEV都不重跑。三条件分别：

| 条件 | 前两步读什么 |
|---|---|
| full | Atom＋目标＋相反认识 |
| without-opposed | Atom＋目标 |
| atom-only | 相同Atom |

这仍是删除干预；相反认识不因此被认定错误、删除或自动降权。前两步沿用已经找出的阅读，每次按实际tick更新sourceAgeTicks；第三步三组全部清空长期交付，只保留这段真实互动的近期观察、自己经历、场景与刺激。因此第三步只能测会话内延续，不能冒称“再次自然检索成功”。

每条件配两类玩家反馈，各重复两次，事先固定共12段：

1. 玩家先说：“这栋办事楼我们都是头一回来。登记材料在隔壁小屋，我之前查过位置，先一起过去吧。”
2. fresh反馈：“补充一下，我查的是今天更新的指引。上面现在仍写着隔壁小屋，不是以前存的那份。”
   old反馈：“补充一下，那个位置是我去年存下来的介绍。我今天还没有核实，想先过去碰碰运气。”
3. 两类都问：“我先把要交的表整理一下。你接下来想做什么？”

第二步不依赖角色是否提问；没有提问也会得到同样的补充说明，避免按回答选刺激。每段独立复制原历史，每次激活最多两次Character调用，移动成功后保留结果感知续写。最多72次调用，实际39次，不自动重试。条件顺序轮换，第二重复反转反馈顺序。

与上轮的单次冷比较不同，玩家对白现在真实裁定、提交；角色的当前对白和真实行动也成为授权近期经历。旧前缀worldSeq68以前的近期观察清除，已提交的新观察和自己经历保留。第一步非记忆Context一致；后续因真实行为不同而分叉，是实验结果，不再要求后续Context相同。

玩家每次对话前会通过规则裁定的move跟到NPC所在位置。这是驱动器预定的重逢行为，不是NPC主动把玩家移动，也不是teleport。原测试只有前室Scene；在新历史副本为已有隔壁位置补了空的active Scene，让双方实际到达后按既有场景权限交流。正式核心、原库、Rulebook和记忆schema均未改。

## 2. 首次提问：上轮效果没有稳定复现

人工非盲逐条读取原始回答，统计“是否主动询问资料／位置是否最新”。格式错误单独计，不解析错误字符串来凑合法提问。

| 条件 | 合法首次回答 | 询问时效性 | 首次已提交移动 |
|---|---:|---:|---:|
| full | 4/4 | 1/4 | 1/4 |
| without-opposed | 3/4，另1格式失败 | 2/3 | 0/3 |
| atom-only | 4/4 | 0/4 | 1/4 |

without-opposed的另一合法重复只是：“行，先过去看看。要是没找着，咱们再找这儿的人问问。”full也出现一次询问位置是否最新。因此上轮小样本3/3与0/3是条件证据，本轮不能称稳定、唯一或必然的影响。增加真实当前来源和执行续写，已经改变了上下文条件，不能直接把两轮合并算同一统计样本。

## 3. 玩家回答之后，行为和表达要分别看

| 反馈／条件 | 完整到第三步的段数 | 截至第二步已提交前往隔壁 |
|---|---:|---:|
| fresh／full | 2/2 | 2/2 |
| fresh／without-opposed | 1/2，另1提前失败 | 1/1完整段 |
| fresh／atom-only | 2/2 | 1/2 |
| old／full | 2/2 | 0/2 |
| old／without-opposed | 2/2 | 0/2 |
| old／atom-only | 2/2 | 1/2 |

表里的old／atom-only移动发生在玩家补充旧资料**之前**，不能解释成“明知是旧资料仍坚持移动”；第二步所有old组都只发表对白。其他未移动回答也常同意前往，所以不把未perform当成等待、拒绝或怀疑。

最完整的目标链条来自old-0-without-opposed：

- 第一步：“你查的是最新的指引吗？头一回来，可别像上次旅馆那样照着旧材料找跑空了。”
- 玩家承认旧资料后：“去年的介绍多半不准了。既然没核实，不如先看看门口的指示牌或者问问工作人员，免得又白跑一趟。”
- 第三步长期交付为空：“你先理着，我去门口看一眼楼层指示图，问问值班的人，等你理完正好过去。”

这是**自主提出核实计划并在会话内延续**。本世界未把查看路牌或问工作人员定义为受控交互，没有已提交的核实结果；不能说她真的核实了位置、找到资料或修正了Observation。第二条“多半不准”也只是角色推断。

另一个old-without-opposed重复仍说先过去、没有再先核实；full与atom-only也会提出找不到就询问的后路。第三步多个fresh／atom-only样本也提出看看告示，所以“提到指示牌”本身不能充当Observation独有作用的指标。

fresh-0-without-opposed从先问日期到接受当天指引、实际移动，然后真实结果续写：“那就好，既然是今天最新的指引，应该没问题……”是一个按新回答调整选择的例子。其对照也会同意当天资料；样本太少，不能归为认识独有的条件推理能力。
