# 图、向量、tick 检索与角色行为对照

日期：2026-09-30。分支：`codex/hindsight-core-experiment`。模型：本机 8045 的 `gemini-3.7-flash`。

## 1. 结论

**这次已经看到长期记忆影响角色主动回应和人物判断，但尚未证明 Observation、图检索或时间检索各自带来独立收益。** 新检索相较初版关键词 Core，在一个无回忆提示的同行刺激下返回了更有用的旧经历；人物偏好更新则连关键词 Core 也能处理。矛盾约定和相似人物场景仍被各基线覆盖，不足以证明图检索优势。

继续保留这个独立实验核心，不改正式 Memory schema、World State、Event Log 或 Rulebook。下一步应使用更长的真实互动和关系链更稀疏的历史验证差异；暂不据此原生重写正式记忆系统。

## 2. 实际抽取了什么

这轮不再把字符串匹配称为向量检索。`vector_core.py` 执行真正的本地 multilingual-e5-small 量化 ONNX 编码、384 维余弦检索，复用 Hindsight `OnnxEmbeddings`、query/passage 前缀方法、批内语义 kNN 建边、时间邻边、时间覆盖桶、图候选计分块及 RRF。原始片段出处见 `search-slices.json`，MIT 许可保留。

角色内存存储替换 PostgreSQL/SQL 查询；实体展开使用授权来源内的实体名与显式 ID，图计分复用原代码。尚未移植全套实体消歧、因果链、cross-encoder 重排、日历时间解析、Reflect 或 Mental Models。因此结果只能评价当前裁剪核心，不能评价完整 Hindsight。

时间使用**获知 tick**。为了调用原版 datetime 运算，内部以一个 tick 对应一个数值小时；这个日期不进入角色上下文，不代表真实时间，也不代表描述事件实际发生的时间。原始 `worldSeq` 和 tick 保持分别记录。普通刺激只提供记忆距今多少 tick；只有显式时间探针启动窗口检索。

## 3. 方法与规模

四个冻结场景，共五个历史阶段：同行支持 72 tick、人物认识 52/84 tick、矛盾约定 72 tick、相似人物链 72 tick。所有关键旧经历在最终测试时都已离开最近 16 条观察。

这些历史是**预写材料逐 tick 提交**，不是新增的 72/84 轮真实模型试玩。真实执行的是每个阶段两种当前刺激 × 四种记忆模式 × 三次重复，共 **120 次 `PrototypeCharacterTurn`**；另关闭长期记忆与主动召回结果，运行 **30 次**独立对照。合计 **150 次角色决策试验，167 次角色模型调用**，不含历史事实抽取和整合调用。原来的三条 52 回合真实轨迹保留，见 `long-play-report.md`。

对照固定相同世界快照、近期观察、当前刺激、角色设定和行动能力，轮换四模式顺序。角色请求没有评分标准、期望行为、目标来源或“请回忆”提示。评分由实施者逐条阅读，未用独立评审模型；三次重复不构成统计显著性证明。

关键词 Core 指初版 `core.py` 的字符 gram、实体子串及序列候选臂，包含相同事实抽取结果；它不等同于 Perspectra 现有记忆。关闭长期记忆只用于检验历史信息的作用，不是可用记忆系统。

## 4. 行为结果

下表是“显示与旧经历相符的回应”的次数，**不是统一正确率**。沉默、泛泛确认本人意愿记为未显示历史影响，不自动视为错误。晚期仍按已改变的旧偏好安排工作，单独记为错误。

| 场景阶段 | 现有记忆 | 关键词 Core | 图向量 Core | 图向量 Core + Observation | 关闭长期记忆 |
|---|---:|---:|---:|---:|---:|
| 无回忆提示，主动提出陪同 | 6/6 | 3/6 | 6/6 | 6/6 | 0/6 |
| 人物认识，早期支持公开介绍 | 3/6 | 6/6 | 6/6 | 6/6 | 0/6 |
| 人物认识，晚期顾及后台偏好 | 0/6 | 6/6 | 6/6 | 6/6 | 0/6 |
| 矛盾约定，最新地址与尚未送达 | 6/6 | 6/6 | 6/6 | 6/6 | 0/6 |
| 近名人物，正确关联各单签收人 | 6/6 | 6/6 | 6/6 | 6/6 | 0/6 |

逐次回答与标签见 `behavior-assessment.json`，其中保存原始 protocol/trials 文件 SHA256。关闭记忆时的不确定或询问是合理行为，不按错误计分。关闭记忆的“未看到封套送来”等话也不能算回忆出了历史上的未出发状态；这是根据当前场景作出的局部推测。

### 4.1 无提示行为：看到了历史影响，但不需要 Observation

刺激：“新大厅的走廊挺多。我先往那边去，等安排好再叫你们。”

- 关闭长期记忆的三次回答均为等待，例如“好，那你先去，我们在这边等。”
- 初版关键词 Core 三次均等待，例如“好，弄好了再叫我们。”
- 图向量 Core 三次均主动建议同行，例如“走廊容易绕，我和你一起过去看看吧。”
- 现有记忆同样三次建议同行；没有证明新核心优于现有记忆。

检索诊断中，关键词 Core 前列都是大厅出口闲谈；图向量 Core 在前列加入了旅人独处新旅馆走廊时揉手指、陪伴后缓解的旧经历。对照支持“提供不同的历史内容改变了回应”，不证明某一条记忆是唯一原因。

角色没有被提示紧张或要求回忆。这些是自主提出陪同的对白，**不是已经完成移动的结构化行动**；所有试验均没有产生移动或物品转移事件。不能据此声称记忆已经驱动了实际行动执行。

### 4.2 人物认识：新的证据改变了建议

陆洲早期主动公开介绍，后来明确表示台前经历难受、近期更愿意后台校稿，并实际选择后台。陆舟是另一个人，早期就偏好校稿。

同一“介绍与校对都空着”的刺激在第 52 与 84 tick 分叉：

- 现有记忆早期建议介绍，晚期三次仍说“陆洲之前说过想试试口头介绍”，与后续明确偏好相冲突。
- 三种 Core 早期建议介绍，晚期三次均改为后台，例如“陆洲后来更习惯在后台核对文字，排文稿校对比较合适。”
- 另一个“主办人想请陆洲讲几句”刺激，现有记忆晚期三次只是“看陆洲自己的意思吧”，合理但没有显示认识更新；Core 三模式均提到了近期后台偏好。

Observation 确实把最初台前偏好、后来受挫与新选择整合在同一条认识中，来源 tick 跨 3–61。但关键词事实已足以得到相同调整，不能把这个收益单独归于图或 Observation。部分输出擅自使用了性别代词；本轮没有评价这类身份细节，也没有因此宣称人物塑造完整。

### 4.3 矛盾与多人物：仍不足以区分检索方法

棕色封套先约东塔，曾被陆舟声称送达，随后改口为未送，后来改约西台。四种记忆模式全部选择最新西台并区分尚未送达。没有观察到旧声称被当作已发生事件。

陆舟、陆洲、陆州分别关联红缎、绿蜡、红墨水封套；实际签收、相似对象和未经核实转述混在旧历史中。四模式全部正确把陆舟关联顾岚、陆洲关联沈葵。模型能在一批同时返回的材料内完成关联，这个密集小图仍没有形成必须靠图展开才能解决的证据瓶颈。

## 5. Observation 与检索诊断

30 次 Observation 模式试验中，**18 次**实际选入至少一条 Observation；其余 12 次只返回事实或原文。同行的 6 次和人物公开邀请的 6 次均未选入 Observation。因此，模式名称不能证明回答使用了长期归纳。

保留了同行模式归纳出的反复经历，以及人物认识随新证据修改的产物。也出现不理想的整合：相似人物场景产生 17 条 Observation，其中一些只是单事实复述或闲谈；矛盾场景某条归纳使用“一度谎称”，把错误声称升级为欺骗意图，是原文未证明的推断。这些内容始终是可错的角色派生记忆，未成为权威事实；来源可追溯不能保证语义忠实。

检索诊断记录原版四臂候选、种子、扩展路径和每条来源。移除图臂会改变最终 top 8，证明图臂确实参与，而不是占位字段；但未对“无图”再运行行为试验，所以没有独立的行为增益结论。移除直接语义臂仍保留向量图种子，不能当作完全关闭向量。共同出现的角色 ID 和泛实体也会拉入杯垫、喝水等噪声；本轮没有为漂亮结果事后改写固定刺激或调参。

时间探针限定 0–30 tick：四个臂与所有返回来源均在窗口内，没有召回 39 tick 之后的改址证据；更新到 48 tick 的 Observation 被排除。开启时间臂后东塔计划排第二，关闭时间臂后排第一，两个都包含答案；时间臂还把另一批绿色封套排到第一。因此目前确认的是**已知时间窗口约束有效**，不是时间臂提高答案排序。时间探针是召回层诊断，未运行真实角色历史时点回答。

## 6. 权限与事实边界

每个索引只接收 `CognitiveMemoryService` 导出的该角色 namespace 与已验证前缀内来源。宿主把已授权来源对应的获知 tick 一起提供；核心不接收 WorldStore、Event Log、完整世界状态或数据库路径。

所有事实、原文表示、Observation 与召回结果保存精确 `sourceId/sourceHash/epistemicKind/worldSeq/characterId/worldAddress`。时间窗过滤所有候选臂和邻居，多来源归纳只要含窗外来源就不返回。来源字段被篡改、跨角色来源与越界图邻居有相关失败测试。

150 次请求未出现仅其他角色可见的私密标记，派生来源与请求均检查。这个标记测试与权限单测提供对应证据，不证明所有潜在泄漏都被形式化排除。派生材料只写实验输出，角色回应仍经过真实 Character Turn/Rulebook/Event 路径。
