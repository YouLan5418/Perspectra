# 实验分层：Source → Event Atom → Episode → Observation

状态：可选实验实现；正式 Memory schema、World State、Event Log 和 Rulebook 不变。

本记录修正此前将一次完整经历叫作“语义事件”的方案。`Episode` 是经历，内部仍保留独立的最小语义事件。实验中的 Event Atom **不是**权威 World Event。

| 层 | 表示什么 | 可以改变什么 | 不能做什么 |
|---|---|---|---|
| Source | 本角色获准得到的原始证据，含原文与六字段映射 | 新来源追加；旧来源保留 | 用摘要或认识重写原文；读取其他角色来源 |
| Event Atom | 一件发生/获知的最小语义事项，以及它的证据语境 | 从原文选择完整语句，区分发言、叙事、表现和行动结果 | 将声称变为亲眼确认，将意图变为完成，增加主体、因果或动机 |
| Episode | 同一次活动/经历中的 Atom 分组 | 跨回合与处理批次延续成员关系 | 把部分成立推广为整段成立；整体设置“已发生/已完成” |
| Observation | 基于经历形成的可修正主观认识 | 归纳、遗忘、推断，引用支持与相反材料 | 回写 Source/Atom；提升为权威世界事实 |

## 1. 具体边界

“一起喝茶”是一段 Episode，里面可以包含：玩家声称泡茶、邀请、沈南答应、玩家叙述递茶、规则接受的递茶结果、沈南感谢等不同 Atom。

没有获准看到的递茶执行结果，就没有“已执行递茶”的 Atom。若只看到叙事，记录的是“玩家叙述了递茶”，不是实际物品转移。执行结果缺失也不自动证明失败。若看到拒绝结果，拒绝状态与对应 Atom 一起保留。

同一 Source 可以承载多个 Atom；它们不自动获得相同的语义确定性。比如 Source 的 `epistemicKind=reported_speech` 中可能同时含发言与未裁定叙事，Atom 保留原始六字段不变，另记录证据片段的 channel。Source 引用存在不等于其内容为真。

Episode 的前后次序按来源顺序展示，不生成因果关系。获知 tick 仍然是获知时间，不冒充所述事项的发生时间。

## 2. 当前实现

- `episode_core.py` 替换新模式中的自由 fact 改写器。原实验 `facts` 数组存放 Event Atom，`memoryLevel=event_atom` 明确其含义；这只是实验 JSON，没有改正式 schema。
- 模型只选择原文片段。程序根据现有授权来源格式保留说话者、证据 channel 和原文语境，构造正文。选取句内碎片会被拒绝；不清楚时保留完整片段。完整语境随 Atom 一起进入模型请求。
- 明确带 accepted/rejected 的授权行动观察由程序保留完整结果，原始玩家输入和 reason 不充当执行结果；完整 Source 仍原样保存。
- `group` 给新 Atom 分组，允许延续已有 Episode；共同人物/地点/话题不能单独作为合并理由。分组标签是模型提示，不是事实断言。Episode 正文由程序组合成员 Atom，不使用模型写出的整体事件摘要。
- `consolidate` 重新读取 Atom 和旧 Observation 的实际证据。Observation 明确标为 `subjective_inference`，分别保存 supporting/contradicting Atom ID，并记录相关 Episode ID。来源映射只来自具体引用的 Atom，不自动继承整段 Episode 的所有来源。
- 分组与归纳都复制引用证据，不修改下层数据。索引和召回检查嵌套 Atom 的原文、来源映射及与下层 Atom 的一致性。
- 召回去重按 Atom ID；同一来源内未被覆盖的另一事项仍可召回。Episode/Observation 的嵌套证据随结果交付角色模型。
- 新模式索引 Atom、Episode、Observation；原始 representation 留在实验文件用于核对。实体取自对应 Atom 的显式 ID，不再从整条来源的解释性输入继承所有 ID；向量模型、语义边阈值与 RRF 参数保持现有值。没有因果边。

`continuous-drive.ts --memory-grain episode` 接入真实 Character Turn。无该参数时仍使用旧实验基线，不承担正式版本兼容或数据迁移。两种模式必须使用不同输出目录。

## 3. 验证与当前限制

验证聚焦已出现的两个失真：雨伞转述限定丢失、呼唤周姨被写成周姨准备茶。同时验证叙事/执行分离、跨批次分组、具体 Atom 证据覆盖、上层篡改拒绝及跨角色/未来来源拒绝。

真实验证记录见 [分层实验记录](episode-validation-report.md)。原始 120 回合记录只读；局部原句重建不等于全部历史重放，保存请求的模型重放不提交行动，也不等于行为收益 A/B。

有意识接受的限制：

- 保留完整语境会降低压缩率；Atom 不一定已经达到理想的最细粒度。这里优先解决无依据改写，不宣称实现完美语义切分。
- 识别现有文本来源格式是实验适配，尚未改成从授权结构化证据直接取各字段。
- Episode 分组仍可能过宽，当前只增量追加，不自动重新拆分旧分组。
- Observation 仍由模型生成，可能过度概括或复述时间线。主观标识与引用校验不能证明自由文本的推断都合理。
- 同一 Source 的原始输入、发言、叙事可能重叠，不可当作多份独立证据。当前未做完整语义去重。
- 模型读取完整已有事件与相关归纳，尚未优化长历史成本与上下文预算。各来源年龄完整保留，不能用 Episode 最新 tick 掩盖旧材料。

完整授权前缀重建及相同决策请求的三组行为对照已完成，见 [完整前缀实验报告](episode-prefix-study-report.md)。证据分层保留；目前重复交付、长 Episode 编码截断和 Observation 确定性抬升仍需修正，尚未证明稳定行为收益。此次没有增加因果抽取、实体消歧模型或新的事实裁定层。

## 2026-09-30 后续修正：检索与交付职责拆分

前面的证据与认知层级继续保留。认知对象之间是引用关系，Observation 可跨 Episode 或直接引用 Atom；成员组织不提升事实确定性。

现已增加 [Retrieval Projection / Delivery Projection](projection-design.md)：原认知档案只负责证据和认识，检索使用带映射的短表示，交付回到档案按当前上下文和预算读取必要内容。原来的直接全文索引与对象展开交付作为冻结实验对照保留，不再作为新投影模式的实现方式。角色阅读字段和完整追溯档案分别保存。

该拆分不修复已有 Observation 的语义失真，也不修改正式 Memory schema。验证结果见 [投影对照报告](projection-prefix-study-report.md)。
