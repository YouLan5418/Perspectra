# 简化记忆版本：120 回合连续试玩

日期：2026-10-01。独立实验分支 codex/hindsight-core-experiment；请求模型 gemini-3.7-flash，本机 8045 网关。

## 结论

完成了 120 个玩家回合、295 次真实 Character Turn，全部返回，没有运行错误。当前最明显的问题是低信息刺激产生无价值召回，以及严格来源规则阻断了本轮所有 Observation 概括交付。

这轮不能证明长期认知或主动行为改善。第 75–120 回合陷入闭目休息、等待开饭的重复，共 46 回合；其中 45 回合发言只有省略号。必须把这一段的体验停滞和无价值非空召回如实计入结果，不能把回合数量或非空率当质量验收。

## 实验前补的小改动

1. 重启时，从已完成回合保存的各角色授权请求恢复已见姓名／身份元数据，并检查请求、索引快照的角色、世界及前缀。索引与查询继续共用索引内的清理表。不从完整世界 manifest 补充他人身份。
2. trace-summary 加入每 20 回合的实际非空交付、Observation 候选／扣留／交付次数，以及有记忆交付的玩家回合数。候选与交付不再混为一谈；仍保留完整检索路径和原始分数 trace。
3. 先运行到第 20 回合正常退出，再恢复同一轨迹到 120 回合。三个角色重启后的姓名表、清理文本和第 20 回合索引文件字节均与重启前一致。

E5、improved-v3 暂定门槛、最多 3 项交付和严格 Observation 来源规则全程不变。没有启用标签版，没有调参、换编码器、做池化标注或使用留出点。正式 Memory schema、World State、Event Log、Rulebook 不变。

## 实际轨迹与数量

玩家完成 26 次移动、16 次物品交互、78 次发言。前段包含安顿行李、拿放保温瓶／书／笔记本／茶叶盒、分开散步、回厅交谈、提出帮忙和未来去茶棚的打算；没有为记忆安排特定剧情考题。

NPC 返回 273 次 abstain、22 次 publish，没有 perform 提案或主动 recall 决策。23 个玩家回合没有角色调用，主要发生在玩家独自活动时；这些回合没有混入角色空召回率分母。没有发生玩家私聊，也没有完整的承诺兑现／失约／误解修正过程。

## Trace 中的具体问题

### 1. 第 100 回合：省略号召回旧省略号

turn-0100-call-001-companion 的当前查询为“……”，没有内容词，仍走 search。结果交付三条旧“……”，三条来源不同，角色返回 abstain。第 101–120 回合的 60 次调用全部非空，主要沿用这种无价值召回。

这是确定出现的问题：目前 skip 仅判断查询字符串是否为空，纯标点仍能进入向量路。3 项预算控制长度，不能阻止同样的空内容从不同 Source 占满名额。下一步优先做确定性的低信息查询跳过／检索内容排除，先处理这个直接反例，不继续提高整体门槛。

### 2. 第 42 回合：放下茶叶盒召回旧保温瓶与笔记本

turn-0042-call-001-companion 的查询是“drop，对象tea box”。召回旧的保温瓶放下动作和笔记本拿起动作。

旧保温瓶命中 drop／对象，词项覆盖约 0.352、余弦约 0.911、lift 约 0.471；旧笔记本只命中对象，覆盖约 0.142，但余弦约 0.895、lift 约 0.373，仍从语义条件进入。两类噪声均不能简单归给实体路或 RRF；查询还有动作模板残留，语义门槛也允许具体对象不同的动作进入。

三角色在该回合都返回 abstain，没有出现把旧动作说给玩家的可见错误。这是召回噪声证据，不是已证明的角色行为损害。下一步可以局部处理动作模板词与具体对象信号，不扩展检索架构或重新开展大规模校准。

### 3. 合理印象也被严格来源规则挡住

第 73 回合沈南的 Observation 含“交流态度随和惬意”，以及玩家喜欢在大厅读书、闲聊、歇息的认识，支持为 20 个 speech Atom 加 1 个 action Atom；因混入发言支持而整体抑制。第 77 回合三个角色对玩家休整偏好的概括同样被扣留。

这支持用户指出的产品代价：严格规则会损失由对话形成的合理主观印象。但候选正文也混有具体行动、读书进度、计划等内容，不能据此认为给整段加一个标签就解决了所有依据与确定性问题。

可以把“带来源限定的主观印象交付”作为下一轮局部实验方向。本轮并未验证角色因此缺乏人物印象，也没有与标签版成对比较；3 条反复修订的认识不足以估计总体损失率。

### 4. 连续试玩在等待中停滞

第 74 回合玩家表示闭目等待开饭；第 75 回合起反复休息，直到 120 回合没有新的互动推进。NPC 多数保持沉默，没有结构化行动。当前刺激、近期上下文、玩家笔记和世界推进共同影响这个结果，不能单凭长期记忆 trace 指认其中某一因素。

后续试玩需要先避免无限重复等待，用正常的新事情形成有效刺激；不安排人为记忆考题。此次仍保留完整停滞段，没有剪掉后换一个好看的结尾。

## 边界与验证

- 新数据目录运行，没有写入 D:/worlds 历史数据；实验核心仍仅接收 CognitiveMemoryService 的单角色授权前缀。
- 重启回归检查通过：正常恢复，并拒绝不同角色、不同世界与未来前缀；另有 7 项既有交付回归通过。
- continuous-drive 与导入 helper 的独立 TypeScript 类型检查通过；git diff --check 通过。
- 对全部调用执行来源与实际输入审计：快照对应只读角色 namespace／world tick 表，六字段引用、角色／世界范围、获知 tick／年龄、实际模型请求一致。
- 所有交付最多 3 项，紧凑 JSON 字符预算不超过 4,500。记录的模型回答全部返回，未将缺失响应当 abstain。
- 没有运行完整 TS Vitest／lint 门禁，没有人工相关度 gold、语义蕴含审计或行为 A/B。没有新的私聊泄漏玩法覆盖，不能把程序来源校验当作完整语义隔离验收。
