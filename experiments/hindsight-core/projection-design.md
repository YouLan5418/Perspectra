# 检索投影与交付投影：独立实验设计

状态：2026-10-01，当前实验路径启用查询／索引统一清理、相关性准入、候选截断前合并和最多 3 项的保守交付。停止继续扩展离线标注与校准，参数仍为 improved-v3 暂定值。历史报告保留为阶段对照，不表示当前交付规则。不是正式 Memory schema 迁移。最新实现、验证及限制见 [简化交付报告](small-delivery-report.md)。

## 1. 解决的实际问题

上一轮同一对象同时保存证据、参与检索、交付角色。Episode 拼入全部 Atom，Observation 嵌套完整证据，交付直接展开对象。结果是平均 memories JSON 达到 17,109 字符，长 Episode 的向量正文被截断，部分近期内容重新进入上下文。

用两个普通函数替换“直接索引完整认知正文”和“直接展开完整对象交付”。继续复用原有 Hindsight 搜索片段、本地 E5 和角色调用工具，不增加数据库或正式接口。

## 2. 认知档案与两个投影

Source 是原始证据；Event Atom 是最小语义单位；Episode 是同一次经历的组织；Observation 是可修正的主观认识。这是引用关系，允许 Observation 引用多段 Episode 或具体 Atom，不是逐层替换或全部内容一起变真。

本轮冻结已有认知档案，保留旧实验档案中的嵌套证据。投影不会改变 Source、Atom、Episode、Observation，不会将自己的输出重新输入 retain/consolidate。引用存储去重留待独立改动。

| 层 | 结构 | 细节省略 | 推断与事实边界 |
|---|---|---|---|
| Source | 可附宿主元数据，原文不改写 | 不省略原始证据 | 不推断 |
| Atom | 来源、说话者、渠道等 | 尽量少，保留完整语境 | 不新增主体、因果、意图或确定性 |
| Episode | 分组与成员引用 | 阅读表示可省略，成员身份保留 | 分组不证明计划或叙述已经执行 |
| Observation | 支持、反证、认识 | 可以 | 可推断主观认识，内嵌具体事实不能强于证据 |
| Retrieval Projection | 搜索表示与成员映射 | 可以 | 本版用原文摘录和确定性行动描述，来源标签留在元数据，不新增关系，不作为证据 |
| Delivery Projection | 排序、层级、时间和阅读标记 | 可以选择整项省略 | 不改写、不补因果、不推断；不能截掉否定或条件 |

## 3. Retrieval Projection

入口是完整的单角色授权快照。先验证 CharacterId、WorldAddress、asOfWorldSeq、已授权 sourceRefs，再产生搜索表示。

- Atom：发言使用原文摘录，行动使用已有结果字段的确定性描述。来源标签和明确说话者/动作实体放入元数据，不作为通用搜索词。未提供的结果不补写，拒绝仍保留拒绝性质。
- Episode：按成员顺序形成局部搜索窗口，每个窗口保留对应 Atom 和 Source 映射；不索引完整 Episode 拼接正文或模型生成的经历标签。
- Observation：已有主观认识正文进入检索清理，交付按下述来源条件选择原概括、原始支持或省略；投影不修复其既有语义失真。
- Source 原文保留在档案中。本版所有来源已有 Atom，未再将同一 Source 作为额外的竞争搜索单位。

每个表示使用同一固定本地 tokenizer 测量 passage 输入，最多 220 token，低于编码器 256 token 上限。过长原文可拆成搜索摘录；角色阅读始终回到档案，不读截断摘录。

表示可进入 Vector / BM25 / Graph。图中的语义相似、实体共享和时间邻近不是因果或事实确认。多个表示在每个检索臂的 32 个名额及 20 个语义种子截取前先合并为同一 memoryId，再做等权 k=60 RRF。每条记忆每臂一票，窗口越多带来的最大值命中机会仍未完全消除。

普通查询不自动推测时间窗口。当前质量路径将显式 tickWindow 用作全部候选的过滤，不再通过时间边新增候选。旧时间扩展仅用于保留的实验对照。近期证据表示在搜索前排除；Observation 即使依据近期证据形成，也可能作为不同的主观认识参与召回。

### 3.1 当前查询和融合

queries.py 只接受该角色的授权 Context。当前发言优先；同条表情叙述仅在没有发言时作为查询，近期 observations/selfObservations 不再拼接。主动 recall 使用角色提出的查询。动作字段确定性转为短描述；不从其他角色或世界日志补全主体、地点和执行结果。

语义输入含 query 前缀及特殊 token 最多 256 token；关键词从同一关注文本提取中文双字项与拉丁词，保留文档词频，不跨标点拼接。实体种子直接来自当前刺激的明确角色/对象/地点及授权场景地点，不再从语义候选反推整批实体。空刺激不使用通用兜底查询。只有成功纯移动记录时走实体臂，并排除单纯行动记录作为阅读候选；主动询问历史移动仍正常走全部检索臂。该限制可能漏掉与旧行动记录有关的提醒，需在新试玩中检查。

质量路径保留每个表示的原始余弦、BM25、匹配词、IDF 覆盖度、相对查询背景的语义提升、实体分、准入结果和排名。语义提升为 max(0, (cosine - 当前候选余弦中位数)/(1 - 中位数))，不是置信度。

暂定准入条件：余弦 >=0.3 且语义提升 >=0.30，或者查询词项 IDF 覆盖度 >=0.15。此参数在固定阅读点上探索调整过，未通过独立留出集校准。RRF 不承担相关度门槛；融合后按相关性信号重排序，以 RRF 打破同分。没有候选可返回空。

实体按不同 memoryId 的出现频率计算 IDF，共享实体必须伴随已过门槛的语义或词项信号。实体角色保留在 trace，尚未实现完整的指称解析和角色关系匹配。语义邻居不再独立参与 graph 投票；现有语义边保留为诊断路径，不能解释成新增准入或事实印证。

## 4. 候选簇与 Delivery Projection

候选簇是实际 Atom 成员重叠形成的临时连通分组，不按相同人物、地点、话题合并经历，不持久化为新的认知层。

交付根据候选排名、档案、当前上下文和预算进行：

1. 对 Episode 读取命中窗口中自身通过相关性门槛的 Atom，按实际匹配信号选片段，不再统一使用语义分最高的窗口。完整原始证据语境仍不能截断。没有可交付 Atom 的 Episode 不占候选名额。
2. 多个 Atom 引用同一段完整语境时，语境只交付一次。覆盖的 Atom ID 全部记录在 trace 中。
3. 同一 Source 的玩家发言与玩家输入，只有原文完全相同且来源明确标出同一玩家时才合并。独立渠道或不同时间的事件分别保留。
4. 已经在本次 observations/selfObservations 的证据片段不再交付。
5. Observation 的全部支持 Atom 必须为 direct_observation，或 executionStatus=accepted 的 action，才有资格交付原概括。任一发言、外显叙述、拒绝或未知结果支持都会抑制概括；尝试回退为一段自身通过相关性门槛的原始支持语境。没有合适支持则省略。已在当前上下文的反证复用，其余反证与概括或回退支持一起纳入预算；无法容纳则整体省略。来源条件不证明概括的语义蕴含、意图或因果，也可能扣留有价值的发言型主观认识。
6. 默认最多 3 个阅读项、4,500 个紧凑 JSON 字符；反证同样占项数。此处不是 3 个独立经历的配额。完整证据语境放不下时整项省略，不截断原文。

当前预算按重排序的记忆逐轮分配：每轮每个 memoryId 一段完整证据，非 Observation 每个 memoryId 最多两段；Observation 与反证仍作为完整组处理。临时连通簇只用于诊断，尚未设每簇配额，不能将共享一个广泛 Observation 的所有经历压成同一记忆。结构去重不等于所有相似表述都可以删除；跨时间的重复承诺与更正仍是独立经历。

## 5. 角色阅读与追溯分离

角色读取 memoryId、层级、原文或已有 Observation、来源性质、sourceIds 和 sourceAgeTicks，不读取嵌套 Atom、完整档案、索引文本或图路径。

完整六字段 sourceId/sourceHash/epistemicKind/worldSeq/CharacterId/WorldAddress 保存在独立 delivery trace，结合表示到记忆到 Atom 的映射、支持和反证成员、完整检索臂排名和图路径可追溯。Trace 不是角色阅读载荷。

sourceAgeTicks 是距最新所引来源获知 tick 的距离，不是事件发生时间或 Observation 生成时间。具体各来源 knownTick 可以从同角色快照的 Source 表核对。

## 6. 实验边界与验收

核心仅接收 CharacterViewBuilder / CognitiveMemoryService 已授权的角色来源快照；不持有 World Event Log、其他角色来源或完整世界状态的读取句柄。正式 Memory schema、World State、Event Log 和 Rulebook 不变，派生内容不写成世界事实。

冻结原 120 回合与已完成的 81 个分层前缀，重放全部 137 个原查询。保留仅改交付的 shadow 诊断；真实行为对照为“分层 Core 原交付”和“两个投影”，135 个相同决策点每组各调用一次 Gemini，其他上下文字段不变。

先检查证据重复、近期重复、实际载荷、原文语境、六字段映射和固定 15 个阅读点，再看真实模型的决策、对白和行动提案。独立决策重放不执行行动，不证明新的连续世界轨迹或长期玩法收益。

连续实验入口通过 --memory-grain episode --memory-projections 选择新路径。完整检索和交付 trace 在 projection 字段中，hasObservation 表示实际交付含认识。原完整前缀实验是历史证据；最新简化版本验证了 12 个玩家回合、27 次真实角色调用，但交付全部为空，未验证长期非空召回收益。另有四个历史 worker 请求和五次保存上下文的模型冒烟调用，详见简化交付报告。

历史结果见 [投影实验报告](projection-prefix-study-report.md)。当前查询与召回质量结果见 [本轮报告](recall-quality-report.md)。


## 固定检索清理字段（2026-10-01，实验）

Retrieval Projection 的 retrievalText 复用原窗口，不改原 text 或 Source。角色授权前缀内已见的身份元数据形成 retrievalAliases，查询和文档共用确定性规则；未登记昵称不猜测。投影质量运行路径已启用清理后的向量与 BM25 索引，Delivery 仍读原始带来源限定的证据。姓名从内容信号中移除，仍保留为原查询的实体种子及表示中的 mentioned 元数据，不证明行动关系。旧关键词／语义探针保留为基线。连续进程积累授权姓名历史；重启时从已完成回合的各角色授权请求及其快照 scope 恢复，再建立索引。恢复检查世界、角色和前缀，不从完整 manifest 补全身份。旧池化方法见 [池化说明](retrieval-pool-report.md)，当前产品取舍以 [简化交付报告](small-delivery-report.md) 为准。


连续入口每 20 个玩家回合输出 trace-summary 的非空交付、Observation 候选／扣留／交付次数；候选为空与交付扣留分别统计。长试玩使用严格 Observation 版本，是否放宽由实际记录决定。

最新完整连续记录见 [120 回合报告](long-small-delivery-report.md)：来源映射和预算通过；低信息刺激仍会召回旧标点，严格 Observation 概括未交付，后段等待停滞。非空率不表示相关度或行为收益，当前没有据此继续收紧门槛或放宽来源规则。
