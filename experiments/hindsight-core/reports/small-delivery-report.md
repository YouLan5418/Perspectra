# 简化召回与保守交付：实现及验证

日期：2026-10-01。仅适用于独立实验工作树、分支 codex/hindsight-core-experiment。

## 本轮决定

停止继续扩展双模型标注、池化评分、编码器比较和门槛校准。已有工具及历史结果保留供回溯，不再作为继续试玩的前置条件。30 点留出没有使用，没有生成新的人工 gold。

保留 improved-v3 的暂定相关性条件与本地 multilingual-e5-small，不换 Qwen、不继续提高门槛。接受少召回、空召回和偶尔忘记旧事，优先减少无关旧事与过度确定的 Observation 进入角色上下文。

## 实际改动

- Retrieval Projection 的 retrievalText 进入实际向量编码和质量路径 BM25；查询使用同一确定性姓名、角色 ID 与固定模板清理规则。Source 和阅读原文不改。
- 姓名表来自该角色授权前缀内的身份元数据及当前授权 Context，不从完整世界补全未知身份。去掉的名字仍保留为实体种子或搜索表示的 mentioned 元数据，不把“被提到”升级为“参与行动”。
- continuous-drive 在当前进程内积累各角色已见的身份元数据。恢复已有轨迹时不会自动重建之前进程的全部姓名历史，这是目前接受的限制。
- Delivery 默认最多 3 个阅读项、4,500 个紧凑 JSON 字符。质量路径仍逐轮分配，每条非 Observation 记忆最多两段。3 项不是 3 个独立经历；必要反证也占预算。
- Observation 自由概括只有在全部支持 Atom 都属于 direct_observation，或 action 且 executionStatus 为 accepted 时才有资格交付。混合发言、外显叙述、拒绝或未知行动结果，不能借一条成功行动让整段概括获得资格。
- 不满足条件时，抑制概括，尝试交付一段通过相关性准入的原始支持语境，并保留所有尚未在当前上下文中的反证；没有合适支持则省略。反证组放不下时整体省略，不剪掉反证。
- 原 Observation 继续留在档案及索引中；本轮不重写 retain/consolidation，不把角色自己的话变成可信世界事实。

这是保守的来源类型限制，不是语义蕴含证明。即使支持来源全部可信，程序仍不能证明自由概括中的每个意图、因果或性格判断。有价值但仅由发言支持的主观认识也可能被暂时扣留。
