# 历史 JEV 研究脚本

这里收纳原 `tests/experiments/jev-*` 和玩家命令影子审计脚本。正式宿主中的可选 JEV 模块在 [desktop/host](../../../desktop/host/README.md)。

这些脚本用于解释原实验，部分固定了 2026-09-26/27 的路径、事件序号、其他工作树或模型配置，不保证在新环境直接复跑。尤其 `jev-shadow-smoke.ts` 会向 OpenRouter 发请求并追加历史结果文件，它不是离线测试。整理没有执行这些外部调用，也没有重写旧结果或冻结源码副本。

确需复跑时，先核对原始来源，并把输出改到新的实验目录。当前游戏、默认检查和便携包不运行这些脚本；其中 TypeScript 仍保留类型检查。
