# Perspectra Windows x64 测试版

完整解压后双击 `Perspectra.exe`。不要只复制 EXE；`runtime` 目录必须随包保留。

本包自带 Node、Python、固定 WebView2 与离线 E5 记忆编码模型。不需要安装 Rust、Cargo、Node 或 Python。模型对话仍需要你自己的 OpenAI 兼容服务和网络。

## 第一次运行

1. 打开“全局设置”，填写完整的 `.../v1/chat/completions` 地址、模型标识及需要的 API Key。
2. 点击“测试模型连接”。这会发出一次少量请求；连接成功不代表模型一定遵循游戏 JSON 协议。
3. 应用设置，然后“载入游戏包”，选择 `examples/测试示例` 目录，校验并载入。
4. 开始游戏会在系统默认浏览器打开本机网页；Launcher 保持独立窗口。

`examples/前室与后室` 是官方默认界面的基础示例；`examples/测试示例` 附带包预设、变量、猜数字活动和社区前端。社区前端默认沙箱，无需授信即可试玩；只有你明确确认后才启用受信任模式。小游戏入口由游戏页面提供。

## 保存、故事线与退出

已提交游戏进度保存在窗口设置显示的“实例数据目录”。停止游戏后可继续；正常退出 Launcher 会结束它启动的 Core。

要开启故事线：等待当前行动完成，在 Launcher 的“故事线”中保存完整节点，结束游戏后选择节点并分叉。旧线路不会被覆盖。

移动本测试包后，之前载入的游戏包路径可能失效；首次运行前请将解压目录放在准备长期保留的位置。

## 数据与隐私

- API Key 仅保留于本次会话，退出后需要重新填写。
- 默认数据位于 Windows 用户数据目录中的 `app.perspectra.launcher`，以设置页面显示的位置为准。
- 备份时先结束游戏并退出 Launcher，再复制整个数据目录；同时保留原游戏包。实验版暂不保证跨版本存档迁移。
- “实际模型请求”含角色私密上下文，只有自己调试时查看，不要直接上传或附在公开反馈中。
- 授权的远程前端内容可以在不改变本地包摘要的情况下变化；只信任自己认可的来源。

## 已知限制

本轮仅面向 Windows x64 小范围测试。没有代码签名和自动更新；故事线分享、Assistant Prefill 和自定义上下文模板尚未接入。外部模型的速度与 JSON 遵循能力会影响体验。大型包、长时间运行与干净系统验收状态见随包验收记录。

若遇到问题，先保留存档，不要删除数据库。按“反馈模板.md”提交复现步骤；不要发送 API Key、原始模型请求、角色私密日志或完整数据库。
