# Perspectra Windows x64 测试版

完整解压后双击 `Perspectra.exe`。不要只复制 EXE；`runtime` 目录必须随包保留。

Windows 本机工作区启动问题（2026-10-24）：若从受限开发工作区的 dist/portable 目录直接运行时没有窗口，日志出现 WebView2 `0x800700AA`，可能是 EXE 继承了工作区的 Low Mandatory Level 标签。请把原 ZIP 完整重新解压到普通用户目录后运行；本次同一 candidate4 ZIP 在普通目录已打开完整界面。无需修改系统安全设置或删除启动器配置、存档。它不代表所有 0x800700AA 错误都有同一原因。

本包自带 Node、Python、固定 WebView2 与离线 E5 记忆编码模型。不需要安装 Rust、Cargo、Node 或 Python。模型对话仍需要你自己的 OpenAI 兼容、Anthropic 或 Google 模型服务和网络。

本文按 2026-10-29 当前源码同步；具体 ZIP 包含哪些能力，以本包 build-info.json 和验收记录.md 为准。产品版本相同不表示构建内容相同，替换文档或 Skill 不会升级程序。10-24 candidate4 的既有验收不覆盖后续统一 Provider、狼人杀相关宿主修复或本次创作资源更新。

## 第一次运行

1. 点右上角 ⚙，在“模型接口”添加连接，选择协议，填写完整请求地址（OpenAI `/v1/chat/completions`、Anthropic `/v1/messages`、Google `/v1beta/models/模型:generateContent`）及需要的 API Key，保存连接。
2. 查看模型并测试连接。这会实际发出请求；当前源码的角色决策和连接测试统一经 pi-ai 使用流式通道，模型服务须支持相应流式响应。成功不代表模型一定遵循游戏 JSON 协议。在实例的模型设置选择连接和模型，可为角色单独配置。
3. 选择另行取得或自己创作的完整 `worldpack-source/v5` 源目录，校验、载入并创建实例。
4. 开始游戏会在系统默认浏览器打开本机网页；Launcher 保持独立窗口。

本次仅分发 Perspectra 程序，不附带试玩包、游戏实例或私人数据。游戏内容需另行准备。社区前端默认沙箱，只有你明确确认后才启用受信任模式。游戏工具菜单提供重新加载、切换官方界面和后台记忆整理。

创作者可以在终端调用随包 `worldpack.cmd`，无需源码和开发工具。先运行 `--version`、`--help`，再用 `validate` 检查自己的源包；完整命令、JSON 诊断和验收边界见[创作校验](创作校验.md)。

随包 [perspectra-creator Skill](skills/perspectra-creator/SKILL.md) 整合原创世界包、酒馆 PNG／JSON 卡迁移和原生预设创作。附带 Node 脚手架、物品模板、随包 Python 可运行的静态卡片提取／容量分析，以及包推荐和预设库交换模板；不执行原卡脚本。将整个 `skills/perspectra-creator` 目录复制到所用 AI 工具的 Skill 目录，再告诉它 Perspectra 解压位置与创作需求。预设用 `worldpack.cmd preset validate` 单独检查，作品通过 Launcher 新实例验收。它不会自动安装 Skill 或发布作品，生成作品放在自己的新目录。

## 保存、故事线与退出

已提交游戏进度保存在窗口设置显示的“实例数据目录”。停止游戏后可继续；正常退出 Launcher 会结束它启动的 Core。

要开启故事线：等待当前行动完成，在游戏页面“保存进度”，结束游戏后从本局抽屉“存档”选择节点并分叉。旧线路不会被覆盖。新节点包含当时长期档案，分叉不额外调用模型整理；没有档案的旧节点使用授权原始经历。导出存档时选择已保存节点；分享保留节点当时的长期档案。接收者载入相同游戏包后，通过“导入存档”创建独立实例。

移动本测试包后，之前载入的游戏包路径可能失效；首次运行前请将解压目录放在准备长期保留的位置。

在实例“模型 → 修改”可从关闭、低、中、高中选择模型支持的思考强度，下次启动生效；不可用档位置灰，未知模型使用默认选项，接口支持仍需测试。多人反应默认总时限 120 秒，可在运行参数调整。

## 预设与前端权限

结束游戏后，在实例“角色预设 → 修改”中选择全局默认、包推荐或实例自定义。实例内按“角色专属 > 角色组 > 实例默认”选配置；角色或组的配置替换下层，未填参数使用 Core 默认值。修改后重新开始生效。预设库支持原生 JSON 导入导出，不能直接导入酒馆预设，也不能替换 Core 输出协议。

“游戏前端 → 权限”用于确认受信任模式或撤销授权。默认沙箱不开放外部网络/浏览器存储；信任模式仍隔离 Core 令牌、密钥和角色私密上下文。运行中撤销回到官方界面并保留进度。

> 受信任前端访问的远程内容可以在不改变游戏包摘要的情况下发生变化。

活动卡片中的“只有你知道”来自玩家自己的活动私有记录，不包含其他角色的 private 或 internal。默认舞台等待时只显示“正在回复中”；公共接口仍可能包含场内处理者名字，隐藏回合目前没有对玩家隐藏这一调度信息。具体游戏的玩法与已知限制由作品作者另行说明。

已有实例的模型需在该实例的模型配置中修改；全局设置不能替代旧实例配置。失败时先检查公开历史和当前状态，再按提示重试，不反复提交相同玩家行为。

## 数据与隐私

- API Key 按连接保存到 Windows 凭据管理器；可在连接设置更新或删除，不写入游戏包或存档。
- 默认数据位于 Windows 用户数据目录中的 `app.perspectra.launcher`，以设置页面显示的位置为准。
- 备份时先结束游戏并退出 Launcher，再复制整个数据目录；同时保留原游戏包。实验版暂不保证跨版本存档迁移。
- “实际模型请求”含角色私密上下文，只有自己调试时查看，不要直接上传或附在公开反馈中。
- 授权的远程前端内容可以在不改变本地包摘要的情况下变化；只信任自己认可的来源。

## 已知限制

本轮仅面向 Windows x64 小范围测试。没有代码签名和自动更新；完整故事树分享、Assistant Prefill 和自定义上下文模板尚未接入。外部模型的速度与 JSON 遵循能力会影响体验。大型包、长时间运行与干净系统验收状态见随包验收记录。

若遇到问题，先保留存档，不要删除数据库。按“反馈模板.md”提交复现步骤；不要发送 API Key、原始模型请求、角色私密日志或完整数据库。
