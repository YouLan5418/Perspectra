# Windows x64 干净系统验收

当前候选版未完成此验收。本机隔离 PATH、搬离源码目录的验证不能代替此项。

建议在没有 Node、Python、Rust、源码仓库的 Windows 10/11 x64 新用户环境或虚拟机中操作；记录 Windows 版本、用户名类型和内存。开始前保留压缩包旁的 SHA-256 校验文件。

1. 核对 ZIP 的 SHA-256，完整解压到包含中文和空格的长期目录。
2. 普通用户双击 Perspectra.exe。应出现游戏库，不要求安装运行环境。若 Windows 拦截，记录提示原文；请勿关闭系统安全功能。
3. 在设置中填写自己的 chat/completions 地址、模型和会话密钥，点击连接测试；故意使用错误地址后应有可读错误，修正后成功。
4. 用实际“载入游戏”目录选择器载入 examples/测试示例，创建实例。启动后应由系统浏览器打开游戏。
5. 依次测试聊天、移动、物品交互、活动开始/无效输入/逃生；无效输入不应悄悄推进状态。切换官方默认模板后仍可聊天。
6. 停止游戏，设置全局/实例/角色组/角色专属预设，重新开始；确认生效优先级。只在自己电脑查看实际模型请求，不附在公开反馈中。
7. 保存静止节点，停止、继续，确认进度；停止后从节点分叉，旧线路保留。
8. 默认社区前端应为沙箱。明确授权后应显示受信任；运行中撤销应切换回沙箱；如切换无法确认则停止 Core，下次回到沙箱。
9. 游戏运行时正常退出 Launcher，确认自己启动的 Core 和 Python 无残留；重开后继续原实例。密钥应重新输入。
10. 连续运行至少 30 分钟并完成至少 30 次操作，记录响应速度、错误、内存变化和后台记忆整理状态。此项是发布前长时门禁，十二轮检查不能代替它。
11. 断开互联网但保持本机模型服务，启动和记忆编码不应尝试下载依赖；远程模型本身离线不可用属于预期。

每一步标注通过/失败/未测。遇到失败保留数据，按反馈模板给出最短复现步骤，不提交凭证、数据库或角色私密上下文。
